# Категории импорта .181 — факты и границы

До подтверждения импорта можно сохранить категории исходника, выбрать
существующую через поиск/страницы или ввести новую. Общая категория ZIP назначается
всем его чертежам; обзор явно показывает имя и число документов. «Исходные»
сбрасывает выбор, «Назад» не пишет данные. Категория — поле документа, не папка
на диске. Импортированные копии хранятся в config/BuildWorks/imports QA-профиля.

Имя нормализуется существующим правилом Trim/UpperInvariant; 1–24 символа,
без управляющих символов и < >. null сохраняет исходные категории, введённая
пустая строка отклоняется. Проверка выполняется до запуска worker. Меняется
только окончательная отдельная копия перед кодированием; исходник, review,
sourceDocuments и original/source.bin сохраняются. Обзор не создаёт категорий
в локальном реестре и не обходит его прежние ограничения собственных сохранений.

В длинном отчёте видна полоса прокрутки. Ею можно читать во время операции,
не получая разрешения менять данные. Ввод категории недоступен до готовности
обзора и восстанавливается после возврата/нового обзора.
