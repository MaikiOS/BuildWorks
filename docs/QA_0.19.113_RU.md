# Проверка .113 — сохранить записи или исключить отсутствующие детали

Файл: `tests/fixtures/missing-policy/12-missing-choice.blueprint`.
Имя: **QA113 Missing Choice**. Состав: обычная стена `woodwall` и намеренно
несуществующий `BuildWorks_QA_MissingPrefab` в точке X=2. Это авторский QA-файл,
устанавливать сторонний мод для него не нужно.

В проводнике открой папку профиля Default, затем
`BuildWorks/tests/fixtures/missing-policy`; скопируй полный путь к файлу.
Исходное состояние: изолированный TerrainRamp-1.0-Test, QA мир/персонаж вне спавна
на подготовленной площадке. Проверь установленную версию .113. Запуск только
Thunderstore → **Modded**. Инструкция не разрешает автоматический запуск игры.

1. В каталоге редактора нажми «Импорт файла», открой указанную папку, выбери файл,
   нажми «Импорт файла». До подтверждения должна появиться одна отсутствующая
   запись с точным ID и источником. Выбор по умолчанию:
   «Отсутствующие детали: СОХРАНИТЬ ЗАПИСИ».
2. Нажми «Подтвердить импорт». Открой отдельную копию через «РЕДАКТИРОВАТЬ»:
   в дереве две записи, одна обычная стена и условный маркер отсутствующей детали.
   Исходный файл не меняется. Закрой редактор.
3. Повтори импорт того же файла. Нажми кнопку отсутствующих деталей: надпись
   меняется на «Отсутствующие детали: КОПИЯ БЕЗ ОТСУТСТВУЮЩИХ ДЕТАЛЕЙ».
   Предупреждение указывает исключение одной записи. Нажми «Назад к параметрам
   файла», снова «Импорт файла»: выбор должен вернуться к сохранению записей.
4. Ещё раз включи копию без отсутствующих деталей и нажми «Подтвердить импорт».
   В результате должна быть новая отдельная копия с одной стеной. Первую неполную
   копию и исходный файл этот выбор не изменяет. Открой новую копию, сдвинь стену
   гизмой, «Сохранить» → имя **QA113 Only Wall** → «Сохранить». Повторное открытие
   сохраняет одну стену и её изменение.
5. Молотком выбери **QA113 Only Wall**. Ожидается одна стена обычного размера.
   Отключи бесплатную стройку для проверки survival; ресурсы подготовленного QA
   стенда уже доступны. Запиши их количество, построй один экземпляр: один шаг,
   ожидаемый расход без повторного списания. Выйди с сохранением из QA мира,
   снова войди: стена сохраняет положение, поворот и масштаб.

Ошибки: нет предупреждения/точного ID; записи удаляются без выбора; «Назад»
сохраняет исключение; портится исходник/первая копия; после исключения остаётся
маркер; гигантский масштаб; лишний расход, зависшая очередь или исчезновение
после загрузки. При полностью отсутствующем составе исключение должно быть
недоступно, а исходные записи можно сохранить. Этот отказ, изменение реестра и
атомарность ZIP проверены автоматически; здесь не нужно вручную менять моды.

Сценарий не подтверждает multiplayer, административное восстановление,
крепления/хранилища, отмену после списания или туманный v11.
