## Что исправлено

Прежний адаптер typed-ZDO принимал у крепления только `item:String`.
Теперь `item:Int32` допускается только при точном имени из Info **той же
исходной строки**. Проверяются четыре поля `имя:variant:quality:type`, совпадение
hash имени с числовым ID и совпадение трёх атрибутов с декодированным состоянием.
Глобального поиска по хешу, похожего имени и подстановки модели нет.

Перед декодированием проверяется связь prefab/номера строки/Info/ZDO с сохранённым
источником. Пустой, некорректный, подменённый или неполный Info оставляет запись
неподдержанной. Любой неизвестный внешний ключ, включая одноимённое поле другого
типа, сохраняет прежний запрет применения всего состояния. Старый пятиаргументный
API и строковый вариант сохранены; без Info числовой ID не угадывается.

Поддержанное содержимое поступает в существующий `valheim-itemstand-v1`, с прежними
настройками включения, стоимости и предоставления собственного предмета. Эти
правила, серверные права и восстановление административного состояния не менялись.
Точный исходник остаётся в sourceDocuments. Схемы native22/portable11 прежние.
