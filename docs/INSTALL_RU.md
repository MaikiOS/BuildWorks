# Установка приватной альфы 0.19.329

[English](INSTALL.md)

BuildWorks 0.19.329 — приватная альфа для ручного тестирования

1. Полностью закрой Valheim.
2. Открой папку нужного профиля с установленным BepInEx 5.
3. Скопируй старую папку BepInEx/plugins/Ostrix-BuildWorks ВНЕ любых plugins; отдельно сохрани конфиги и библиотеку чертежей.
4. Слей папку BepInEx из архива с папкой профиля, заменив вместе BuildWorks.dll, BuildWorks.Geometry.dll, YamlDotNet.dll и THIRD_PARTY_NOTICES.md. Оставь одну активную копию мода.
5. Конфиги, чертежи, миры и персонажей сохрани. Не переноси тестовый профиль, мост QA или isolation token.
6. Запусти свой modded профиль. В BepInEx/LogOutput.log должна быть одна загрузка BuildWorks 0.19.329. На втором ПК повтори установку в его собственный профиль.

Копия при перетаскивании: зажми Alt и тяни стрелку/плоскость перемещения. До сдвига копии нет, перемещается копия; Esc отменяет, Undo отменяет результат целиком.
Отображение → уровень земли Y задаёт условную плоскость и не сдвигается автоматически. Проверка опоры и устойчивости включается отдельно, изначально выключена. Серый значит «не проверено». Красный может ещё соответствовать минимальной опоре; смотри текст панели. Окончательные условия и оплата проверяются в настоящем мире Valheim.

Для отката закрой игру и верни backup мода; не удаляй игровые данные. При несовместимости данных старой версии используй соответствующий backup библиотеки.
Это приватный ZIP, не публичная бета и не пакет Thunderstore. Английская инструкция и точные границы проверки — INSTALL_EN.txt и QA_SCOPE_EN.txt.


[Все четыре файла: BuildWorks.dll, BuildWorks.Geometry.dll, YamlDotNet.dll, THIRD_PARTY_NOTICES.md; проверенный hostSteam26249040/BepInEx5.](ALPHA_0.19.329_RU.md)

## Данные и удаление

Обычная библиотека: `BepInEx/config/BuildWorks/blueprints.json`; переносимые файлы: каталог BuildWorks, `share/<id>.buildworks.json`. QA перенаправляет данные в существующий изолированный корень. Точный путь даёт игровое «Поделиться»; профиль не угадывать. Папка share сама не импортируется и не публикуется сервером.

Перед удалением закройте игру и сохраните чертежи/share. Удаляется только `BepInEx/plugins/Ostrix-BuildWorks`; уже построенные объекты мира это не отменяет. Миры/персонажей/другие профили не удалять.

Сверьте SHA256SUMS.txt из архива: один номер версии не отличает прежние329-итерации. Используйте приватный архив владельца; публичная ссылка загрузки не заявлена.
