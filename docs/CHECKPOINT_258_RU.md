## Изменение

К журналу [257](CHECKPOINT_257_RU.md) подключён исполнитель для private Local host. Перед эффектом проверяются собственный плательщик/мир/каноническая квитанция, неизменный inventory, точный сохранённый sealed-источник и поколение. Сначала сохраняется профиль и намерение очистки. Исключение из защиты разрешает ровно один вызов DestroyZDO для того же экземпляра, ID и manager; finalizer проверяет одно добавление в native-очередь и сохраняет исходное исключение.

Затем исполнитель ждёт отсутствие объекта и в ZDOMan, и в ZNetScene, запускает штатный world save и принимает только N+1 с полным сканом отсутствия. Уже завершённый повтор не требует старого объекта и не удаляет/сохраняет повторно. Неопределённость, timeout, другой профиль/мир/инвентарь или разрыв контекста прекращают работу с reconciliation. Runtime исключает наложение payout/collection/cleanup и останавливает незавершённую работу при Suspend/Dispose.

QA-адаптер вызывает тот же runtime, измеряет фактический inventory и отдельно считает попытки native-удаления/world-save/profile-save. Счётчик попытки сам по себе не доказывает эффект. Обычная отмена через табличку пока не вызывает этот путь; финальное закрытие проекта не реализовано. Новых ресурсов код очистки не создаёт.
