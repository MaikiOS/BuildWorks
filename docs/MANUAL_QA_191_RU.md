# .191 — автоматическая замена устаревшей крыши

Начальное состояние: установленная .191 или новее (сейчас .192; сверить живой список), прежний QA-мир/персонаж через Thunderstore → TerrainRamp-1.0-Test → Modded. Старые принятые тесты не повторять. Для пунктов1–4 не нужны материалы, рецепты или стенд; ничего строить не требуется.

Исходники находятся в `BuildWorks/artifacts/Blueprints-for-import/BuildWorks-tests`:

- `35-present-not-in-hammer.blueprint` — одна старая деталь, карточка **TEST 35 Legacy Roof Warning**.
- `hs_blackforest_hut.blueprint` — исходный Forest Hut,28 деталей, четыре старых ID. Файл библиотеки не менять.

1. Молоток → «ЧЕРТЕЖИ» → «Импорт файла». Открыть указанную папку, выбрать файл35 и начать проверку файла. До «Подтвердить импорт» ожидается **wood_wall_roof → wood_wall_roof_a — 1 шт.**, сообщение о сохранённом исходном ID и правилах актуальной детали. Нажать «Назад к параметрам файла», затем закрыть: новый архив/карточка не должны появиться.
2. Повторить импорт файла35 и нажать «Подтвердить импорт». Открыть результат → «РЕДАКТИРОВАТЬ». Ожидается та же форма и положение; поиск по ID `wood_wall_roof_a` находит актуальную деталь. В своей копии выполнить «Сохранить как…» с новым именем и снова открыть её. Исходный файл остаётся прежним.
3. Через «Импорт файла» выбрать Forest Hut. Ожидается **четыре** замены до подтверждения, а не ручной подбор четырёх деталей. Подтвердить, открыть редактор:28 деталей, форма дома сохранена. Импорт создаёт новую запись; прежнюю отредактированную QA187 Forest Hut не перезаписывает.
4. Для импортированной копии → «Экспорт файла» → PlanBuild. До подтверждения ожидается предупреждение об истории замен, которая не помещается в сторонний формат. Отменить. При отдельной проверке полного экспорта BuildWorks повторно открытый файл должен содержать актуальные ID и исходное происхождение.

Признаки ошибки: старый ID остаётся рабочим ID после заявленной замены, число замен неверно, красная missing-рамка вместо доступной крыши, модель сдвинута/масштабирована, повторное открытие отказывает по source reference, источник изменился, после отмены появилась карточка. Если список замен отсутствует, сообщить версию игры/сборки и точное имя файла: это может означать отказ native проверки; не подбирать случайный новый ID.

Проверку оплаченного строительства/reload автоматически преобразованного Forest Hut выполняет Codex отдельно после подготовки ресурсов в QA. Не нужно добывать материалы или строить стенд вручную. Файл35 сам по себе не является устойчивым стендом для строительства: одиночная крыша требует обычной опоры.

Сценарий .190 для недоступной старой крыши после успешной миграции .191 меняет ожидаемый результат и не повторяется как прежний тест предупреждения.
