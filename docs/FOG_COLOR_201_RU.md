# Цветовой контракт тумана v11: .201

2026-10-16. Причина белёсой стены .200 воспроизведена: собственный shader-пакет был собран в Gamma, тогда как Valheim работает в Linear, с HDR и DeferredShading. Исправлена сборка пакета; четыре runtime shader/compute исходника не менялись. Утверждённые архив и исходники v11 сохранены.

## Что изменено

Обычный Build-FogGhostAssets.ps1 теперь принудительно собирает Linear пакет и проверяет фактический цветовой режим. Отдельный -GammaReference создаёт только контрольный пакет в artifacts и не заменяет игровой. C# и PowerShell возвращают прежние настройки Workbench; ProjectSettings.asset после проверок совпал с исходными байтами. LoadEmbedded явно отклоняет Gamma-хост. Явный конструктор ресурсов остаётся доступен для сравнительных тестов.

Игровой пакет содержит прежние три собственных ресурса, 49 715 байт, SHA `0DD52DF3790D17756DA5A5F9D45B54F23FAD0716E8B7FB95A7662B4E2BAAF889`. Игровые модели и текстуры в пакет не добавлялись.

## Доказательства

- Unity 6000.0.61f1, Linear/HDR/Deferred: поверхность из Linear пакета совпала с прямым исходным shader пиксель в пиксель, средняя RGB-разница 0. Ошибочный Gamma пакет дал 0,048705826878076335. Отрицательный тест загрузки embedded пакета в Gamma прошёл. Это сравнение неподвижной поверхности, не всей Linear объёмной симуляции и не пользовательское принятие внешнего вида.
- Отдельное сравнение с утверждённой Gamma-лабораторией сохранило шесть кадров и два переноса в прежнем допуске; Shape/Pigment/Noise совпали побитово. С игровым Linear пакетом прошли 270 шагов и 18 полных точных сравнений Smoke/Flow/Surface, дробные интервалы, предел догоняющих шагов, ошибочные данные и освобождение ресурсов.
- Normal/QA сборки: 0 ошибок, 0 предупреждений. Host Steam25909357, QA-control/isolation и localization1104 прошли. Verify helper отсутствует; выполнены прямые проверки и независимые correctness PASSED/Ponytail Ship.
- Установлена QA0.19.201.0 только в TerrainRamp-1.0-Test, DLL SHA `F8829697C625613FB2D84E917A66D4FED8D29EAE1DDE7518C40498C4DA6C3022`. При установке 143 прежних файла сохранили SHA и UTCmtime.
- Valheim запущен через Thunderstore → TerrainRamp-1.0-Test → Modded. Перед входом подтверждены только прежние QA-мир и персонаж. Native woodwall сохранил цвет дерева и прозрачность; просмотрены кадры до контакта и внутри стены. Реальное движение персонажа: damage 0 → 1 → 1 при остановке → 0 после выхода; smoke при контакте 2,98046875. Failure отсутствует, временный root и ссылка удалены.
- Видимые 14 записей инвентаря, включая количества, слоты и показанную прочность, совпали до/после финального прогона; Wood9. Полные inventory bytes здесь не сравнивались. Прежний WAL v4 сохранил SHA `95A4C7430457CDF2130246421F144F607F2B4E4ED0F17894C447E553BB602CF8`. Защиты god/ghost сняты, игра штатно закрыта, собственный helper остановлен, endpoint отсутствует.

Локальные доказательства: artifacts/fog-material-201, fog-color-check/verification.json, fog-runtime-assets, fog-runtime-assets-gamma, fog-runtime-visual, fog-runtime-simulation. Три игровых кадра скопированы в fog-material-201 до очистки bridge. В публичный Git они не включаются.

При чтении отчёта ввода с -Capture первый ConvertFrom-Json получил `Unexpected character encountered while parsing value: S`: скрипт дописывает строку Screenshot после JSON. Повторный разбор отделил эту строку; оба отчёта имеют status=completed. Контакт и восстановление отдельно подтверждены игровым API. При штатном закрытии Sky сообщил no screenshot targets found; отсутствие процесса подтверждено отдельно.

## Что остаётся

Одна стена не доказывает готовность целого дома. Принятие вида v11 пользователем в игровом освещении, полная Linear volume-паритетная проверка, повёрнутые/пересекающиеся источники и производительность остаются открытыми. Существующая область занимает около 46,9 МиБ полей: такую область нельзя создавать каждой детали. Следом — корректная принадлежность плотности нескольким частям при ограниченной памяти; затем постоянный проект и колышек/табличка, материалы, достройка, отмена/возврат, повторная загрузка и сервер. Обычная стройка ещё не использует этот туман. Полная цель ACTIVE.
