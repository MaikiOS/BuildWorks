# .181 — категория до импорта

Проверять, когда удобно, после установки .181 через обычный QA-профиль
TerrainRamp-1.0-Test → Modded. Каталог не заполняется автоматически.
[Все исходники для выбранных тобой импортов](<C:/Users/nfspr/AppData/Roaming/Thunderstore Mod Manager/DataFolder/Valheim/profiles/Default/BuildWorks/artifacts/Blueprints-for-import>).
Можно использовать свои файлы. Готовый небольшой пример двух чертежей:
`BuildWorks-tests/34-two-categories.zip` в этой папке.

1. Исходное состояние: открыт «Импорт файла», выбран файл, выполнен первый шаг
   «Импорт файла», показан обзор перед подтверждением. Поле «Категория» пустое:
   это означает сохранение категорий исходника, а не потерю категории.
   Для примера34 после «Подтвердить импорт» ожидаются карточки
   QA181 Category A/B в категориях QA181 A/B. Ошибка: обе принудительно
   оказались в OTHER или каталог выбрал посторонний результат.
2. До подтверждения другого выбранного файла введи в «Категория» своё имя,
   например «Мои тесты». Обзор явно показывает нормализованное имя и число
   документов. Для ZIP это общая категория всех документов. После подтверждения
   карточки находятся в МОИ ТЕСТЫ, выбран первый результат на своей странице.
   Исходный ZIP не меняется. Ошибка: часть документов сохранила прежнюю категорию,
   появилась лишняя карточка или новое имя пропало после перезапуска игры.
3. В следующем обзоре нажми «Выбрать»: найди существующую категорию поиском
   и нажми её строку. «Отмена» возвращает обзор без нового выбора, «Исходные»
   сбрасывает переопределение. «Назад к параметрам файла» ничего не записывает;
   следующий обзор начинает с исходных категорий. Ошибка: нельзя вернуться,
   старый отменённый выбор сам применяется или ввод уходит в игру.
4. Неверное имя, например `<bad>`, объясняется и не даёт подтверждения.
   Верни допустимое имя или нажми «Исходные». Длинные предупреждения читаются
   колесом/видимой полосой прокрутки. Ошибка: сырое исключение, скрытый текст,
   недоступное подтверждение после исправления или неподвижный интерфейс.

Этот тест не требует ресурсов, рецептов, строительства или подготовки мира.
Не нужно импортировать весь набор и повторять уже принятые проверки масштаба,
камеры и Save As. Индивидуальные категории внутри группового выбора файлов,
сам выбор нескольких файлов, автофайл/«Поделиться» и передача игроку ещё впереди.
