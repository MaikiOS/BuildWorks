# Короткая проверка доступности .179

Когда будет время: Thunderstore → TerrainRamp-1.0-Test → Modded → прежний QA-мир/персонаж. Никакой ручной добычи/разблокировки рецептов для этой проверки. Авто17/18, масштаб, SaveAs и камеру повторять не нужно. [Копии .178](MANUAL_QA_178_RU.md) остаются отдельной непроверенной серией.

**Файл:** `hs_blackforest_hut.blueprint`, исходная библиотека Biome Blueprints. **Уже импортированная карточка:** `QA175 Forest Hut`,28 деталей. Пользоваться этой сохранённой копией, повторный импорт не нужен. В каталоге молотка выбрать «ВСЕ», найти имя через «ПОИСК». Если своей копии нет, сообщить это; исходники/чужие карточки ради теста не удалять.

1. С молотком открыть карточку → «Проверить чертёж». Ожидается читаемый отчёт; он также записан в `BepInEx/LogOutput.log` текущего QA-профиля, блок `BuildWorks blueprint diagnostics`. Закрыть окно. Не требуется вручную переписывать отчёт. Ошибка: окно не закрывается/зависает или разные действия дают общий отказ без причины.
2. Нажать «РАЗМЕСТИТЬ». Если доступно — должен появиться призрак28 деталей с правильными размером/осями; поиск/другая страница не должны запрещать доступную деталь. Если остаётся `!`, ожидается конкретная причина: отсутствует prefab/нет в инструменте/не разрешена игрой. **Это возможный незакрытый случай, а не успешная стройка.** Не открывать рецепты и не подменять детали ради получения зелёного результата: теперь сохранённые факты позволят найти действительную причину.
3. Только если призрак доступен и показанных ресурсов хватает: на свободной ровной части QA-площадки проверить положение и построить один раз. Ожидается совпадение с призраком, обычный показанный расход. Ничего не разбирать. Выйти/снова войти в тот же мир, сравнить именно этот дом и изменённую деталь с состоянием до выхода. Ошибка: пропавшие/гигантские детали, другое положение/поворот, лишнее списание/повторное строительство. Если ресурсов не хватает, эту часть пропустить, ничего добывать не нужно; незавершённый ресурсный сценарий с колышком/v11 ещё разрабатывается.

Строительство этого дома и его reload заранее не объявлены исправленными. Проверка причин доступности не проверяет весь импорт, административный режим или сеть. Новые тестовые saves не создаются.
