## Остановка первой попытки и исправления проверки

Первый запуск `20261020-185806` прошёл12/12 подготовки, но runner отверг два предупреждения HarmonyX о `AdventureBackpacks.API.ABAPI`/`Backpacks.API`. Проверен источник `ValheimQA/vendor/ValAgentBridge/Src/BackpackCompat.cs`: это проверка наличия необязательных модов; при отсутствии API функция возвращается. Те же сообщения сохранены в подготовке250. Новое правило допускает только эту точную пару Warning/source/text и только при подготовке; остальные ошибки и предупреждения отклоняются. Старый отчёт остаётся отклонённым, запись тогда не начиналась.

До запуска независимый обзор также потребовал дождаться завершения асинхронного recorder: Stop сам по себе не гарантирует освобождения буферов. Private runner теперь ограниченно ждёт resourcesReleased, проверяет восстановление cadence и фактический результат закрытия fixture до logout. Пять проверок отказных/пустых состояний прошли. Если cleanup не завершился, игра сохраняется для разбора и мост не перезаписывается вслепую. Ошибка PowerShell empty-array/ProcessId при завершении первой попытки исправлена; после отдельной проверки отсутствия процесса мост тогда восстановлен штатным скриптом. Во второй попытке весь порядок завершился автоматически.

Collector отдельно исправлен по фактической последовательности записи: capture начинается до StartWallPass, а обратный подход может быть мгновенным. При нулевых страницах после recovery comparedTexels=0 ожидаем, при hold требуется ненулевое сравнение. Это исправления проверки свидетельств, не изменения поведения тумана.
