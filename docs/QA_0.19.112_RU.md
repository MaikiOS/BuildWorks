# Проверка .112 — одна стена

Готовый файл: `tests/fixtures/single-part/11-single-part.blueprint`, имя
**QA112 Single Wall**, одна обычная стена без предметов/состояния.
В проводнике открой известную папку профиля Default, затем
`BuildWorks/tests/fixtures/single-part`; скопируй полный путь к этому файлу.

Исходное состояние: только изолированный профиль TerrainRamp-1.0-Test и отдельный
QA мир; персонаж вне зоны спавна на подготовленной площадке. Перед запуском
сверить установленную версию. Запуск через Thunderstore → **Modded**.
Эта инструкция не является разрешением автоматического запуска.

1. В каталоге редактора открой «Импорт файла», укажи путь к этому файлу, нажми
   «Импорт файла», затем «Подтвердить импорт». Ожидается отдельная копия, одна
   деталь; исходник остаётся прежним. Дубликат детали не должен появиться.
2. Найди **QA112 Single Wall**, нажми «РЕДАКТИРОВАТЬ». В дереве одна стена.
   Сдвинь её гизмой, нажми «Сохранить», подтверди имя/категорию кнопкой
   «Сохранить». Закрой и открой снова: одна стена, изменение сохранено.
3. Молотком выбери сохранённую копию. Ожидается одна стена обычного размера.
   Для проверки расхода отключи бесплатную стройку; подготовленные ресурсы
   QA стенда уже доступны. Запиши количество ресурсов до размещения.
   Размести один экземпляр. Должен завершиться ровно один шаг без зависшей очереди,
   расход соответствовать показанной стоимости; повторного списания быть не должно.
4. Сохрани и выйди из QA мира, снова войди: одна построенная стена сохраняет
   положение/поворот/масштаб. Не использовать основной мир.
5. В редакторе удали единственную деталь: пустой документ не должен сохраниться
   поверх существующей копии. Отмени изменение или закрой без сохранения.

Ошибка: запрет сохранения одной детали, появление второй записи/стены, гигантский
масштаб, исчезновение после загрузки, зависшая очередь, лишний расход, изменение
исходника или потеря сохранённой копии после попытки пустого сохранения.
Крепления, отмена после списания и multiplayer требуют отдельных сценариев;
эта стена их не подтверждает. Поддержка одной детали не завершает выбор
«Без отсутствующих деталей» и не подключает туманный v11.
