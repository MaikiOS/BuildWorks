## Placement and operating requirements

These changes apply to BuildWorks F9 and blueprint placement. Ordinary placement outside BuildWorks retains native tilt/clearance rules. A typed Container cannot be an attachment donor, even when `m_supports=true`. Other WearNTear donors retain their own native support flag and valid-view requirement; static surfaces without WearNTear remain eligible. A bench's existing native donor right is not removed merely because it is furniture. Overlap with a chest is allowed when a separate eligible surface provides contact. No global Wear exemption, strength boost, free payment or admin air placement is included. Fire, fuel, roof and other operating requirements are checked separately from placement.
