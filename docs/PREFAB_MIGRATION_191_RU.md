# .191 — проверенная замена старой детали при импорте

Реализовано одно соответствие: `wood_wall_roof` → `wood_wall_roof_a`. Основание — явные метки разработчиков в текущих ресурсах Valheim и [сравнение моделей](PREFAB_MIGRATION_EVIDENCE_RU.md), а не сходство имён.

При предварительной проверке файла/группового импорта мод сверяет текущие прототипы: исходную/целевую метки, корневой масштаб, дочерние TRS, активность/слои/теги, общие mesh и material references, renderers, BoxCollider и LOD. Skinned/неизвестные формы коллайдеров, повторяющиеся пути и более128 узлов отклоняются. У новой детали должны существовать Piece, WearNTear и непустой корректный native рецепт. Если проверка не проходит, автоматическая замена не выполняется; обычные предупреждения и ручная работа остаются.

Заменяются только разобранные записи с точной связью с исходной строкой; неразобранные foreign data и materialSeed этой первой версии правила не переносятся на другой prefab. Позиция, поворот, масштаб, stable ID и группы сохраняются. Старые собственные чертежи не переписываются автоматически. Правило работает в предварительной проверке импорта файла/набора, а не как глобальный alias всех prefab в мире.

Перед «Подтвердить импорт» окно показывает оба ID и число замен. Отмена не пишет архив. Перед началом записи native проверка повторяется. Это не проверка каждый кадр: просмотр окна не запускает постоянное сравнение mesh.

## Происхождение и форматы

- Native24/portable13 хранят необязательный `originalPrefabName`. Эффективный `prefabName` используется для моделей, зависимостей, native стоимости и размещения; исходный ID — для строгой связи со строкой source document.
- Разрешена только указанная точная пара. Другой ID, неверные строка/документ, отсутствие источника и попытка добавить поле в native23/portable12 отвергаются. Проверка источника не отключена, архивный текст не переписывается.
- Значение проходит clone, detached copy, редактор, сохранение/«Сохранить как», вставку/массив/контур, Undo/Redo и world workspace. Это метаданные происхождения, не право строить или восстанавливать административное состояние.
- PlanBuild получает актуальный ID по своему формату. Перед экспортом выводится предупреждение, что история замены остаётся только в соседнем полном файле BuildWorks.

## Что проверено

Geometry и полный Store прошли. Новый Store-сценарий проверяет review→подтверждение→архив→каталог, отказ при изменении native gate после review, сохранность исходника/TRS, copies, native24/portable13, отказ подмены и старого формата, editor Duplicate/Undo/Redo и предупреждение потери истории в PlanBuild. Остальные тесты обновлены под текущие24/13 с сохранением старых fixture/downgrade/future проверок.

Обычная и QA-сборки0/0, HostContract191, QA isolation, localization1102 и formatter новых классов прошли. Helper verify отсутствует. Независимое чтение correctness PASSED; финальный Ponytail — Ship. Настоящий Controller DLL bridge также проверил copy→BuildStoreParts→native save→disk→DocumentFromBlueprint с обоими ID и исходником; его штатный csproj восстановлен в tests/BuildWorks.EditorBridgeChecks.

В Unity6000.0.61f1 без графики **сам production геометрический предикат** прошёл на двух установленных prefab. Полный Workbench прошёл624 снимка: новое окно импорта показывает четыре замены на12 сочетаниях разрешения/масштаба; снимок1280×720/140% просмотрен, перекрытия нет. Workbench использует разрешающий тестовый native hook и не доказывает native рецепт/полномочия/строительство. Первые отказы wrapper/HostContract были старыми ожидаемыми количеством снимков/номером формата; после исправления оба скрипта целиком прошли повторно.

В Valheim .191 автоматический импорт, строительство, устойчивость, стоимость и reload ещё не приняты. Ручная замена Forest Hut на .189 остаётся принятым отдельным случаем. Установка и SHA фиксируются отдельно. [Короткая ручная проверка](MANUAL_QA_191_RU.md).

Полная цель, остальные конвертеры/моды, предметы/серверные права, колышек/v11, выделение и сеть остаются открытыми.
