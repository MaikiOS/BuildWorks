# Ручная очередь .182 — готовый файл и «Поделиться»

QA .182 установлена в TerrainRamp-1.0-Test. Проверяем только разрешённый QA-мир через Thunderstore → TerrainRamp-1.0-Test → Modded. Каталог автоматически не пополняется. Принятые проверки масштаба, Save As, камеры и привязок повторять не требуется.

## 1. Автоматический файл собственного чертежа

Исходное состояние: свой небольшой чертёж, созданный тобой или импортированный и сохранённый в редакторе. Если нужен готовый пример, необязательно импортируй `16-supported-snap.blueprint` из `artifacts/Blueprints-for-import/BuildWorks-tests`. Другие исходники для импорта в `artifacts/Blueprints-for-import` остаются отдельно от игры.

1. Открой выбранный чертёж в редакторе, измени одну деталь и нажми «Сохранить»; подтверди имя/категорию.
2. Открой каталог чертежей редактора, наведи на карточку сохранённого чертежа и нажми «Поделиться» внизу.
3. Нажми «Открыть папку». Точное имя файла показано в окне: `<ID>.buildworks.json`. Запиши это имя для следующих шагов. «Скопировать путь» копирует полный путь к этому файлу.
4. Вернись в редактор, измени чертёж и снова сохрани. Снова открой файл через «Поделиться».

Ожидается: файл находится в `TerrainRamp-1.0-Test/BepInEx/config/BuildWorks/share`, обновляется под тем же именем; новая карточка из-за передачи не появляется. Папка возникает после первой записи. «Сохранить как» даёт отдельный чертёж и отдельный файл. Удаление собственного чертежа удаляет его управляемый файл; исходники и пользовательский экспорт не затрагиваются.

Ошибка: новая карточка при каждом нажатии «Поделиться», старое содержимое после успешной записи, отсутствие файла без сообщения об ошибке, изменение исходного файла библиотеки.

## 2. Сохранённая версия при открытом черновике

Исходное состояние: файл и точное имя из проверки 1; сохранённый чертёж открыт в редакторе.

1. Сдвинь деталь, но не сохраняй.
2. Открой каталог, наведи на карточку сохранённого чертежа, нажми «Поделиться».
3. Закрой окно и каталог. Проверь свой несохранённый сдвиг и Undo.

Ожидается: окно явно говорит о передаче сохранённой версии. Файл не включает несохранённый сдвиг; черновик и его история остаются. Новых карточек нет.

Ошибка: несохранённый черновик заменён или помечен сохранённым, сдвиг попал в передаваемый файл без сохранения.

## 3. Молоток и импорт переданного файла

Исходное состояние: файл из проверки 1. Дополнительные ресурсы и строительство не нужны.

1. Открой молоток → «Чертежи», выбери ту же карточку, нажми «Поделиться».
2. Проверь совпадение полного пути с проверкой 1, закрой окно.
3. Через «Импорт файла» выбери точный `<ID>.buildworks.json`, показанный в проверке 1. Подтверди параметры и явно выбранную категорию.
4. Открой импортированный чертёж в редакторе; сравни состав, масштаб, положение, надписи/опоры, если они были в исходном примере.

Ожидается: молоток даёт тот же готовый файл; только явный импорт добавляет карточку. Источник сохраняется, поддерживаемые данные совпадают. Получатель файла может повторить этот импорт у себя. Передача внутри сетевой игры и общая серверная библиотека пока не реализованы.

Ошибка: «Поделиться» сразу размещает объект, публикует что-либо или создаёт копии; файл не читается собственным импортом; данные пропадают.

Сбои записи, конфликты с чужим файлом и повтор после Save As проверяются автоматически. Для ручной проверки не блокируй папки и не повреждай свою библиотеку. Игровая приёмка и сетевой обмен остаются отдельными доказательствами.
