# Условия бинарного выпуска

[English](PUBLISH_CHECKLIST.md) · [Исходники/QA/публичный пакет](docs/CURRENT_STATUS_RU.md)

Push исходников не является бинарным релизом. Старые галочки не наследуются, автоматического выпуска нет.

- [ ] Назвать точный коммит, согласованную пару DLL, совместимость host и заявленный объём.
- [ ] Пройти затронутые build/localization/geometry/store/host; UI/fog при изменениях. Старые ошибки учитывать отдельно.
- [ ] Установить штатным скриптом в разрешённую QA при закрытой игре; сверить хеши и сохранность данных.
- [ ] Пройти нужные native вид/ввод/стройку/отмену/ресурсы/reload на поддерживаемых языках/разрешениях.
- [ ] Для сетевых обещаний пройти host+remote/reconnect/restart/права.
- [ ] Описать неподдерживаемые форматы/состояние, missing, ограничения и остаток. Лабораторный рендер не выдавать за постоянный дом.
- [ ] Проверить происхождение/лицензию пакета; только свои assets, без игровых DLL/saves/token/логов/QA-обходов прав.
- [ ] Получить отдельное разрешение Ostrix на этот бинарный релиз; затем notes/manifests/hashes принятой пары.

.206 сейчас QA, не публичный пакет; недострой/табличка и приёмка всего модуля открыты. Исторические [условия .37](docs/PUBLISH_CHECKLIST_0.19.37_RU.md) и опубликованные alpha сохраняют исходный объём. [LICENSE](LICENSE) не меняется.
