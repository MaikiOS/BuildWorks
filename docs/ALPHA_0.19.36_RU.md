# Статус исходников BuildWorks 0.19.36 alpha

[English](ALPHA_0.19.36.md) | **Русский**

English localization 0.19.35 принята в игре. Отдельная проверка косых деталей показала, что Blueprint Editor сбрасывал каждое новое размещение в AUTO вместо переноса активного ванильного индекса Q/E-точки.

## Исправление

- одиночная деталь в редакторе наследует `Player.m_manualSnapPoint` через существующий host-adapter;
- E продолжает цикл со следующей точки, не вращая деталь;
- составной чертёж остаётся в AUTO, потому что индекс одной детали не обозначает опору всего чертежа;
- collider-эвристика, проверенная во время диагностики, удалена: exact prefab tests не показали полезного изменения положения.

## Автоматические доказательства

- Release build: 0 предупреждений, 0 ошибок;
- каталоги и runtime-токены: 596/596, без коллизий;
- регистрация English/Russian: PASS;
- Geometry 104, Store, EditorBridge 3, WorldLayout 10, HostContract: PASS;
- Unity Workbench: 81/81 PASS;
- хеши установленных DLL в `TerrainRamp-1.0-Test` совпадают с проверенными артефактами.

Косые детали и русский язык ещё требуют игровой приёмки. Commit, push, Pull Request, бинарный пакет и публичный release не выполнялись.
