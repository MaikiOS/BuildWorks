## 0. Непрерывная мышь — впервые в настоящей игре

Исходник16-supported-snap.blueprint, карточка TEST16 Supported XYZ Snap; папка указана в проверке1. РЕДАКТИРОВАТЬ → СОХРАНИТЬ КАК… → QA137 Scale. В копии выбрать пол, вернуть100% по всем осям. S → X → двигать
мышь к верхнему краю области модели. Ожидается перенос указателя к нижнему
краю без скачка формы; продолжение движения меняет масштаб. Повторить несколько
проходов, Enter подтверждает одним действием, Ctrl+Z возвращает исходную форму.
Повторить G → X → Z и перетаскивание стрелки гизмы с зажатой ЛКМ:
преобразование продолжается через край; отпускание/Enter фиксирует видимый результат.
Для R используется одна ось; свободное наведение G на поверхность не переносит курсор.

Удерживать Ctrl: курсор свободно достигает панелей и кнопок осей; отпускание
Ctrl внутри области модели позволяет продолжить. Esc отменяет без изменения;
Alt+Tab во время операции отменяет и освобождает курсор. Вернуться, начать новую
операцию: мышь и кнопки работают. Закрыть редактор: игровой ввод возвращается.
Ошибка: скачок модели при переносе, повторные самопроизвольные переносы,
невозможность попасть в панель с Ctrl, изменение после Esc/Alt+Tab, застрявший курсор.

Если появится сообщение о недоступном переносе, этот пункт НЕ принят:
записать точный текст и приложить LogOutput.log; продолжить остальные проверки
числовым вводом. Наличие Input System DLL само по себе не доказывает работающий backend.
Если перенос не наблюдается250мс или не попадает в допуск8px, предпросмотр
безопасно отменяется с сообщением. Это ограничение также сообщить; принудительно
менять настройки ввода игры не нужно. Материалы и строительство здесь не нужны.

## 2. Две оси XZ

В той же копии QA137 Scale выбрать пол с исходным масштабом100% по всем осям,
«Оси: детали». S → X → Z: обе кнопки осей подсвечены. Двигать мышь вверх внутри
окна: меняются X/Z, Y остаётся100%. Ввести1.5 → Enter: X/Z=150%, Y=100%.
Ctrl+Z отменяет одной операцией; Ctrl+Y возвращает. Снова Ctrl+Z для исходной формы.
G → X → Z → мышь: движение только в плоскости XZ. Ввести1 → Enter:
смещение по X и Z на1м в выбранной системе координат; Y не меняется.
Ctrl+Z отменяет. Повторить S → Z → X: результат такой же. Esc отменяет предпросмотр.
СОХРАНИТЬ и повторно открыть: подтверждённые положение и форма сохраняются.
Повтор первой оси переключает локальные/мировые оси, сохраняя пару;
третья ось выбирает одну ось. Для вращения R пары не предусмотрены.
Ошибка: Y меняется, вторая ось заменяет первую, Enter даёт другую форму,
отмена оставляет изменение или Undo требует двух операций.
