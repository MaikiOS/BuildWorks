# Ручная проверка копий .178

Проверять, когда удобно, в прежнем QA-мире через Thunderstore → TerrainRamp-1.0-Test → Modded. Материалы не нужны: эта серия целиком в редакторе. Принятые масштаб, auto17/18, SaveAs и камеру повторять не требуется.

Файл **33-copy-alignment.buildworks.json** находится в `Default/BuildWorks/artifacts/manual-qa-178`. «Импорт файла» → выбрать эту папку/файл → «Подтвердить импорт» → карточка **QA178 Copy Alignment** → «РЕДАКТИРОВАТЬ». Исходное состояние: красная рамка **QA missing target**, поворот Y30°; стены **QA own wall A/B** стоят отдельно, X7 и X9. Если эта карточка уже изменена, использовать её исходный файл и отдельное имя копии.

1. **Копии и отмена.** В дереве выбрать рамку, с Ctrl добавить A и B. «СОВМЕСТИТЬ» в параметрах инструмента: у рамки появится предпросмотр двух копий, исходные стены останутся в стороне. «ОТМЕНА» убирает только предпросмотр; в дереве снова три исходных записи. Повторить и нажать «ПРИМЕНИТЬ»: пять записей, две исходные стены и две новые в отдельной выбранной группе, рамка сохранена. Ошибка: оригиналы уехали/исчезли, рамка удалена, лишние копии остались после отмены.
2. **Локальные оси и история.** У новой группы выбрать «Оси: детали». G → X → ввести 1 → Enter: двигаются только копии вдоль их повёрнутой красной оси. Undo отменяет этот сдвиг; ещё один Undo убирает весь результат совмещения. Redo возвращает обе копии. «СОХРАНИТЬ КАК…» → **QA178 Copy Saved**, выйти и повторно открыть эту карточку: оригиналы, рамка, две копии и их поворот сохранены. Ошибка: движение вдоль мирового X при локальных осях, движение оригиналов или повреждение состава после открытия.
3. **Замена и каталог.** В исходной карточке с тремя записями выбрать рамку+A+B → «ЗАМЕНИТЬ» → «ПРИМЕНИТЬ»: четыре записи, оригиналы остаются, удаляется только рамка, у её начала координат две копии. Один Undo возвращает три записи. Затем выбрать только рамку → «СОВМЕСТИТЬ» → «Открыть каталог» → доступную деревянную стену → «ПРИМЕНИТЬ». Рамка остаётся; локальная гизма новой стены совпадает с её поворотом. Ошибка: исходные детали потеряны, для отмены одной операции требуется несколько Undo или локальная ось расходится с деталью.

Совмещение известной рамки использует центр записанного объёма; замена — начало координат опорной детали. Неизвестные размеры не угадываются. После совмещения можно подогнать копии гизмой и удалить рамку отдельно. Стройка, ресурсы, перезагрузка мира и сеть этой серией не проверяются.

Остальные новые проверки .177 остаются в [короткой очереди](MANUAL_QA_177_RU.md); заведомо заблокированный Forest Hut снова строить пока не нужно.
