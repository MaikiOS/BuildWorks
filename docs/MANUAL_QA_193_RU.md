# .193: проверка обычного автостыка

Проверку выполняет Codex после разрешения Ostrix от2026-10-15. Это сценарий ещё не завершённой native приёмки, а не просьба повторять принятые проверки редактора.

## Начальное состояние

Thunderstore → `TerrainRamp-1.0-Test` → `Modded`. Loader должен сообщить0.19.193, QA-изоляция активна; только прежние QA-персонаж и мир `BW_QA_43d3719a`. При другой идентичности никаких действий в мире. Не создавать новые saves и не входить в TerrainRamp_Lab/личные миры. Сначала записать положение, инвентарь, god/ghost и существующий Forest Hut/TEST24; не переиздавать ресурсы автоматически.

Codex использует существующие опоры QA-площадки или самостоятельно готовит контролируемый стенд в разрешённом мире. Пользователь не должен собирать материалы или строить стенд. Подготовку стенда, бесплатные QA-операции и собственно проверку обычного строительства учитывать отдельно. Пока стенд не готов, серия не помечается доступной пользователю.

## Привязка без расхода ресурсов

1. Выбрать обычную «Деревянную стену» молотком, точный режим F9 закрыт. Записать колесный угол и ghost TRS.
2. Подвести к одинаковому месту трёх горизонтальных опор с контролируемыми root0°, yaw180° и roll180°. Для каждой записать prefab, root quaternion, native/chosen source/target, режим auto/manual и конечный ghost quaternion.
3. Повторить с изменённой камерой, затем с ручным выбором точек Q/E. Ни одной установки для этого шага не требуется.
4. Ожидается: скрытый поворот опоры не умножается на поворот стены; native/chosen пара совпадает для обычной детали. Камера может изменить выбранную точку, но не добавляет поворот корня цели. В точной ничьей native порядок точек допускает другой кандидат; это отдельно отмечать, не называть дрейфом quaternion.
5. Проверить явный точный режим: F9 → существующий «АВТОСТЫК» → намеренное выравнивание по XYZ наклонённой цели. Отмена возвращает обычное управление; ресурсы не списываются.

## Размещение и сохранение

После preview-проверки Codex готовит достаточные ресурсы отдельной зафиксированной QA-операцией. NoCostCheat должен быть false. Выполнить одно обычное native размещение, сверить реальный TRS с ghost, расход/инвентарь и поддержку. Затем штатно сохранить/выйти/повторно войти и сверить именно эти объекты и свежий инвентарь; старые сетевые ID не считать идентичностью после reload.

Ошибка: самовольный разворот на180°, смена ordinary пары нашим обработчиком, расход при просмотре/отмене, расхождение ghost/реального объекта, потеря или повторное списание после reload. При отказе сохранить лог/кадр/состояние; не повторять мутирующий шаг вслепую. После серии восстановить временные god/ghost, освободить ввод и штатно выйти, чтобы компьютер был свободен при возвращении Ostrix.
