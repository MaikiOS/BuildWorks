# .176 — сверка локального файла персонажа

13 октября 2026. QA **0.19.176** установлена в **TerrainRamp-1.0-Test**.

Завершённая в памяти передача теперь может подготовить ожидание и проверить канонический локальный `.fch`: персонаж, целостность SHA-512 и точные native-байты его inventory. Подтверждение связано с ID операции, завершённым журналом v3, меткой контейнера, обеими inventory и текущим ZDO. Проверки повторяются до открытия файла и после чтения. Общий ограниченный сериализатор используется и для сундука, и для собственных предметов игрока; архивные свойства не загружаются.

Поддержана только текущая запись profile46 / Player33 / Inventory109. Максимум файла32MiB, inventory1MiB/4096 записей, строка профиля32KiB, статистический словарь65536 записей, миров1024; перед выделением памяти и обходом проверяется остаток секции. Неверная контрольная сумма, длины, версии, EOF, UTF-8, идентичность, состав или свойства дают отказ. Читается один canonical handle с FileShare.Read; `.new`, `.old`, Cloud, Legacy и Auto подтверждением не являются. Источник и путь проверяются повторно: native-сохранение может изменить источник.

**Это доказательство текущего содержимого inventory в локальном файле**, а не того, что был выполнен новый save-запрос. Старый канонический файл с совершенно теми же байтами удовлетворяет только этой узкой проверке. Остаток Player33 после inventory остаётся непрочитанным; полная пригодность Player.Load, облако, сервер, сохранение мира и атомарность двух сторон не доказаны. SHA-512 защищает от повреждения, а не от намеренной правки локальным владельцем. Код не вызывает сохранение, не снимает удержание операции, не удаляет журнал/метку и не разрешает refund. Наполненный Container в строительстве **по-прежнему выключен**.

Проверено: CPU51 новый parser/adapter/реальные временные файлы; прежние240 transfer/271 return/114 recovery/36 journal/31 reservation; полный Geometry; normal/QA0 ошибок/0 предупреждений; Host текущей Steam25730771 с четырьмя дополнительными native fingerprints; локализация990; headless Unity compile/contact и настоящий shared capture/guard. Native Inventory/игра в CPU заменены инертными моделями. Первые ошибки InvalidDataException, sandbox NuGet и рассогласование loader version исправлены; итоговые проверки прошли. Correctness PASSED, Ponytail Ship. `verify` не установлен: использованы прямые проверки и независимый обзор.

Установка: BuildWorks SHA256 **CA1D1F860158311789BE641D37DD877E09D6BE7E5366DFA6CA56288667BCF334**; Geometry **08E29183B670459393BAE0D8D8660148D9FE8632E089FDF3A973B6D5CA765775**. Все158 config-файлов/token/квитанции неизменны. Игра, ввод, модель и пользовательские saves не запускались/не изменялись. Протоколы и private native evidence: `artifacts/checkpoint-0.19.176`; декомпиляции не входят в source-only Git.
