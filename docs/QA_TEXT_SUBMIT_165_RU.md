## Воспроизведение и граница результата

Через QA-ввод F5 открывает консоль. После смены виртуального устройства выбранное
поле теряется: отдельный text и попытка клика вне поля дали подтверждённый aborted
`Text requires a focused writable TMP/UGUI input field`, stopRevision8→9→10.
Закрытие/открытие F5 в той же последовательности восстанавливает native фокус:
text задаёт devcommands/ghost on, но Return не подтверждает ввод. На кадрах нет
ответов `Dev commands: True`/`Ghost mode:True`; выполнение команд не заявляется.
Консоль затем закрыта F5, все нажатия отпущены. Телепортация/защита не подтверждены.

Артефакты: `artifacts/local-qa-agent/yard-20261012`, квитанции01–05, текущие
декомпилированные Terminal/Console/GuiInputField/TMP_InputField. Снимки mailbox
перезаписываются; сохранность каждого промежуточного кадра не заявляется.
Игровой лог проверен отдельно вне песочницы. Процесс был скрыт песочницей:
отсутствие Get-Process в ней не было принято за закрытую игру.

## Исправление

Текущий GuiInputField отключает EventSystem navigation, а TMP читает текстовые
клавиши из Event.PopEvent. Виртуальный InputSystem keyboard не создаёт эти события.
QA AfterInput после Feed вызывает штатный ExecuteEvents.submitHandler ровно на
первом кадре Return и только для выбранного активного, focused, interactable,
не readonly TMP-поля с отключённой navigation; MultiLineNewline исключён.
При обычной navigation действует прежний путь. Новых протокольных действий,
прямых вызовов TeleportTo/стоимости/предметов, OS-ввода нет.
