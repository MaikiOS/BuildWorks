# .232 — обычный чертёж создаёт строительный проект

19.10.2026 · [English](CHECKPOINT_232.md)

Подтверждение обычного структурного чертежа теперь сначала сохраняет точный план и создаёт табличку/v11, затем передаёт детали существующей native-стройке с оплатой. Проверен ограниченный private Local host-путь на двух стенах; весь модуль не завершён.

## Изменение и найденная причина

`ArmPlacement` перед native-списанием передаёт замороженные мировые позы в `BlueprintConstructionProjectRuntime.Create`. Подтверждение поглощается; первая ProjectPart запускается в следующем кадре. При ошибке Store подтверждение не проваливается в прежнее строительство. Повтор неопределённой записи сохраняет ID; изменение snapshot/TRS вызывает конфликт вместо нового проекта. Подтверждённый durable-файл остаётся успешным результатом даже при ошибке таблички; без таблички автоматический старт запрещён.

Native-прогон обнаружил настоящую остановку после первой стены: `SyncWorldPlacementMode` оставлял неактивную Session в `BlueprintWorldPlacement` из-за выбранной карточки, а разрешение следующей ProjectPart требовало `None`. Теперь оба пассивных режима допустимы; активный редактор/F9/выделение, pending catalog, окна и прежние gameplay-проверки сохранены. Это также позволяет открыть табличку с выбранным чертежом.

Специальные поверхности, `foreignData`/содержимое, Repeat/Guide и сетевой контекст сохраняют прежний путь. Это явная граница этапа, а не поддержка всех объектов.
