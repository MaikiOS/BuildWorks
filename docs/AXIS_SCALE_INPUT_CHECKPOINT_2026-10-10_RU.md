## Следующая ручная проверка — только после новой QA-установки

Исходное состояние: Thunderstore → **TerrainRamp-1.0-Test** → **Modded**,
тестовый мир/персонаж **BW_QA_43d3719a**, в логе новая установленная версия.
Сейчас стоит .117: этот сценарий пока не выполнять.

Файл: `16-supported-snap.blueprint`, карточка **TEST 16 Supported XYZ Snap**.
Папка: `C:\Users\nfspr\AppData\Roaming\Thunderstore Mod Manager\DataFolder\Valheim\profiles\TerrainRamp-1.0-Test\BepInEx\config\BuildWorks\test-fixtures`.
Использовать существующую карточку; повторный импорт не требуется.

1. Открыть **«Редактировать»**, выбрать один пол в дереве. При необходимости
   **«Сохранить как…»** → отдельное имя, чтобы сохранить исходный стенд.
2. S → X → двигать мышь вверх/вниз. Изменяться должна только выбранная ось.
   Набрать 1,5 → Enter: должно получиться 150% от формы в начале действия.
3. Ctrl+Z / Ctrl+Y возвращают обе формы. Повторить выбор Y кнопкой,
   затем Z клавишей; Esc отменяет незавершённое изменение.
4. **«Сохранить»**, закрыть редактор, снова **«Редактировать»** эту копию:
   форма и положение должны сохраниться. Принятые расход/reload/камеру отдельно не повторять.

Ошибка: меняются остальные оси, прыжок формы при Enter, кнопки осей недоступны,
Esc меняет документ или повторное открытие теряет масштаб. Для повёрнутой детали
недопустимый перекос должен давать понятный отказ, без частичного изменения.
