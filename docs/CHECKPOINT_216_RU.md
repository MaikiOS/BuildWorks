## Изменение и причина

Плотная динамическая копия полей для каждого владельца заменена одним ограниченным набором GPU-страниц. У каждой страницы сохранён одноклеточный край соседних значений; шейдер использует аппаратную фильтрацию. Для8192 блоков фактическая текстура126×126×114 занимает **14478912 байт**, независимо от числа владельцев. Статическая форма плюс динамические страницы в контрольном renderer: **22601184 байт**, прежде29208736. Это учёт конкретных текстур, не всей памяти процесса и не замер FPS.

Адрес опубликованного поколения меняется вместе с метаданными только после успешной упаковки. Отказ сохраняет предыдущий адрес и все32 слова метаданных. Проверяются владелец, поколение, банк, границы буферов и настоящий предел физических страниц, включая лишние ячейки округлённой текстуры. Срок жизни текстур остаётся связан с завершением GPU-работы.

Прямое ручное смешивание восьми значений отклонено после двух одинаковых превышений прежнего допуска: локальная ошибка0.0611572/0.0612793 при пределе0.03. Логи сохранены. Допуски не ослаблялись; итоговый вариант использует аппаратную фильтрацию. Независимый dense reference сохранён только для сравнения.
