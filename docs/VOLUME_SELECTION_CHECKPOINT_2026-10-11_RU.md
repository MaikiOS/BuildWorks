# .150 — площадь и границы мирового выделения, offline

Исходники .150; установлена прежняя QA .146. По просьбе Ostrix игра, Unity,
ввод и установка не выполнялись. Полная цель и игровая приёмка остаются открыты.

## Поведение в исходниках

В существующем «ВЫБРАТЬ В МИРЕ» добавлен режим «Режим: объём»:
протянуть площадь XZ, задать «Низ»/«Верх», нажать «Обновить выделение».
Плоскость фиксируется при входе по Y исходного призрака/персонажа; обе высоты —
смещения относительно неё, это явно написано в панели. Диапазон ±512м.
Изменение высоты показывает рамку, но не сканирует мир при каждом движении мыши.
После изменения нельзя сохранить устаревший список: требуется обновление.

Правило попадания — **мировая точка положения Piece** внутри включительных
границ. Пересекающая край длинная деталь с началом координат снаружи автоматически
не входит: её можно добавить кликом. Это не проверка пересечения геометрии.
Список по6 строк на страницу; [x] исключает, [ ] возвращает. Клик по видимой
доступной детали добавляет/исключает; Ctrl исключает. Ручные решения сохраняются
при изменении площади/высоты; исключение имеет приоритет. Новый вход очищает их.
Режим «Режим: экранная рамка» сохраняет прежний выбор по видимости.

Запрашиваются только имеющиеся Piece; автоподгрузки зон нет. Панель показывает
число незагруженных зон, **не обещает полноту**. Радиус запроса покрывает диагональ
объёма с запасом для строгой границы native radius query. Запрос ограничен4096
зонами и допустимыми координатами. Budget/QA отказ сохраняет предыдущий выбор.
Normal512/QA50000 остаются прежними; перед большой мутацией и capture проверяется
изолированная loaded session. При исчезновении выбранной детали список становится
устаревшим: нельзя молча сохранить частичный результат.

Визуальный вариант — тонкая полупрозрачная голубая рамка12 рёбер без коллайдеров,
теней и заливки. Это **предложение, не утверждённый игровой вид**. Сравнение на
фоне мира/разных разрешениях ещё предстоит. Деревья и объекты без строительного
Piece этим режимом не поддержаны; их административный путь I11/I12 открыт.

## Доказательства

Логи и receipt: `artifacts/checkpoint-0.19.150/`.

- Geometry: границы/finite/overflow, обратный объём, ручные решения, дедупликация,
  пустой результат,50000 и атомарный отказ50001; весь Geometry suite прошёл.
- `BuildWorks.WorldSelectionChecks/Run.ps1` исполняет извлечённые настоящие методы
  экранной рамки, commit и input с заменителями host. Normal/QA commit проверяет
  лимит/права до мутации и изменение подсветки только у затронутых деталей.
- Обзор обнаружил ошибку: короткий клик по высокой стене отклонялся при промахе
  луча по горизонтальной плоскости. Исправлено разделением click/drag. Тест
  прежнего early return красный; текущий handler проходит click, неверные start/end
  drag и верную площадь, сохраняя прежнюю площадь при отказе.
- Normal/QA .150:0 warnings/0 errors. HostContract Steam25185596, локализация988,
  compiled QA isolation в обеих DLL, EditorBridge прошли. `verify` отсутствует;
  вместо него прямой diff, эти проверки и независимый обзор, затем Ponytail.
- Ponytail обнаружил повторное создание/локализацию всех строк при height drag.
  Убрано: сохраняется снимок до изменения состава. Actual-source height/HUD test
  на50000 строках и64 шагах сохраняет тот же массив без новых локализаций;
  изменение состава пересобирает снимок. Прежний вызов воспроизводит красный тест.
  Это проверка числа работ/ссылки, не замер FPS Valheim.
- Четыре новых production-файла проходят scoped format. В изменённых старых
  Session/HUD остаются3 прежних WHITESPACE вне нового кода; происхождение записано
  в `format-preexisting.json`. Общий формат проекта не объявлен чистым.
- Для будущего Unity Workbench добавлен HUD test: высоты/отмена поля, явное
  обновление, страницы/режимы/input gate. Он **не запускался и не компилировался
  Unity**. Runtime HUD компилируется обеими сборками плагина.
- Установленные DLL .146 снова сверены; установка/сохранения не менялись.
  Состояние обзоров и локальные commits записаны отдельно в verification.json.

Store/полный корпус импорта не повторялись: формат, хранилище и конвертер этим
этапом не меняются, последние .148 результаты сохранены. Не измерены native
picking/зоны/highlight/FPS/память. Capture → редактор → стройка → reload/сеть
не проверены. Отмена текста высоты возвращает число, но может оставить требование
обновить список; это текущая граница удобства, не потеря исходных данных.
