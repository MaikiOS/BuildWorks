## Current implementation findings

- `BlueprintEditorController.TrySave` calls `TryUpdateDocument` for an existing
  source and `TrySaveDocument` for a new document. Save As needs a distinct ID and
  must retain the original, including on cancel/write failure.
- Format XYZ support does not establish an axis-editing tool. Geometry, preview,
  bounds, snap, native colliders and reload must agree.
- `RequestMissingReplacement` requires an individually selected missing record
  plus available replacement pieces or their group. Visibility/locking and
  parent-plus-child selections are guarded. The action exists, but discovery and
  prerequisite explanations remain a real UX failure.
- `UnifiedHammerCatalog` offers confirmed deletion for stored native blueprints,
  deliberately omitting it for external library sources. Removing a stored copy
  must not delete its external source; hiding a library entry is a separate action.
- Existing tree search and cyclic All/Selection/Hidden/Locked/Missing filters are
  insufficiently clear, particularly Russian «НЕТ». Add explicit categories,
  attribute search and retained ancestor context without changing membership.
- Editor flight already uses held RMB + WASD, Q/E vertically and Shift for speed.
  This is not acceptance of a discoverable interior-camera mode, item placement
  workflow or restored input ownership.
