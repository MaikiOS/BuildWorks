Выбрана одна атомарная группа вместо последовательной очереди: каталог проверяется один раз, первая операция не делает последующие обзоры устаревшими. Цена — общий ограниченный снимок группы в памяти и отмена всей непубликованной группы. Повреждённые файлы исключаются явно до подтверждения; исправные выбранные документы публикуются вместе. Исключённый документ не становится рабочей карточкой, но исходный файл остаётся в архиве происхождения.

Группа: 1–32 исходных файла/карточки, до64 МиБ входных bytes, общий бюджет чтения распакованных данных128 МиБ, до100000 деталей суммарно; существующие ограничения отдельного документа, entries/превью и всей библиотеки сохраняются. Экспорт подготовленных документов ограничен64 МиБ. Не отключена защита от повреждений/исчерпания памяти. Runtime callbacks prefab metadata снимаются на host-потоке; worker не обращается к Unity.

Экспорт этого этапа — полный внутренний BuildWorks ZIP. PlanBuild и другие сторонние batch-форматы пока не добавлены. Сохранение sourceDocuments/unknown evidence не означает восстановление чужого поведения. Точные исходные файлы хранятся в импортированном архиве; экспорт переносит данные поддерживаемого portable-формата. Серверная публикация и личная передача внутри игры ещё не реализованы.
