# .127 — legacy-надпись PlanBuild и семь отказов координат

Исправлен отказ чтения надписи, которая начинается с кавычки, но не является
JSON-строкой. PlanBuild пробует JSON, а при ошибке оставляет исходный текст:
[PieceEntry.FromBlueprint](https://raw.githubusercontent.com/sirskunkalot/PlanBuild/master/PlanBuild/Blueprints/PieceEntry.cs),
проверено 2026-10-10. Например, кавычки вокруг фразы и слово Achievement после
них — допустимый буквальный текст, а не неизвестное состояние объекта.

BuildWorks разрешает такой результат только для prefab `sign` в `.blueprint`.
Крепления используют прежний строгий декодер; остальные Info/ZDO/chance остаются
отдельными инертными данными. Контрольные символы и длина свыше4096 запрещены.
Сверка Info с исходной строкой при ZDO использует тот же literal-декодер;
известный ZDO text имеет приоритет, неизвестный ZDO не удаляется.
Разбор native/portable JSON не ослаблен. Форматы остаются native22/portable11.

Обе регрессии сначала воспроизвели отказ: обычная надпись и надпись с ZDO. Проверены JSON, обычный текст, начальная
кавычка, буквальный незакрытый текст, предел длины, запрещённые символы,
атомарный отказ, строгий вызов для других адаптеров, native save/reopen и
portable roundtrip с точным текстом источника и привязкой к строке.

В неизменённом локальном архиве DarkTrooper/2v2t5.0.0 файл
`TheDecay CornerStairwell - Apollyon.blueprint` теперь сохраняет все467 записей,
точную надпись на строке174 и исходный документ после native/portable цикла.
Для проверки конвертации использована инертная единичная база масштаба:
доступность моделей, правильный игровой масштаб и строительство этим не доказаны.
Корпус: **202/209 читаются,7 явно отклоняются**, новых отказов нет.
