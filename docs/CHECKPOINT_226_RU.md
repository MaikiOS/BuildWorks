# .226 — оплаченная native-достройка и повторная загрузка

18 октября 2026 · [English](CHECKPOINT_226.md)

В существующем изолированном QA-мире проверены прежняя оплаченная попытка,
достройка четырёх стен через обработчик таблички и повторная загрузка мира.
Это ограниченный structural/local-host этап, а не готовая система недостроя.

## Исправленные причины

- Первый стенд ставил центр woodwall у ног: стена была заглублена на1м. Native отказал NoRayHits без расхода; исправлена только позиция тестового стенда по действительным bounds, без изменения tolerance или земли.
- Inventory.Save пишетv110, SnapshotItem ошибочно ставилv109: терялось `Cheated=true`. На реальном снимке подтверждено расхождение; исправлен envelope110, строгая сверка свойств сохранена. CPU принимает правильный110 и отклоняет109/потерю свойства; native проверил16записей.
- Открытая табличка блокирует обычный ввод; recovery ошибочно требовал его доступности. Убран противоречивый guard, остальные проверки контекста/молотка/дистанции сохранены.
- ZDO.Load назначает новые сетевые ID. Поиск после reload использует уникальный сохранённый operation marker среди всех ZDO нужного prefab, с дедупликацией; текущий ID нужен только для поиска instance. Уже сохранённые journal/receipt не переписываются. Совпадение внешнего вида или позиции не заменяет marker/receipt.

## Что ещё не готово

- Обычный путь размещения пока не создаёт этот durable-проект: текущий проект создан явным QA-сценарием.
- Туманv11 ещё не подключён к оставшимся частям; дом/native-prefab визуал, наклоны/масштаб/recontact/FPS требуют проверки.
- Возврат оплаченного при отмене, общий ресурсный склад, содержимое/крепления/admin restore, сервер/remote не завершены.
- Recovery ограничен прежним Intent, однозначным объектом и сохранившимися стеками; надписи/варианты материала и стадия Observed при сбое требуют отдельного восстановления. Неопределённый исход не повторяется и не возвращает ресурсы автоматически.
- Проверены обработчики и состояние, а не физический E/raycast, UGUI-мышь, HUD или полная перезагрузка процесса после достройки. Полный релизный сценарий не принят.
- `verify` skill отсутствует: использованы перечисленные сборки/проверки/независимый обзор.

**Текущая граница:** строим дом без подготовки основания. Землю подключит EarthWorks позже; отмена BuildWorks не должна менять рельеф. Все14блоков цели остаются в живом списке.
