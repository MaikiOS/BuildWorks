# .133 — копирование уже проверенного источника

Исходники 0.19.133, checkpoint `5dfeaa2`. Не установлено: в тестовом профиле
остаётся QA0.19.132. [Её ручной сценарий](QA_0.19.132_RU.md) не изменился.

`CloneSources` создаёт отдельную изменяемую запись, сохраняя ссылку на уже
проверенный неизменяемый `BlueprintSourceDocument`. `ToGeometry` по-прежнему
сравнивает ID, формат, имя и текст; несовпадение требует повторного построения
и проверки ID. `FromGeometry` не изменён. Схема хранения, данные источника,
стоимость, размещение и серверные права не менялись.

На старом копировании воспроизведён отказ теста
`Source clone rebuilt evidence or shared mutable envelope`. Итоговый тест
проверяет раздельные изменяемые записи, общий неизменяемый разбор, отказ при
изменении любого из четырёх полей и корректное перепривязывание нового текста.

Диагностика `--catalog-timings`: две независимые пробы на временной копии
364 записей / 610822 деталей / 359 источников. Повторный `ImportCopy + Index`
после уже выполненной проверки источников: 370,605/379,393 мс до изменения,
45,012/47,110 мс после (среднее −87,7%). Холодное чтение и полная подготовка
каталога не ускорены: итоговая подготовка 871,202/944,935 мс против
833,622/943,973 мс. Пробы не являются складываемыми этапами операции.
Resolver тестовый; Unity, интерфейс, миниатюры и расход памяти не измерялись.

Общий файловый импорт CoffeeTable: ожидание worker 2445,640/2282,965 мс,
каталог после импорта 851,975/811,322 мс. Дополнительное ускорение общего
импорта не доказано. Первоначальный вариант с ранним удержанием разбора сырой
библиотеки дал 3375,919/3246,391 мс и исключён. Его логи сохранены отдельно
с `early-retention`; они не доказывают итоговый вариант. Причина замедления
(возможная нагрузка на сборщик мусора) не подтверждена профилировщиком памяти.

Host25185596, localization933, isolation/preflight. Оба повторных независимых
