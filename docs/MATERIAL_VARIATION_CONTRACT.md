# Material variation contract

[Русский](MATERIAL_VARIATION_CONTRACT_RU.md) · [Current evidence](CURRENT_STATUS.md)

`BlueprintMaterialState.Supports` resolves actual host prefab capability. A null material seed follows ordinary behavior; a supported nonnegative RandMatSeed may be applied. Invalid/unsupported state is not silently restored. Foreign/unknown fields remain archived with provenance, not a claim of visual/behavior recovery.

Native placement creates fresh object identity and applies only supported constructive properties. Signs/construction choices are distinct from wear/fuel/inventory/admin state. The editor, thumbnail, ghost and placed result must use the same supported material choice. A reload of the house alone is not independent acceptance of every material variant.

Host review refines conservative file inspection before import choices. Export reports unsupported state and never promises another mod will consume BuildWorks extensions. Full material coverage on modded prefabs/native timing/network remains open. Earlier host binding/placement failures remain in [the original contract history](MATERIAL_VARIATION_HISTORY_206.md).
