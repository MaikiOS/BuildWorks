## Концептуальная обложка

`images/buildworks-hero-concept.png` создана специально для GitHub-страницы BuildWorks встроенным генератором изображений OpenAI. Она объясняет идею точного строительства и не является игровым скриншотом.

Финальный prompt:

```text
Wide GitHub repository hero for an original Valheim construction mod: a Nordic timber hall on a stone foundation at sunrise, translucent amber blueprint grid, snap points, XYZ transform gizmo and a repeated array of beams. Original fantasy game concept art; darker negative space on the left; no people, text, logos, watermark or copied game UI/assets.
```

## Снимки интерфейса

`editor-select.png`, `editor-transform.png`, `editor-array.png`, `editor-contour.png`, `editor-catalog-blueprints.png`, `editor-outliner.png` и `editor-settings.png` получены из автоматического Unity Workbench BuildWorks 0.19.33. Это реальные состояния реализованного интерфейса, но не доказательство поведения внутри Valheim.

Игровые изображения F9, индексного молотка и последовательной установки следует добавить после ручного smoke 0.19.33, чтобы публичная документация не закрепляла старые дефекты.
