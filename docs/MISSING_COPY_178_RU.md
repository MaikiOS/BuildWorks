# Копии у отсутствующей детали — .178

По подтверждению Ostrix инструмент создаёт копии выбранных доступных деталей. Оригинальные ID, положения, повороты и родители не меняются. «Совместить» сохраняет отсутствующую запись; «Заменить» удаляет только её. Новая выбранная группа содержит только копии. Один Undo отменяет подтверждённую операцию, Redo возвращает те же ID.

Использован существующий InsertBlueprint: отдельное выбранное поддерево с исходными данными, новыми ID и восстановленными связями групп/pivot вставляется одной транзакцией. Предпросмотр строится на копии документа и не двигает оригинальные визуалы. Независимые опоры/точки привязки документа не размножаются вместе с выбранными стенами. Целый чертёж из каталога по-прежнему переносит свои опоры/точки. Данные/форматы и стоимость строительства не менялись.

Локальная гизма новой группы ориентируется по её скопированной опорной детали. Для каталога явно назначается опора: PrimaryPartId либо первая деталь. Проверены primary после первой строки и отсутствие primary. Центр известной рамки совмещается с центром видимых копий, неизвестная рамка допускает только записанное начало координат/поворот; точная форма отсутствующей модели не восстанавливается.
