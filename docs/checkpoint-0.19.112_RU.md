# .112 — чертежи из одной детали

Native18/portable8 принимают одну деталь. Пустые документы запрещены;
native<=17/portable<=7 сохраняют прежний минимум2. Поля и смысл масштаба не менялись:
зафиксированный baseScale и относительный scale остаются раздельными.

Изменение проходит через разбор внешнего файла, сохранение редактора, захват/
workspace в мире, активацию/разрешение деталей и renderer-only призрак.
Требования нескольких точек для цепочек/контуров сохранены. У единственного
крепления виден предмет при скрытом native-frame, включая batched overlay.

Прошли: normal/QA0/0, GeometryTests, полные StoreTests/корпус353, HostContract,
локализация862/LocalizationTests, полный QASaveIsolation, EditorBridge,17 проверок
настоящей Session в Unity, dotnet format, DeploymentChecks, Unity Workbench276.
Новые проверки: исходник, native18/portable8, legacy17/7, обновление двух деталей
до одной, XYZ/поворот/baseScale, надпись, группа/центр, опора/привязка, import/export,
атомарный отказ пустому результату, неизвестная основа масштаба.
Клики настоящих кнопок сохранения/метаданных и повторное чтение прошли.

Помощник verify отсутствует; используются прямые проверки и независимый
correctness/ponytail обзор. Первые отказы выявили старые ожидания версии/минимума,
неверное ожидание относительного scale вместо baseScale и Save за пределами
возвращённого маленького GameView; тесты исправлены без ослабления проверок и raycast.

Это условие для копии без отсутствующих деталей, а не готовый выбор исключения.
M02 остаётся частичным. Готовый файл: QA_0.19.112_RU.md.

не подтверждены. QA .112 установлена штатным скриптом в TerrainRamp-1.0-Test,
SHA `BBF449755DC3F156D212B38375EF25B960C524E51C136D95590E4AF2FB84A424`.
Все48 QA файлов и библиотека сохранили прежние пути/контрольные суммы.
