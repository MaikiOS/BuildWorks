# .192 — короткая проверка надписи

Начальное состояние: установленная .192, прежний QA-мир/персонаж через Thunderstore → TerrainRamp-1.0-Test → Modded. Версию установки сверить с живым списком. Для этой серии материалы, рецепты и стенд не требуются: строительство и reload Codex проверит отдельно с подготовленными ресурсами. Ранее принятые масштаб, камера и отсутствие дубликатов повторять не нужно.

Файл: **02-sign.blueprint**, карточка **TEST 02 Sign**. [Открыть папку контрольных файлов](<C:/Users/nfspr/AppData/Roaming/Thunderstore Mod Manager/DataFolder/Valheim/profiles/Default/BuildWorks/artifacts/Blueprints-for-import/BuildWorks-tests>). Исходник содержит стену и табличку с текстом **BuildWorks: Привет, Ostrix!**, масштаб обеих записей1/1/1. Файл26 специально задаёт неравномерный масштаб1,5/0,5/2,25 и проверяет десятичные запятые; его деформация не является образцом обычной таблички.

1. Молоток → «ЧЕРТЕЖИ» → «Импорт файла». Открыть указанную папку, выбрать02-sign.blueprint, подтвердить проверку и «Подтвердить импорт». Найти полученную собственную карточку TEST 02 Sign.
2. Открыть «РЕДАКТИРОВАТЬ», приблизиться к табличке. Ожидается читаемый текст на той же табличке, а не отдельно в пространстве. Изменить масштаб всей детали по одной оси, отменить Undo: надпись следует её форме и возвращается вместе с ней. Сохранить отдельную копию через «Сохранить как…», открыть повторно.
3. В каталоге выбрать «ОБНОВИТЬ ПРЕВЬЮ». На маленькой плитке буквы могут быть слишком малы для чтения; модель должна оставаться видимой, без чёрного прямоугольника вместо текста. Читаемость самой надписи оценивать во вьюпорте редактора из пункта2.
4. Выбрать «РАЗМЕСТИТЬ», выйти из каталога и осмотреть призрак, не нажимая ЛКМ. Надпись видна на табличке и перемещается/поворачивается с ней; нет наложения стандартного текста. Отменить размещение, снова выбрать чертёж: призрак возвращается без пропавших деталей или зависшего ввода.

Признаки ошибки: текст появляется только после строительства; отсутствует/дублируется; висит отдельно от доски; после масштаба чрезмерно размыт или превращается в сплошную заливку; сама модель исчезает; закрытие призрака портит обычные таблички. При ошибке указать название файла, версию BuildWorks и место: редактор, миниатюра или призрак. Параметры UGC платформы ради теста менять не нужно.

Отдельно остаётся [серия автозамены .191](MANUAL_QA_191_RU.md), которая входит в .192. Оплаченное строительство/reload автоматически преобразованного Forest Hut и таблички — следующая подготовленная игровая проверка Codex, не поручение добывать материалы вручную.
