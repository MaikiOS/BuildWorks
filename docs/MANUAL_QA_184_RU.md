# Ручная очередь .184 — серверная библиотека и сохранность копий

[English](MANUAL_QA_184.md) | **Русский**

Установлена QA0.19.184.0. Запуск только Thunderstore → TerrainRamp-1.0-Test → Modded → прежний QA-мир. Игру запускаешь ты, когда удобно. Локальная модель и автоматическое управление выключены. Эта серия не требует материалов или строительства стенда.

Прежние принятые масштаб/камера/snap не повторяются. Непроверенная [групповая очередь .183](MANUAL_QA_183_RU.md) остаётся актуальна и на .184.

.184 читает прежние файлы и сохраняет native23/portable12; .183 новые файлы не прочитает. Для будущей сетевой серии устанавливать .184 на обеих сторонах.

## Исходник

Batch-183 — `artifacts/Blueprints-for-import/BuildWorks-tests/Batch-183` (локально, не поставляется): `01-floor.blueprint` → BW183 Floor, одна деревянная деталь. Импортируй только его, открой в редакторе → «Сохранить как…» → имя `QA184 Floor` → подтвердить сохранение. Если такая собственная карточка уже есть, используй её; новые копии без необходимости не нужны.

Другие исходные библиотеки — `artifacts/Blueprints-for-import` (локально, не поставляется). Они сами в каталог не добавляются.

## 1. Публикация и отмена

Исходное состояние: собственная сохранённая карточка QA184 Floor; запомни число карточек N. Серверная библиотека нового QA-мира сначала пустая. В локальном мире его владелец имеет серверные полномочия; это не проверка прав удалённого игрока.

1. Молоток → «Чертежи» → выбери QA184 Floor → «Серверная библиотека». В редакторе вход: каталог чертежей → «Сервер».
2. Проверь имя выбранного сохранённого локального чертежа в нижней строке. «Опубликовать выбранный».
3. В обзоре нажми «Отменить подготовку». Ожидается пустой серверный список и N личных карточек.
4. Повтори подготовку, оставь «Все игроки» → «Подтвердить серверную операцию».
5. Должна появиться одна серверная запись с одной деталью и ревизией1. Выбери строку: она подсвечена, полное имя/категория/публикатор/ревизия видны справа.

Ошибка: запись до подтверждения, новые личные карточки от публикации, начавшееся строительство, зависший экран или необъяснённый отказ. При отказе пришли текст; многократно публиковать одну запись не нужно.

## 2. Личная копия и открытый черновик

Исходное состояние: серверная запись ревизии1. QA184 Floor открыт в редакторе; сдвинь деталь и не сохраняй.

1. Каталог → чертежи → «Сервер» → выбери серверный QA184 Floor → «Получить личную копию…».
2. Дождись обзора состава. Закрой до «Сохранить личную копию»: N карточек, черновик/сдвиг/Undo должны остаться.
3. Повтори получение → «Сохранить личную копию» → «В каталог».
4. Появляется ровно одна личная копия сохранённой серверной версии. Получение не строит её и не заменяет твой несохранённый черновик.
5. Закончи/отмени черновик обычным способом. Открой полученную копию: состав и положение совпадают с сохранённой опубликованной версией, а не со сдвигом из несохранённого черновика.

Ошибка: потеря черновика/Undo, новая карточка после отмены, две копии от одного подтверждения, перенос несохранённого сдвига в серверную копию.

## 3. Обновление, удаление и перезапуск

Исходное состояние: серверная запись ревизии1 и отдельная полученная личная копия.

1. Измени и сохрани QA184 Floor, например поверни деталь. В серверном окне проверь выбранный локальный источник и выбери прежнюю серверную строку.
2. «Обновить серверный» → обзор → «Подтвердить серверную операцию». Ожидается та же запись с ревизией2, а не ещё одна строка.
3. Штатно выйди, вновь войди в тот же QA-мир через Modded. Серверная запись ревизии2 и личные копии должны сохраниться.
4. «Удалить с сервера» → «Отменить подготовку»: запись остаётся.
5. «Удалить с сервера» → «Подтвердить серверную операцию»: серверная запись исчезает. Личные карточки/чертежи и ранее построенные объекты остаются.

Ошибка: исчезновение после перезапуска, изменение старой личной копии при обновлении сервера, новая серверная запись вместо ревизии2, удаление личных карточек.

## Что этой серией не доказать

Для «Все игроки»/«Администраторы», запрета публикации обычным игроком, отзыва прав, reconnect и dedicated restart нужен отдельный host+remote сценарий с модом на обеих сторонах. Один локальный QA-клиент не подтверждает сетевые права. Эти проверки остаются в очереди; сейчас второй компьютер настраивать не требуется.

Объединение происхождения вставок, Undo/Redo/Save/Save As, конфликт и лимит16 проверены автоматически на реальном контроллере и файлах. Не создавай вручную16 серверных записей ради повторения CPU-отказов.

Личные автофайлы для передачи — `share` (локально, не поставляется). Серверные файлы — `server` (локально, не поставляется) разделяются по UID мира. Не редактируй ZIP/ACL вручную: это не пользовательский способ назначения прав.
