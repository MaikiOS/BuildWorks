# BuildWorks 0.19.33 alpha

Дата сборки и автоматической проверки: 11 сентября 2026 года.

## Главное изменение

Редактор теперь ставит одиночную деталь на фактическую поверхность её видимой mesh-геометрией. Это устраняет прежнее поведение, при котором скос, крыша или мебель могли наполовину оказаться под сеткой.

- ray редактора возвращает точную normal выбранного треугольника;
- Q/E совмещает выбранную исходную точку детали с курсором;
- подсказка Q/E показывает номер и направление точки;
- мебель и декор без vanilla snap points получают семь editor-only точек;
- новый Array всегда начинается в `УПАКОВАТЬ / БЕЗ ЗАЗОРА`, 2×1;
- `ПО ДЛИНЕ` остаётся отдельным явным режимом;
- Apply Array остаётся одной операцией Undo.
