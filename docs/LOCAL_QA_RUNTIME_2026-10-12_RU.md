## Исправление скрипта перед вводом

Свежий native DescribeInventory содержит `frame=<номер> stacks=...`. Старый
guard сравнивал весь текст и принимал новый кадр за изменение предметов.
Удаляется только точный начальный `frame=[0-9]+ `; counts/названия/instance ID
и остальные строки продолжают сравниваться. Регрессия проверяет изменение
только кадра, изменение количества/строк; полный подставной цикл теперь меняет
frame на каждом наблюдении. Четыре CPU-теста прошли после правки.
Добавлено событие model_started для доказуемой остановки во время inference.
Это только Python/журнал; новую DLL устанавливать не требовалось.
