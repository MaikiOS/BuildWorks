# E09 — камера внутри постройки

2026-10-09. Исходники и автоматические проверки; ещё не установлено.
В `TerrainRamp-1.0-Test` остаётся QA0.19.116, SHA256
`867E5E474A3C1B335500E47F1B2DC3A6250AC1FAA36E6D92E766E904F33DCF3A`.
Valheim, миры и saves не запускались и не менялись.

В меню **Камера** добавлены **Внутри постройки**, **Вернуться к обзору** и
скорость0.1–30м/с. Вход начинается с текущего положения, без телепортации.
Положение и углы внутренней камеры отделены от обычного обзора: можно летать
внутри, затем точно вернуть прежние положение, ориентацию и проекцию.
Режим всегда перспективный, ближняя граница видимости0.02м уменьшает обрезание
близких поверхностей. Камера свободная, без тела и столкновений со стенами;
это инструмент редактора, не управление персонажем и не admin-режим.
Изменения камеры не редактируют чертёж и не записываются в его формат.
Скорость живёт в текущем сеансе контроллера; постоянная настройка на диске не заявлена.

| Состояние | Действие | Результат / выход |
|---|---|---|
| Обычный обзор | Камера → Внутри постройки | Независимая перспектива, видимый индикатор режима |
| Внутри | Удерживать ПКМ | Курсор захвачен, прицел в центре области просмотра |
| Навигация | WASD, Q/E, мышь; Shift | Движение/осмотр, вниз/вверх, ускорение×3 |
| Навигация | Колесо | Меняется скорость, а не прежняя дистанция обзора |
| Выбрана деталь | Во время ПКМ нажать ЛКМ | Деталь добавляется в чертёж по показанному превью из центра; Undo работает |
| ПКМ отпущена | Курсор / интерфейс | Можно выбирать детали и кнопки; размещение снова следует указателю |
| Окно / текст / потеря фокуса | Прерывание | Полёт останавливается и курсор освобождается; внутренний вид остаётся |
| Выход | Камера → Вернуться к обзору | Восстановлены прежние вид, проекция и ближняя граница |

Escape сохраняет приоритет отмены размещения/действия и закрытия открытого окна;
это не безусловный выход из режима. «Вписать всё/выбранное» возвращает обычный
обзор и выполняет кадрирование. Закрытие/выгрузка/отключение используют существующую
очистку редактора и восстановление прежнего состояния курсора. Мировые права,
стоимость, размещение молотком, сетевые операции и предметы этим режимом не меняются.

## Проверка Ostrix — только после новой установки

Сейчас не выполнять: QA.116 не содержит режима. Сначала записать новую
установленную версию/SHA. Запуск только Thunderstore → `TerrainRamp-1.0-Test`
→ **Modded**, тестовый персонаж/мир `BW_QA_43d3719a`. Мировая стройка и
материалы для этой проверки не нужны: всё происходит в редакторе.

Готовый файл:
`C:\Users\nfspr\AppData\Roaming\Thunderstore Mod Manager\DataFolder\Valheim\profiles\Default\BuildWorks\tests\fixtures\metadata\21-camera-room.buildworks.json`.
Карточка **QA E09 Interior Camera**: четыре `woodwall`, пол/потолок `wood_floor`,
одна группа **QA room**. Это заготовка для редактора, не доказательство
устойчивости или привязок построенного дома.

1. Каталог редактора → **Импорт файла** → файл21 → **Подтвердить импорт** →
   карточка **QA E09 Interior Camera** → **РЕДАКТИРОВАТЬ**. Запомнить обычный вид.
2. **Камера** → **Скорость внутри, м/с**: `0.5` → **Внутри постройки**.
   Появляется индикатор; камера не прыгает. Удерживать ПКМ, двигаться WASD,
   Q/E до помещения. Мышь меняет взгляд, Shift ускоряет. Отпустить ПКМ:
   курсор доступен, положение камеры сохраняется.
3. Подлететь к стене/потолку; медленно осмотреть детали вблизи. Пройти камерой
   сквозь стену допустимо. Колесо при ПКМ меняет скорость, не масштаб чертежа.
4. Нажать Tab, чтобы открыть каталог редактора, выбрать обычную
   деревянную деталь. Удерживать ПКМ: прицел и превью идут из центра области
   просмотра. Нажать ЛКМ — добавленная деталь совпадает с превью. Отпустить ПКМ,
   Escape отменяет повторное размещение, Ctrl+Z убирает добавленную деталь.
5. Открыть меню «Камера»: движение прекращается. Закрыть Escape — внутренний
   вид остаётся. Переключиться в другое приложение и обратно: нет застрявшего
   захвата мыши или самопроизвольного движения.
6. **Камера** → **Вернуться к обзору**: прежние положение/углы/проекция
   возвращаются. Повторно войти, полетать и закрыть редактор: в игре
   восстанавливается обычное управление. Черновик можно закрыть без сохранения.

Признаки ошибки: нет кнопки/индикатора, огромная скорость в маленькой комнате,
деталь ставится в стороне от превью, смена режима перемещает сам чертёж,
модальное окно не останавливает полёт, мышь остаётся захваченной, обзор не
восстанавливается, Escape теряет прежнюю отмену. Сетевая игра, мировые ресурсы,
reload мира и физическое управление пока не подтверждены этим этапом.
