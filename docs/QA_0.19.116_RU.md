# Проверка .116: исходная позиция не смещает чертёж

Файл: `tests/fixtures/placement-headers/15-source-position.blueprint`.
Найти: Default → BuildWorks → tests → fixtures → placement-headers.
Имя: **QA116 Source Position**. Собственная синтетическая стена, чужие моды не нужны.

Исходное состояние: установленная QA .116, изолированный QA персонаж/мир. Игра
запускается только при разрешённой серии через Thunderstore → TerrainRamp-1.0-Test
→ **Modded**. Основные миры не использовать. Этот документ сам не разрешает запуск.

1. Каталог редактора → «Импорт файла», выбрать точный файл → «Подтвердить импорт».
   Ожидается одна деталь, без предупреждения о неизвестном состоянии этих заголовков.
2. «РЕДАКТИРОВАТЬ». Стена находится в пределах рабочей сцены; она повёрнута на45°
   по Y и имеет исходный масштаб XYZ2/.5/1.25. Сохранённые мировые -2480.165 /
   400.894 /126.336 и128.572° не должны дополнительно переместить/повернуть её.
3. «СОХРАНИТЬ» → закрыть редактор → снова «РЕДАКТИРОВАТЬ» сохранённую копию.
   Положение/форма/размер совпадают. Ошибка: стена пропала, переместилась далеко,
   повторно повернулась, изменила масштаб или получила неизвестное состояние.

Native стройка, точное списание, reload мира и multiplayer этим редакторским
сценарием не подтверждаются. Для них действует отдельная подготовленная серия.
