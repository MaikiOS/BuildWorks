# BuildWorks 0.19.34 alpha source baseline

**English** | [Русский](release-notes-0.19.34_RU.md)

## Changes

- English-first runtime localization with a complete Russian catalog;
- 596 stable localization keys covering the current BuildWorks UI;
- language-neutral logic and persistence identifiers;
- localized generated copy, Array, and Contour names;
- contributor-facing architecture, localization, and verification documentation;
- formatting and embedded-resource verification gates.

## Verification

Release 0/0, localization 596/596, Geometry 104, Store, EditorBridge 3, WorldLayout 10, HostContract, and Unity Workbench 81/81 — PASS.

## Known limitations

- 0.19.34 has not been installed or run in Valheim;
- English and Russian manual UI smoke tests are pending;
- the pending 0.19.33 placement and Array gameplay scenarios remain open;
- save/reload, multiplayer, import/export, persistent operations, and procedural curves have not passed their final gates.
