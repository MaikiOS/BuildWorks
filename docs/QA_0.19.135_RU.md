## 1. Границы масштаба

Используй уже импортированную карточку TEST16 Supported XYZ Snap из файла
16-supported-snap.blueprint. Если нужна папка: C:\Users\nfspr\AppData\Roaming\Thunderstore Mod Manager\DataFolder\Valheim\profiles\TerrainRamp-1.0-Test\BepInEx\config\BuildWorks\test-fixtures.
РЕДАКТИРОВАТЬ → СОХРАНИТЬ КАК… → QA135 Scale. Выбрать один пол, «Оси: детали».
Отключить «Сохранять пропорции», задать X=950%, ПРИМЕНИТЬ. S → X → мышь вверх
до предела и дальше → Enter. Ожидается1000% по X, действие подтверждается без
подбора точного положения мыши; Y/Z не меняются. Ctrl+Z возвращает950%.
Для минимума задать X=2%, ПРИМЕНИТЬ; S → X → мышь вниз за минимум → Enter:
остаётся1%, подтверждение работает. Esc до подтверждения отменяет действие.
СОХРАНИТЬ, закрыть/открыть копию: выбранная форма остаётся.
Ошибка: максимум400%, отказ Enter после overshoot, изменение других осей,
прыжок при подтверждении или потеря масштаба после открытия.
Сочетания X+Z и непрерывный перенос курсора пока не реализованы.

## 2. Совмещение с сохранением рамки

Исходник: C:\Users\nfspr\AppData\Roaming\Thunderstore Mod Manager\DataFolder\Valheim\profiles\Default\BuildWorks\tests\fixtures\replacement\14-replace-missing.buildworks.json.
Карточка QA115 Replace Missing. Нужна исходная запись с QA missing target и двумя
стенами. Если запись уже изменена, импортируй файл и сохрани отсутствующую деталь.
РЕДАКТИРОВАТЬ → СОХРАНИТЬ КАК… → QA135 Position.
Выбрать QA missing target, затем с Ctrl обе стены. В правой панели рядом с
«Заменить» нажать «Совместить»; в меню Space полное название —
«СОВМЕСТИТЬ С ОТСУТСТВУЮЩЕЙ».
Предпросмотр: центр двух стен совмещён с центром красной рамки; поворот задан
по первой своей детали, размеры стен сохранены. Грани совпадать не обязаны:
размеры/форма замены не подгоняются автоматически. ОТМЕНА вернёт исходные стены.
Повторить → ПРИМЕНИТЬ: все три записи и рамка остаются; выбраны свои стены,
их можно довести гизмой. Ctrl+Z/Ctrl+Y отменяет/повторяет всё совмещение.
СОХРАНИТЬ, закрыть/открыть копию: рамка и новые позиции остаются.
Затем выбрать только QA missing target → «Совместить» → «Открыть каталог» →
«Детали» → woodwall → ПРИМЕНИТЬ. Новая стена совмещается с рамкой, missing остаётся.
Ненужную missing-запись удалить отдельно обычным Delete, когда подгонка закончена.
Ошибка: исчезает рамка, меняется масштаб, известные центры расходятся, отмена
оставляет копию, Undo требует нескольких действий либо после открытия потеряна запись.
При неизвестных размерах инструмент честно совмещает только начало координат
и поворот, а не обещает совмещение объёма неизвестной модели.

Сохранить как, камеру, Space и уже принятый расход/возврат ресурсов не повторять.
