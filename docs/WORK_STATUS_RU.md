# Требования и состояние BuildWorks

Обновлено: 2026-10-17. [Полная текущая матрица](CURRENT_STATUS_RU.md) отделяет исходники, автопроверки, установку, Valheim, приёмку Ostrix и сеть. [Контракт](../PROJECT_CONTRACT_RU.md) сохраняет полный объём; [ROADMAP](ROADMAP_RU.md) задаёт очередь. Исторические отметки «установлено/следом» не являются текущим состоянием.

| Требование | Статус / оставшаяся работа |
| --- | --- |
| Аудит, источники доказательств и живой список | Выполняются; SocratiCode green34425, переиндексации нет. Текущие файлы/receipts важнее старых заявлений |
| Внешний/свой чертёж→редактор→стройка→reload | Один Forest Hut (28) деталей доказан; весь поддерживаемый корпус/сеть не принят |
| Формат/конвертация/экспорт | Частично: store24/portable13, явные границы источников и потерь; неизвестное не считается восстановленным |
| Missing-записи/замены/метаданные | Реализованы записи/рамки/копии; неизвестные модель/размеры честно обозначаются, нужен широкий регресс |
| Редактор/опоры/привязки/камера/масштаб | Многие случаи приняты; парные оси/перенос указателя/повёрнутые системы и новые UX-случаи остаются |
| Предметы/хранилища/права | Основы есть, долговечное завершение/возврат/сбои/все держатели/admin/сервер не завершены |
| Объёмное выделение | Частично; регулируемые границы/ручные поправки/координаты/актуальный состав требуют завершения |
| Постоянный проект/колышек/табличка | Не реализован полный путь; временная очередь его не заменяет |
| Утверждённый v11 | .211:кэш/shader автопроверки прошли, native shader49/25/48 FPS при замороженном расчёте. Пользовательский дом исчезает с ошибкой recovery readback; исправление/полный FPS/вид/сервер открыты |
| Тяжёлая цепочка/плановая стройка/EarthWorks | Замеры всех стадий и игрового порога впереди; полноценная EarthWorks-интеграция отложена |
| Русский UI/проверки/снабжение | Каталоги1104 ключа и отдельные разрешения/кейсы проверены; полная ручная/сетевая серия не закрыта |
| Категории/автофайл/Share/группы/серверный каталог | Файловые функции есть, часть .197 проверена; полный batch/host+remote/передача игрок→игрок открыты |

Подробные прежние результаты, неудачи, хеши и полная последовательность сохранены в [истории до .206](WORK_STATUS_HISTORY_206_RU.md). Текущие пункты для Ostrix — [живой список](LIVE_CHECKLIST_RU.md). Новые ручные проверки недостроя пока не выдаются: дом и табличка ещё не подключены.
