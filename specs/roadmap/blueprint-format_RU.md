# Текущий контракт формата и обмена

[English](blueprint-format.md) · [Границы приёмки](../../docs/CURRENT_STATUS_RU.md)

Схема основной библиотеки **35** (`CompositeBlueprintStore`); переносимая схема **23** (`BlueprintExchangeFormat`). Номер схемы не равен версии пакета.


> Source candidate0.19.324 uses native35/portable23 for optional Group.sourceDocumentId/sourceLayerId; old34/22 reject field presence and planner sources. InstalledQA323 remains34/22. Planner JSON file import is independently accepted (03FDFFFA);planner paired export/UI accepted in Workbench scope (8D691B88); original consumer/game remain open.

| Вход/выход | Поддерживаемая граница |
| --- | --- |
| Импорт `.blueprint` | Заявленные PlanBuild/Infinity-подобные текстовые диалекты; конечные позиции/кватернионы/XYZ-масштаб, только разобранные заголовки/секции/состояние |
| Импорт `.vbuild` | Распознанные BuildShare-диалекты; расширение не доказывает поддержку |
| Импорт `.buildworks.json` / ограниченного ZIP | Проверенные внутренние документы/записи, пределы деталей/вложенности/байтов; не произвольные модели |
| Одиночный экспорт | Внутренний JSON, полный BuildWorks ZIP или ограниченный PlanBuild `.blueprint` с review потерь/native companion |
| Групповой экспорт | Полный BuildWorks ZIP; выбор/категория/имя/папка |
| Экспорт BuildShare | Не реализован |

Store/editor/share сохраняют prefab ID, стабильные ID записей, TRS/XYZ-масштаб, группы, надписи, свободные опоры/свои snap-точки, поддерживаемые материалы/предметы, зависимости, версии/происхождение и неизвестный исходник. Исходные файлы не меняются. Архивирование не означает понимание/восстановление; неизвестные обязательные структура/TRS явно отклоняются. В чужие форматы не пишутся неподдерживаемые расширения BuildWorks.

Prefab scale/вложенные TRS отделены от относительного масштаба. Исходные мировые Coordinates/Rotation — происхождение, не повторное преобразование локальных строк. Missing хранит трансформацию/известные метаданные; при неизвестных размерах/моде честный маркер. Полностью missing запрещён; копия без missing не меняет источник. Автоматически мигрирует только проверенный точный `wood_wall_roof → wood_wall_roof_a`, без похожих имён.

Для содержимого независимые настройки импорта/экспорта/стройки. Понимание данных не выдаёт admin-права. У новых объектов новая сетевая идентичность. Native reload и совместимость с чужим модом проверяются для конкретного поведения.

Пределы: документ50000 деталей; обычный interactive/editor512, изолированный QA/Unity editor50000; своя библиотека32 карточки/12 категорий/100000 деталей суммарно. Ограничения байтов/вложенности/архивов/памяти сохраняются. Точные проверки — в константах исходников; максимумы не гарантируют FPS.

[Происхождение/условия корпусов](../../docs/EXTERNAL_CORPUS_REGISTER_RU.md) · [История формата](blueprint-format-history-206_RU.md). Поддержка всех внешних файлов/неизвестных диалектов не обещается.


Запись исходника `world-capture-v1` — ограниченный, строго проверяемый, пассивный TSV: известный UID мира либо явное unknown, исходные мировые позиция/кватернион, MVID игрового модуля и версия BuildWorks. Этот frame не преобразует локальные детали и не даёт полномочий. Запись сохраняется через store/editor/copy/portable. Для неё нужны native28/portable16; подмена версии на27/15 отвергается. Старые27/15 без неё читаются без выдумывания отсутствующего происхождения.
