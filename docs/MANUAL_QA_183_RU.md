# Ручная очередь .183 — групповой импорт и экспорт

2026-10-16: Codex проверил ограниченный путь в Valheim .197: обзор/отмена, категории, экспорт с исключением, обратный импорт и logout/reentry. [Границы и доказательства](BATCH_NATIVE_197_RU.md). Повторять его без причины не нужно; несохранённый черновик/Undo, полный перезапуск процесса и весь мышиный ввод ещё не проверены. Тест добавил7 внешних карточек и одну явную личную копию Walls; итог14, это учтённые тестовые результаты.

Запускай через Thunderstore → **TerrainRamp-1.0-Test → Modded**, только прежний QA-мир. Эти проверки работают с каталогом и файлами; добывать материалы и строить стенд не нужно. Принятые проверки масштаба, камеры, Save As и snap повторять не требуется.

## Где взять чертежи

Готовый небольшой набор Batch-183 — `artifacts/Blueprints-for-import/BuildWorks-tests/Batch-183` (локально, не поставляется) содержит:

- `01-floor.blueprint` → **BW183 Floor**, 1 деталь, категория BW183 FLOORS.
- `02-walls.blueprint` → **BW183 Walls**, 2 детали, категория BW183 WALLS.
- `03-two-documents.zip` → **BW183 ZIP Floor** и **BW183 ZIP Walls**, 1 и 2 детали.
- `04-deliberately-invalid.blueprint` → намеренно повреждённый файл; ожидается явное предупреждение и пропуск.

Это собственные технические примеры BuildWorks. Другие внешние библиотеки — `artifacts/Blueprints-for-import` (локально, не поставляется) — BiomeBlueprints-1.0.3, 2v2t-5.0.0 и Previous-imports; происхождение/условия сохранены рядом. Доступность файла не доказывает поддержку каждого его объекта.

## 1. Выбор группы и отмена до подтверждения

Исходное состояние: запомни число карточек N. Открой молоток → «Чертежи» → «Импорт файла»; в редакторе вход находится в каталоге чертежей.

1. «Изменить путь» → вставь полный путь папки Batch-183 из ссылки → «Открыть».
2. Нажми «Выбор группы», отметь все четыре файла. Затем «Импорт файла».
3. Дождись обзора: четыре документа для импорта и предупреждение о `04-deliberately-invalid.blueprint`.
4. Открой «Документы и категории»: видны четыре отдельных документа, включая два из ZIP. Закрой всё кнопкой «Закрыть» до «Подтвердить импорт».

Ожидается: в каталоге остаётся N карточек; исходники на месте. Ошибка: молчаливый пропуск повреждённого файла, зависшее окно, карточки до подтверждения.

## 2. Импорт с разными категориями

Исходное состояние: N карточек; те же четыре исходных файла.

1. Повтори выбор группы из пункта 1. В общей категории введи `BW183 GROUP`.
2. «Документы и категории» → у **BW183 Walls** введи `BW183 CUSTOM`. Остальные поля оставь пустыми. «Применить выбор».
3. Проверь список и предупреждение. Нажми «Подтвердить импорт»; дождись результата, затем «В каталог».
4. Найди **BW183 Floor**, **BW183 Walls**, **BW183 ZIP Floor**, **BW183 ZIP Walls**. Открой каждый в редакторе; сравни числа деталей 1/2/1/2. Не сохраняй случайные изменения.

Ожидается: N+4 карточки; Walls в BW183 CUSTOM, остальные в BW183 GROUP. Выбрана первая новая карточка. Повреждённый файл не создаёт карточку. ZIP даёт два документа. Категория — ярлык каталога, отдельную папку она не создаёт.

Ошибка: карточки исходных файлов вместо четырёх документов, потеря индивидуальной категории, лишние/пустые детали, новая копия при простом открытии каталога. Если не видишь все записи отчёта, прокрути его видимой полосой.

## 3. Групповой экспорт, исключение документа и обратный импорт

Исходное состояние: четыре карточки из пункта 2. Для повтора используй новое имя ZIP: существующие файлы не перезаписываются.

1. Выбери любую из них → «Экспорт файла» → «Выбор группы». Отметь только четыре карточки BW183. Формат группы — полный BuildWorks ZIP.
2. Задай имя `QA183-roundtrip` и папку через «Изменить путь»/«Открыть» либо оставь папку exports.
3. «Экспорт файла» → «Документы и категории» → сними отметку **BW183 ZIP Walls** → «Применить выбор».
4. «Подтвердить экспорт». Дождись результата, скопируй полный путь. Должен появиться `QA183-roundtrip.zip`; само экспортирование карточек не добавляет.
5. Закрой окно. Через «Импорт файла» выбери именно этот ZIP, задай общую категорию `BW183 ROUNDTRIP`, подтверди импорт.
6. В новой категории ожидаются три карточки: Floor, Walls, ZIP Floor; 1/2/1 детали. Сравни вид и форму в редакторе с исходными.

Ожидается: исходные четыре карточки и файлы сохранены; только явный обратный импорт добавляет три копии. Исключённый документ отсутствует в ZIP. Полный путь результата читается и копируется.

Ошибка: экспорт добавил карточки, изменил исходники, записал исключённый документ, ZIP не читается или потерял поддерживаемые данные. Совместимость этого ZIP с чужими модами не заявляется.

## 4. Черновик и повторный запуск

Исходное состояние: свой сохранённый чертёж открыт в редакторе.

1. Сдвинь деталь, не сохраняй. Через каталог открой групповой импорт, посмотри обзор, затем закрой до подтверждения.
2. Вернись к черновику: сдвиг и Undo должны остаться.
3. Заверши/отмени черновик своим обычным способом. Выйди штатно и снова открой прежний QA-мир через Modded.
4. Проверь карточки, категории и состав из пунктов 2–3. Само открытие каталога новых копий не создаёт.

Ошибка: потеря черновика/Undo, пропавшие сохранённые карточки или самопроизвольные дубликаты после запуска.

## Где хранятся результаты

Импортированные архивы — `imports` (локально, не поставляется) — один новый архив на подтверждённую группу, с документами и точными исходниками. Экспорт по умолчанию — `exports` (локально, не поставляется). Автофайлы собственных сохранённых чертежей — `share` (локально, не поставляется). Импортированные карточки появляются в share после собственного сохранения/«Поделиться»; исходная внешняя библиотека сама туда не копируется.

Отмена во время записи, отсутствие частичного ZIP, конфликт имени, изменение источника, общие лимиты и независимые настройки хранилищ/креплений проверены автоматически. Не повреждай свою библиотеку ради повторения этих отказов. Игровое строительство, предметы, тяжёлые дома и сеть остаются отдельными открытыми проверками полной цели.
