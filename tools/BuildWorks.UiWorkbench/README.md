# BuildWorks UI Workbench

Изолированный стенд проверки реального редактора BuildWorks 0.19.9 в Unity
`6000.0.61f1`. Требуется активная лицензия Unity Editor. Установка другой версии
Unity не требует обновления этого проекта.

## Запуск проверок

Из корня `BuildWorks` в PowerShell 7:

```powershell
.\scripts\Capture-UiWorkbench.ps1
```

Скрипт собирает Geometry и копирует девять исходных компонентов продукта в
стенд с проверкой SHA-256. Проверки выполняют настоящий Controller, View,
Scene, манипулятор, хранилище и их события TMP/uGUI в Play Mode. Минимальные
замены игрового хоста позволяют обойтись без запуска Valheim. Ручное нажатие
Play в пустой сцене само по себе не является приёмочной проверкой.

Результаты сохраняются в `artifacts/ui-runtime`: протоколы проверок, хеши
исходников и 45 PNG — выбор, трансформация, массив, контур и каталог на
1920×1080, 2560×1440 и 3440×1440 при масштабе интерфейса 100/120/140%.
Команда проверяет свежесть снимков и успешное завершение исполняемых сценариев;
ошибка компиляции, проверки или тайм-аут возвращают ошибку команды.

Проверяются выбор геометрии без Read/Write, отверстия и заслонение, вложенное
выделение, контуры подсветки, размеры зон клика манипулятора, закрепление точки,
изменение масштаба через настоящие поля, живое перестроение модификаторов и
отмена, сохранение/повторное открытие, освобождение ресурсов.

Отдельный сценарий `ActualDividerAcceptance` читает исходный локальный bundle
Valheim и проверяет `ashwood_decowall_divider` перед `woodwall` в расположении
сохранённого примера пользователя. Его результаты — `actual-divider-check.txt`,
`actual-divider-selected.png` и `actual-divider-hover.png` в том же каталоге.
Игровые prefab используются только как источник геометрии: игровые компоненты
не запускаются. Локальные игровые ресурсы нельзя включать в поставку мода.

Старая демонстрационная реализация `BlueprintEditorWorkbench.cs` сохраняется
для исторической диагностики и не запускается автоматически. Её прежние
15 PNG из `artifacts/ui-workbench` не подтверждают поведение продукта 0.19.9.

## Границы проверки

Стенд не заменяет игровой запуск: обычный молоток, затраты ресурсов, права,
сохранение мира и обмен состоянием между клиентами здесь не исполняются.
Тесты не изменяют игровую библиотеку чертежей и не устанавливают DLL в профиль.
Управление и отдельные игровые сценарии перечислены в
`specs/blueprint-editor-0.19.9-checklist.md`.
