# Импорт .180 — этапы, результат и восстановление

Реализовано: полоска этапов, русское название текущей операции и прошедшие секунды.
Это последовательность этапов, не прогноз времени. После успешного импорта окно
закрывается, каталог молотка/редактора выбирает реальную опубликованную карточку
по ID и importSource и открывает нужную страницу. В многочертёжном архиве выбор
первого документа обозначен до подтверждения.

Редактор сохраняет открытый несохранённый документ, выделение и Undo. После
закрытия окна его старый фокус восстанавливается прежде перехода к результату.
Если каталог уже закрыт, игрок умер или окно закрыли в процессе, автоматического
возврата нет. Запущенная запись продолжается в фоне; результат остаётся в каталоге.

Сбой до атомарного сохранения ZIP не объявляется успехом. Сбой подготовки каталога
после сохранения показывает, что файл уже записан, и предлагает только
«Обновить каталог». Повтор перечитывает существующий архив и не создаёт второй.
Чужая более новая операция не принимается за результат старого окна.
