# QA0.19.140 — экспорт PlanBuild

Сценарий подготовлен; запускай после отметки об установке .140 в
[живом списке](LIVE_CHECKLIST_RU.md). Только TerrainRamp-1.0-Test через Thunderstore →
Modded; существующие BW_QA_43d3719a. Основные миры/персонажи не нужны.
Ресурсы и строительство для этой проверки не требуются.

1. В каталоге редактора найди уже импортированную карточку TEST16 Supported XYZ Snap.
   Исходник `16-supported-snap.blueprint` лежит в
   `C:\Users\nfspr\AppData\Roaming\Thunderstore Mod Manager\DataFolder\Valheim\profiles\TerrainRamp-1.0-Test\BepInEx\config\BuildWorks\test-fixtures`.
   Повторный импорт не нужен, если карточка уже есть.
2. Меню плитки → «Экспорт файла». Введи имя `QA140`, оставь предложенную папку exports.
   Переключи формат дважды: BuildWorks JSON → ZIP + BuildWorks → PlanBuild.
3. «Экспорт файла» → окно «PlanBuild: проверка потерь». Прокрути текст: указаны оба
   файла, данные, которые не восстановит PlanBuild, и ограничения состояния/модов.
   «Назад к параметрам файла» возвращает настройки без нового набора QA140.
4. Повтори переход и нажми «Экспорт с потерями». Ожидается «Экспорт сохранён» с
   полным путём новой папки QA140. «Скопировать путь» копирует этот путь целиком.
   В папке должны быть QA140.blueprint и QA140.buildworks.json.
5. Повтор с тем же именем отказывает, сохраняя оба файла. Через «Назад к параметрам
   файла» можно выбрать QA140b или другую папку. Закрытие до подтверждения набора
   не создаёт. Если путь слишком длинный, выбери «Документы» и короткое имя;
   сообщение об ограничении260 не должно оставлять частичный набор.
   Во время записи закрытие/ESC отменяет ещё не опубликованный набор; если запись
   успела завершиться, готовая папка остаётся. Частичная папка с одним файлом — ошибка.
6. В каталоге → импорт только QA140.buildworks.json из папки результата. Это
   полная копия; проверь сохранённые детали/масштаб/опоры. Затем при желании импортируй
   отдельно QA140.blueprint: это намеренно упрощённая версия, опоры и данные объектов
   из второго файла в ней отсутствуют. Две вручную импортированные версии — две
   отдельные карточки; это не самопроизвольное дублирование.
7. Повтори открытие окна экспорта через каталог молотка. Формат и список потерь
   должны быть доступны и читаться, окно закрывается верхней кнопкой «Закрыть».

Ошибка: запись до подтверждения; исчезновение исходной карточки; перезапись;
пустой/непрокручиваемый список потерь; пропавший полный backup; сырые ключи сообщений;
необъяснимое изменение масштаба после импорта полной копии.

Эта серия подтверждает игровой интерфейс и обмен файлами. Настоящее размещение
экспорта чужим PlanBuild, его ресурсы/устойчивость/reload/сеть — отдельная проверка;
другой мод автоматически не устанавливается. Прежнюю принятую стройку16, камеру,
Space, Save As и расход/возврат ресурсов повторять из-за .140 не нужно.
Открытые проверки мыши/границ/пар осей/«Совместить» остаются в QA_0.19.137_RU.md.
