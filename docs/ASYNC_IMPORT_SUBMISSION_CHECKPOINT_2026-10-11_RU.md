## Изменение

TryImportReviewed по-прежнему проверяет актуальность обзора и явный выбор
отсутствующих деталей. Затем вызывающий поток снимает свежие масштаб, поддержку
материала и копии метаданных каждого уникального prefab, уровень мира и чистый
hash callback. Значения берутся заново при подтверждении, даже если callback
и объект мира не сменились. Не используется предположение, что старый обзор
гарантирует неизменность данных prefab.

В существующем importTask выполняются PrepareForHost, исключение явно выбранных
missing и применение метаданных. Если PrepareForHost вернул исходный документ,
делается ImportCopy до изменения метаданных. Snapshot metadata и отдельная копия
для каждой детали исключают разделяемую изменяемую запись. Источник не меняется;
правила fallback sourceId/sourceVersion остаются прежними.

ValidateMissingReview больше не декодирует RetainedContents: решение использует
контекст, наличие prefab, количества и пустые документы. Все эти проверки
сохранены; обычный обзор по-прежнему анализирует содержимое.

bool TryImportReviewed означает запуск операции. Ошибка нормализации теперь
доставляется через ImportError, как остальные ошибки worker, до файловых операций.
Окно сохраняет подробную причину, очищает завершившийся обзор и блокирует повторное
подтверждение до «Назад к параметрам файла» и нового обзора. Исправлена замена
причины ошибки сообщением stale на следующем Tick.

ReadImportBytes/сравнение точного источника, path/size/count/version/scale guards,
общий бюджет, будущий порядок каталога, проверка ZIP и атомарный File.Move прежние.
Форматы, ресурсы, предметы, права и сетевое состояние не менялись.

## Проверки и измерение

- Store: удерживаемый worker после возврата TryImportReviewed; один свежий снимок
  на повторяющийся prefab; caller-only callbacks; изменение mutable metadata после
  снимка не влияет на результат; raw/нормализованный источник не меняется;
  свежие метаданные следующей операции; ошибка масштаба без ImportDirectory.
- Lightweight missing review сохраняет все поля решения и происхождение, не
  вызывает hash для декодирования содержимого. Старые changed/unloaded/empty
  отказы и сохранность исходника проходят.
- Настоящий Tick с CPU-подменами: успех, причина отказа несколько кадров,
  заблокированное повторное подтверждение/доступный Back, stale и две стадии.
  Старый error branch падает, исправленный проходит; red/green сохранены.
- Полный Store +353 BiomeBlueprints:351 совместим по формату/2 явно блокированы.
  Это не доказательство наличия prefab, стройки или восстановления в игре.
