# Управление BuildWorks

[English](CONTROLS.md) | **Русский**

Нижняя строка редактора и HUD показывают только действия, доступные в текущем состоянии. Таблица ниже — справочник, а не замена контекстным подсказкам.

Под вьюпортом выделена область для клавиш режимов, действий инструмента,
истории/групп/скрытия и камеры. Ввод, меню и перетаскивание показывают свои
подсказки. Высота панели параметров сохранена.

## Индексный молоток

| Действие | Управление |
| --- | --- |
| Выбрать карточку | ЛКМ |
| Добавить/убрать из избранного | СКМ |
| Страницы | Q/E или PageUp/PageDown |
| Открыть действия чертежа | удержать ПКМ, навести, отпустить |

## Редактор: выбор и видимость

| Действие | Управление |
| --- | --- |
| Добавить/убрать из выбора | Ctrl/Shift + ЛКМ |
| Скрыть выбранное | H |
| Изолировать выбранное или группу | Shift+H |
| Показать всё кроме выбранного | Ctrl+H |
| Показать всё | Alt+H |
| Просвечивание перекрывающих деталей | F7 или кнопка `Просвет F7` у вьюпорта |
| Удалить | Delete или СКМ по детали |

Просвечивание изначально выключено и действует только в редакторе. Невыбранные
детали, мешающие выборочным лучам к видимому выбору, становятся полупрозрачными
силуэтами; выбранное остаётся непрозрачным. Камера, смена выбора и выключение
возвращают исходные материалы редактора. Скрытие, выбор мышью, исходные prefab,
сохранённый чертёж и мир не меняются.

В режиме контура (C) наведение на связанное ребро опоры показывает только синюю
линию, ЛКМ создаёт призраки. Отмена, Esc, G/Q и удаление исходника очищают оба.

| --- | --- |
| Орбита | СКМ + движение |
| Панорама | Shift+СКМ + движение |

## Трансформация

| Действие | Управление |
| --- | --- |
| Переместить/вращать | тянуть стрелку или кольцо ЛКМ |
| Копировать движением | Alt + тянуть стрелку |
| Временный магнитный move | Ctrl + тянуть |
| Ограничить опору осью | X/Y/Z |
| Точный numeric scrub | тянуть значение; Shift — точнее, Ctrl — быстрее |

## F9 в мире

| Действие | Управление по умолчанию |
| --- | --- |
| Включить/выключить precision layer | F9 |
| Зафиксировать ghost | F10 |
| Освободить курсор для ручек | удерживать левый Alt |
| Общий frame чертежа вместо мировой опоры | удерживать N |
| Undo / Redo | Ctrl+Z / Ctrl+Y |
| Отмена | Esc |

F9, F10, Alt, N, положение HUD и масштаб UI изменяются в конфигурации BepInEx.
