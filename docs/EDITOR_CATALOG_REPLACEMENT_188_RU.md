# .188 — явная замена загружаемой детали из каталога

В настоящем QA-мире .187 импортирован Forest Hut из `hs_blackforest_hut.blueprint`: 28 деталей. Через реальные кнопки редактора изменён поворот двери, проверены Undo/Redo, «Сохранить как…» и повторное открытие собственной копии `QA187 Forest Hut`. Пройдены 96 шагов; шаг размещения отказал до призрака. Строительство не начиналось, 64 Wood остались в инвентаре.

Причина: четыре записи используют `wood_wall_roof`. Prefab загружается, но его нет среди всех 609 записей текущего Hammer. В списке есть отдельный `wood_wall_roof_a`; доказанного правила автоматического соответствия нет. Ни похожее имя, ни одинаковая цена не доказывают одинаковую модель. Старый prefab не объявляется отсутствующей моделью, исходный файл не меняется.

## Изменение

Одна выбранная видимая незаблокированная деталь теперь допускает «ЗАМЕНИТЬ» или «СОВМЕСТИТЬ» из каталога, даже если её модель доступна. Пользователь явно выбирает новый prefab либо чертёж и проверяет предварительный результат. Замена удаляет только выбранную запись; совмещение оставляет её. Существующая многовыборочная замена отсутствующей записи своими деталями сохраняет оригиналы и создаёт копии.

Подтверждение заново проверяет документ, revision, выделение и доступность источника. Неподходящее выделение показывает инструкции, но не открывает замену. Отмена не меняет историю; одна операция отменяется одним Undo. Совмещение известного объёма загруженной модели использует её фактические видимые bounds. Неизвестные размеры не угадываются.

Стоимость, рецепты, станции, native Hammer eligibility, серверные права и сетевые идентификаторы не изменены. Ручная замена — редактирование чертежа, а не объявление автоматической поддержки старого prefab.

## Следующая игровая проверка

Только прежний QA-мир и персонаж через Thunderstore → TerrainRamp-1.0-Test → Modded. Использовать уже созданную карточку `QA187 Forest Hut`, категория `QA187`; повторно импортировать источник не нужно.

1. Открыть «РЕДАКТИРОВАТЬ». Найти четыре записи с ID `wood_wall_roof` через поиск дерева.
2. Выбрать одну запись → «ЗАМЕНИТЬ» → «Открыть каталог». Явно выбрать `wood_wall_roof_a` как тестовый вариант; сравнить форму, положение и полный поворот, прежде чем нажать «ПРИМЕНИТЬ».
3. Сначала проверить «ОТМЕНА»: старая запись остаётся, новых деталей нет. Затем подтвердить замену, проверить Undo/Redo. Повторить осознанный выбор для остальных трёх записей, без автоматической подстановки по имени.
4. «СОХРАНИТЬ», выйти и повторно открыть: 28 деталей, поворот двери 15° сохранён, выбранные ID и позы совпадают с подтверждённым результатом.
5. Проверить карточку и «РАЗМЕСТИТЬ». Если другая деталь недоступна или форма не совпадает, зафиксировать точный ID/причину и остановиться до списания ресурсов.

Полный оплаченный дом и reload выполняются отдельным продолжением после проверки призрака и штатной стоимости; приведённые пять шагов не являются доказательством строительства.
