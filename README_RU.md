# BuildWorks

**Русский · [English](README.md)**

BuildWorks расширяет молоток Valheim точным строительством, каталогом чертежей и отдельным редактором. Импортируйте поддерживаемую постройку, измените её настоящие детали, постройте по штатным правилам и сохраните поддерживаемые трансформации после reload. Свои постройки можно выделять и редактировать.

![Концепт BuildWorks](docs/images/buildworks-hero-concept.png)

**Текущие исходники / изолированная QA: 0.19.217.** Последний публичный пакет: [0.19.37 alpha](https://github.com/MaikiOS/BuildWorks/releases/tag/v0.19.37-alpha), исторический prerelease. Его ZIP не содержит новые функции исходников. Новый публичный бинарный релиз не опубликован.

**QA .217 установлена: точный перенос скорости v11 GPU↔RAM.** Unity28/7:2688 отсчётов/196 точных сравнений,8 контактов; ValheimQA8/8: резерв94478116 байт, roundtrip2457600 half-значений, инвентарь неизменен/мост восстановлен. Строгий backend не включён в Building; следующий шаг — настоящий дом/визуальный v11/FPS, затем табличка. [Доказательства и границы](docs/CHECKPOINT_217_RU.md).

## Возможности

- Категории молотка, поиск, недавнее, избранное и карточки чертежей.
- Редактор с деревом, группами, независимыми опорами, своими точками привязки, Undo/Redo и внутренней камерой.
- XYZ-перемещение/вращение, масштаб1–1000% по компонентам, числовой ввод, одна/две оси, инструменты Array и Contour.
- Поддерживаемый импорт `.blueprint` / `.vbuild`, экспорт с проверкой потерь, категории, «Сохранить как», удалить/скрыть, автофайлы, «Поделиться» и групповой обмен.
- Missing-записи сохраняют трансформации; явное совмещение создаёт копии, оставляя оригиналы. Неизвестная модель не выдумывается.
- Штатная стройка за ресурсы с проверками выживания. Дом Forest Hut (28) деталей и точный reload проверены; это не доказательство всех импортов и сети.
- Английский базовый и русский игровые каталоги.

В дальнейшем BuildWorks развивает редактируемые сборки и повторения, строительство по направляющим и собственные адаптивные детали. Полная последовательность — в [дорожной карте плагина](docs/ROADMAP_RU.md).

## В работе

Текущий приоритет: **v11 → целый недостроенный дом → постоянный колышек/табличка → материалы/продолжение/отмена/возврат/reload**. [.212](docs/FOG_RECOVERY_212_RU.md) исправляет воспроизведённую межкадровую ошибку, из-за которой дом исчезал после прохода. В игре дом прошёл туда и обратно без исчезновения; Ostrix не принял растворение/возврат и скорость прохода. Полный вид/скорость дома и постоянная табличка открыты.

Хранилища/крепления/admin restore, прямая передача игрокам, полная серверная приёмка, удобное объёмное выделение и тяжёлые постройки не завершены. Обычный предел интерактивного редактора/размещения512 деталей; изолированная QA проверяет более высокие пределы. Произвольные огромные/модовые постройки не объявлены рабочими.

## Зависимости и сборка

Нужны Valheim и BepInExPack Valheim5.4.x. Jotunn, TerrainRamp и EarthWorks не являются runtime-зависимостями. Проверенная версия host — в [статусе](docs/CURRENT_STATUS_RU.md).

Для .NET SDK нужны локальные игровые assemblies; игровые DLL в Git не добавляются:

```powershell
dotnet build .\src\BuildWorks\BuildWorks.csproj -c Release `
  -p:ProfileRoot="C:\path\to\BepInEx-profile" `
  -p:ValheimManagedDir="C:\path\to\Valheim\valheim_Data\Managed"
dotnet run --project .\tests\BuildWorks.GeometryTests\BuildWorks.GeometryTests.csproj -c Release
```

Разработческая установка разрешена только штатным скриптом в TerrainRamp-1.0-Test. Основной автоматический QA — локальный ValheimQA по `../ValheimQA/RUNBOOK_RU.md`: GABS запускает этот профиль напрямую, проверяет изоляцию, выполняет сценарий, штатно выходит и восстанавливает мост. Постоянное разрешение от18.10.2026 заменяет старое требование Modded для этих тестов. Не прерывать игру пользователя; сбросы/новая выдача/посторонние изменения мира/другие профили/сеть требуют своего объёма разрешений. Локальный стенд не входит в GitHub-поставку.
