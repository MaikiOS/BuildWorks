# 295 — локальный grid-кандидат; остановленные контроли и диагностика

22.10.2026. Локальный editor-only кандидат учитывает настоящие full-depth texel centres, сохраняя прежние допуски, исходные веса low S/T и точный full fallback. Новая ветка допустима только при совпадении четырёх raw depth с исходными выборками; guards отклоняют неверные размеры, вырожденные span, нечисловые значения и экстраполяцию. Shader292 и установленный bundle не менялись. **295 не принят и не установлен.**

Два GPU-запуска остановились на одной предпосылке теста: `old plane must really fall back3440x1440`, до первого native-size вызова нового кандидата. Замена source RT на Texture2D не помогла. Повторения прекращены, оба неудачных лога сохранены; successful native-size coverage не заявляется.

Отдельный AddressAudit измерил восемь заранее выбранных точек (четыре угла8×8 и3440×1440), ARGBFloat. Clone неизменного292 записал фактические CameraUV/depth/четыре taps/strictTotal/weights/uniforms; обе исходные маски тоже сохранены. Compiler0, exit0, настройки возвращены, временный clone удалён. В native-size(2,2) CameraUV правильный, Y-переворот опровергнут; fullDepth32,7168999 совпал с tap11, strictTotal0,5625. Старый shader законно принял пиксель. Ошибка предпосылки — Point boundary/фактическая адресация, а не доказанная поломка295. Следующий шаг — исправить fixture на основании измеренных координат, сохраняя baseline/допуски и независимые отрицательные контроли.

По измеренным taps Astra выбрал новый контроль (1,1): у него тот же lowBase=(0,0), поэтому адреса не угадываются заново, но full depth уже не совпадает с tap. Предсказание старого shader расходится примерно на0,123м при допуске0,033м. Контроль честно получил старый fallback; затем новый295 тоже вернул fallback: **`point-grid rescue3440x1440` FAILED**. Маски обе magenta сохранены до assertion. Это уже ограничение кандидата, а не прежняя ошибка предпосылки: вычисленный floor(lowUV×size) не гарантирует адрес исходной Point-выборки на границе. Точная raw-проверка остаётся; причина её отказа требует отдельного доказательства. Простого расширения допуска не будет. Перед этой проверкой исправлена единственная ошибка helper C#CS0136 (повторное имя pixel); её лог также сохранён.

295 не переносится в игру. Ни ускорение, ни полный четырёхсторонний визуальный gate не подтверждены. Обычный туман .267 остаётся прежним и отклонённым владельцем по скорости/виду. Старший read-only обзор выбирает следующий способ детерминированной выборки; очередной такой же native A/B не запускается.

Решение Astra для следующего отдельного кандидата: общий целочисленный адрес full-depth texel из low pixel для обоих проходов; low интегратор принимает готовую глубину, сохраняя ray UV/jitter, а прежний wrapper/full fallback остаётся. Composite использует те же адреса и прежние S/T weights; нельзя переиспользовать S/T старого292. Новых RT/настроек нет. Это ещё не реализованное исправление. Риск — отсечение low ray может сместиться на один full texel у тонкой геометрии. Нужны настоящий low-pass clipping/odd/Point+Bilinear/negative controls и matched wall, затем один фиксированный native contact A/B; без ускорения или при дефекте краёв ветка отклоняется. Точный guard, отвергнувший295, отдельно не измерен.
