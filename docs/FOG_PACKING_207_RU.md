# Упаковка тумана .207

[English](FOG_PACKING_207.md) · 2026-10-17 · [Текущее состояние](CURRENT_STATUS_RU.md)

В .207 убран общий XY-размер блоков атласа. Детали занимают собственный размер с прежними фильтрующими границами; ограниченный поиск раскладки выполняется только при изменении размеров. Разрешение, shader/compute, текстуры и формулы v11 не менялись. Новые смещения принимаются только после успешного выделения атласа.

Проверено в Unity:

- Сохранённые размеры28 деталей Forest Hut:126955800 байт вместо193460292; лимит128 МиБ не повышен. Это допуск раскладки по метаданным, не рендер реального дома.
-100 воспроизводимых случайных наборов: детерминизм, отсутствие пересечений/обрезки, границы устройства/памяти; ошибочные и переполняющие значения отклоняются.
- Прежняя серия4 кадров/3 источников: точное содержимое полей, разница порядка0, парного рендера7,67e-7, границ0, непрозрачного перекрытия0, переноса6,06e-5. Удаление и очистка сохраняют независимость источников.
- Успешная раскладка A → искусственный отказ выделения B → прежние смещения/текстуры и повторный кадр A без изменений. Реальное исчерпание GPU-памяти не провоцировалось.

Normal/QA0 ошибок/0 предупреждений на окончательной сборке; host, QA control, QA isolation, локализация1104 и независимые correctness/Ponytail PASSED/Ship прошли. При промежуточной параллельной проверке возник MSB3026 из-за временного чтения DLL; после завершения проверки чистая пересборка прошла. Проверка Junction потребовала разрешения sandbox и затем прошла.

Установлена QA0.19.207.0 только через защищённый Deploy-TestBuild в TerrainRamp-1.0-Test; хеш совпал.143 прежних защищённых файла сохранили SHA/точное время;130 файлов вне test-fixtures также сравнены непосредственно до/после установки. Игру не запускали. Нового публичного бинарного релиза нет.

**Открыто:** полные расчётные поля этих28 деталей всё ещё требуют272384000 байт при бюджете98304000. Контактный набор в пробной позиции также превышает бюджет. Упаковка не решает эту отдельную задачу. Следующее — ограниченные контактные области без потери невосстановленного тумана, затем реальный дом/память/FPS и постоянный проект с табличкой. Последний native визуал остаётся .203/две стены.

Локальные доказательства, не поставляются: `artifacts/fog-house-207` и сохранённый Unity-отчёт внутри него. Сохранённые размеры не гарантируют размеры фактически запечённой геометрии prefab. Поиск раскладки ограниченный, не оптимальный для всех возможных построек.
