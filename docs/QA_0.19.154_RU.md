сначала установит одну проверенную QA не ниже .154 через Deploy-TestBuild и
назовёт версию. Запуск: Thunderstore → TerrainRamp-1.0-Test → **Modded**, существующие
QA-мир/персонаж. Основной мир не использовать. Материалы не нужны: эта серия
проверяет новое предупреждение и импорт/экспорт, не повторяет принятую стройку.

Файл: `27-planbuild-snap-tail.blueprint` в папке
`C:\Users\nfspr\AppData\Roaming\Thunderstore Mod Manager\DataFolder\Valheim\profiles\Default\BuildWorks\tests\fixtures\planbuild`.
Собственный безопасный чертёж: одна `woodwall`, две точки XYZ, дополнительные
столбцы с намеренно неизвестным текстом. Карточка: **QA154 Snap Fields**.

1. Исходное состояние: каталог редактора открыт, версия>=.154. «Импорт файла» →
   указанная папка → файл27 → «Импорт файла». Дождаться обзора. Ожидание: одна
   постройка, явное сообщение «у 2 строк дополнительные поля не используются»,

   сведения. Ошибка: отказ fields/transform, текст обрезан без прокрутки, данные
   объявлены полностью восстановленными либо предупреждения нет.
2. «Подтвердить импорт» → закрыть окно → QA154 Snap Fields → «РЕДАКТИРОВАТЬ».
   Ожидание: редактор открывается, одна обычная стена. Ошибка: пустая карточка,
   потеря стены, лишние модели, сообщение о неизвестных полях как об ошибке
   позиции. Координаты/порядок двух точек уже проверены CPU; визуальная/world

3. Закрыть редактор → меню той же карточки → «Экспорт файла». Выбрать **PlanBuild**,

   Ошибка: предупреждение исчезло либо заявлено восстановление неизвестных полей.
