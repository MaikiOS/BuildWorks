## Что изменилось

- Высота объёма: перетаскивание обновляет границы без полного поиска на каждом движении; завершение drag, колеса, сброса или текстового ввода обновляет настоящий состав выделения. Зажатое значение без изменения не запускает пересчёт. Отказ некорректных границ сохраняет прежний выбор и необходимость повторного обновления.
- В новом строгом fog runtime источник остаётся владельцем точного GPU-состояния до явного удаления. Простой больше не пропускает входные отсчёты и не уничтожает остаточную скорость; восстановление формы само по себе не освобождает источник. Допуск числа источников ограничен вместимостью пула заранее.
- ReleaseOnly-проверка Unity теперь записывает отказ и исходную ошибку даже при отказе до запуска редактора. Новый универсальный ReleaseRegression сохраняет отдельные старые receipts .214.

## Ручные проверки — когда будет удобно

Повторять автоматический тест высоты не требуется. Если проверяешь удобство: в прежнем QA-мире с имеющимся Hammer открой «ЧЕРТЕЖИ» → «ВЫБРАТЬ В МИРЕ», обведи часть существующего дома, перетащи «Верх» или «Низ» и отпусти. Граница должна двигаться во время drag, список/подсветка — обновиться после отпускания; колёсико и завершённый ввод высоты тоже обновляют состав. Ошибка: прежние детали остаются выбранными после завершения или выбор очищается при неверных границах. Закрой режим без сохранения/строительства. Для этой проверки новый файл чертежа не нужен.
