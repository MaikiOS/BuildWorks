# Установка альфы .329

[English](INSTALL.md)

[Download / Скачать](https://github.com/MaikiOS/BuildWorks/releases/tag/v0.19.329-alpha)

Архив сохранён без пересборки; надписи private обозначают его первоначальную выдачу. Требуется существующий Valheim с BepInEx 5. Проверенный host: Steam build 26249040 / QA BepInEx5.4.23.6 / Unity6000.0.75f1. Совместимость с другими сборками отдельно не доказана.

1. Полностью закрой Valheim.
2. Открой папку нужного профиля с установленным BepInEx 5.
3. Скопируй старую папку BepInEx/plugins/Ostrix-BuildWorks ВНЕ любых plugins; отдельно сохрани конфиги и библиотеку чертежей.
4. Слей папку BepInEx из архива с папкой профиля, заменив четыре файла Ostrix-BuildWorks вместе. Оставь одну активную копию мода.
5. Конфиги, чертежи, миры и персонажей сохрани. Не переноси тестовый профиль, мост QA или isolation token.
6. Запусти свой modded профиль. В BepInEx/LogOutput.log должна быть одна загрузка BuildWorks 0.19.329. На втором ПК повтори установку в его собственный профиль.

ZIP SHA256: `3C91113CB4D601A843317DA251BB60BF191107EC5D7E15D74983279373934E41`.

## Обновление, данные и удаление

Закрой игру перед обновлением. Резервные копии храни вне plugins. Заменяй все четыре поставляемых файла вместе; не смешивай DLL. Valheim/BepInEx не включены. Для удаления убери только BepInEx/plugins/Ostrix-BuildWorks; существующие постройки/миры/персонажи не откатываются. Сохрани конфигурацию и библиотеку BepInEx/config/BuildWorks, включая blueprints.json и share. Откат бинарников может требовать соответствующей копии библиотеки. Не копируй QA-профиль, мост и токены.
