# Отложенная проверка нового выделения .150

**Сейчас не выполнять: установлена .146.** Сначала Codex должен установить одну
проверенную QA через `Deploy-TestBuild.ps1`, сверить DLL и назвать её версию.
После этого Thunderstore → `TerrainRamp-1.0-Test` → **Modded**, существующие
QA-персонаж/мир `BW_QA_43d3719a`. Основной мир не использовать.

Исходный стенд: уже принятый `TEST 16 Supported XYZ Snap`, исходный файл
`tests/fixtures/player-exchange/16-supported-snap.blueprint`, категория `BW TEST`.
Это2 опоры и2 пола. Используем имеющийся стенд; старое размещение/расход повторно
не проверяем. Если его нет или нет ресурсов, остановиться: Codex подготовит
стенд безопасно в отдельный разрешённый этап. Ничего добывать/строить вручную
для подготовки не требуется. Новый захват мира сам ресурсы не списывает.

1. Молоток → «ЧЕРТЕЖИ» → «ВЫБРАТЬ В МИРЕ». Должно быть «Режим: объём» и
   подпись плоскости Y. Сверху направить камеру вниз, протянуть ЛКМ площадь стенда
   вне панели. Ожидание: рамка, число выбранных и список деталей. Ошибка: обычное
   строительство вместо выделения, невидимая рамка, недоступная панель, исключение
   в логе. Сделать кадр с рамкой/панелью; её читаемость пока не утверждена.
2. По подписи Y вычислить низ/верх относительно плоскости. Изменить «Верх», чтобы
   полы оказались выше границы; нажать «СОХРАНИТЬ» до обновления. Ожидание: понятное
   требование «Обновить выделение», без сохранения старого списка. Нажать
   «Обновить выделение»: полы исключены, опоры остаются, если их origin внутри.
   Затем вернуть высоту и обновить. Ошибка: незаметное сохранение устаревшего
   выбора, неверный счёт, замена правила origin пересечением видимой модели.
3. Нажать строку [x]: она становится [ ], деталь исключается. Изменить верх и
   обновить: исключение остаётся. Нажать [ ]: деталь возвращается. Видимую деталь
   снаружи площади добавить кликом; Ctrl-клик исключает. Ожидание: ручные решения
   сохраняются. Ошибка: самопроизвольный возврат, пропажа строки, изменение мира.
4. Коротко кликнуть видимую высокую деталь при почти горизонтальном луче камеры.
   Ожидание: обычное ручное включение/исключение, без ошибки плоскости. Начать
   протягивание площади тем же лучом: допустим отказ с сообщением, предыдущий
   выбор остаётся. Ошибка: отказ короткого клика или очистка выбора при отказе.
5. Задать «Низ» выше «Верх», обновить. Ожидание: ошибка высот, прежний выбор
   сохранён, сохранение блокируется до исправления/обновления. Отменить с помощью
   «ОТМЕНА»: рамка/подсветка исчезают, игровой ввод возвращается. Ошибка: зависший
   курсор, оставшаяся подсветка, расход материалов или изменение деталей мира.
6. Повторно войти; переключить «Режим: объём» на «Режим: экранная рамка» и обратно.
   Ожидание: прежний способ доступен, панель не перекрыта, скрытые поля не держат
   ввод. Проверить обычное разрешение и уменьшенное окно, не менять основной мир.
   Страницы списка проверяем на подготовленной Codex большой площадке позже:
   вручную создавать десятки объектов не требуется.
7. Обновить пригодный объём → «СОХРАНИТЬ». Ожидание: новая карточка, детали мира
   остаются; открыть карточку в редакторе и сверить состав. Перезапустить QA-мир
   только в разрешённой серии: карточка снова открывается. Строительство копии,
   расход/отмена/reload и сеть — отдельные открытые проверки, не доказаны этим
   захватом. При незагруженных зонах должно быть явное число; оно не гарантирует,
   что все удалённые детали доступны.

Для каждого отказа: номер шага, версия, кадр панели и свежая ошибка лога. Повторный
захват полного незагруженного дома не ожидается; игрок должен загрузить нужную
область. Огромную постройку/сетевую сессию запускаем отдельным этапом с ресурсами
и подготовкой Codex, без вмешательства в основные сохранения.
