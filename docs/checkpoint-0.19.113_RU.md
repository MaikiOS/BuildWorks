# .113 — явная копия без отсутствующих деталей

Импорт и экспорт в собственные JSON/ZIP предлагают отдельную копию без недоступных
prefab. До подтверждения показаны исходный файл, точный ID и количество записей.
По умолчанию записи сохраняются; «Назад к параметрам файла» сбрасывает выбор.
Неизвестный мод не угадывается по имени объекта.

Доступность определяется наличием prefab в загруженном реестре, независимо от
рецепта и прав. Если реестр недоступен, исключение отключено. Перед записью
повторно проверяются контекст реестра и отсутствующие ID. При изменении требуется
повторное подтверждение. Если опустошится хотя бы один документ ZIP, весь импорт
отклоняется до публикации. Исходные bytes и доказательства источника сохраняются.
Прежняя картинка не прикладывается к копии с изменённым составом.

Трансформации и зафиксированный масштаб оставшихся деталей сохраняются. Все группы,
включая ранее пустые вложенные, опоры, anchors и пользовательские привязки остаются.
Очищаются только недействительные ссылки центра/основной детали или группы.
Независимые настройки хранилищ/креплений/стоек применяются к оставшимся объектам.
Остальное неизвестное состояние по-прежнему не восстанавливается.

Автоматически прошли: normal/QA (0 ошибок/предупреждений), GeometryTests,
StoreTests/353 исходника, HostContract, локализация 869/LocalizationTests,
QASaveIsolation, EditorBridge, WorldLayout 17 случаев настоящей Session,
dotnet format/whitespace, DeploymentChecks и Unity Workbench 300 снимков.
Настоящие UI-клики проверяют выбор по умолчанию, список ID/количество, сброс через
«Назад», отказ при изменении контекста, повторное подтверждение и редактор одной детали.

Первый независимый обзор остановил потерю пустых групп. Исправлено; добавлена
регрессия вложенных пустых групп, неизменности исходника и повторного чтения.
Исправления тестов закрывают редактор до повторного открытия и учитывают новые
ID у отдельной копии. Помощник verify отсутствует; нужны прямые проверки и обзор.
