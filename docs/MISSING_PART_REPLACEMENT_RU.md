# Совмещение и замена отсутствующей детали

[English](MISSING_PART_REPLACEMENT.md) · [Текущий статус](CURRENT_STATUS_RU.md)

Отсутствующий prefab остаётся отдельной записью с сохранённой трансформацией. Известный локальный bounding box показывается с этой трансформацией. Без размеров маркер сообщает неопределённость; начало координат не обязательно центр модели.

1. Откройте неполный чертёж. При необходимости включите фильтр missing в дереве; группы сохраняются.
2. Выберите одну missing-запись и свои детали для совмещения. Доступны совмещение и совмещение с заменой; доступные детали можно вставить из каталога.
3. Посмотрите превью. При известных рамках совмещаются центры геометрии и сохранённая ориентация; при неизвестных доступно только записанное начало/поворот. Точная поверхность не выдумывается. При нехватке исходных размеров можно дорегулировать вручную.
4. «Совместить» создаёт копии рядом с missing, сохраняя исходные детали и missing-запись. «Заменить» дополнительно удаляет эту одну missing-запись. Отмена ничего не меняет; подтверждение — один Undo. «Сохранить»/«Сохранить как» записывает результат.

Красная рамка — ориентир, не восстановленная модель. Копия без missing — явный выбор импорта; если доступных деталей не остаётся, конвертация запрещена. Нет случайной подстановки по имени. Автоматическая миграция только проверенного `wood_wall_roof → wood_wall_roof_a`, с исходным ID/происхождением.

Доказательства: [копии .178](MISSING_COPY_178_RU.md), [каталог .188](EDITOR_CATALOG_REPLACEMENT_188_RU.md). Весь корпус и все native случаи не приняты.
