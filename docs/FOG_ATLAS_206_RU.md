# Общий рендер нескольких источников v11 — .206

2026-10-16. Это ограниченный этап переноса эффекта, не готовый строительный проект.

`BlueprintFogVolume.RenderMany` сохраняет прежний путь для одной/двух деталей. Для большего числа `BlueprintFogAtlas` упаковывает независимые Shape/Smoke/Surface в три производные GPU-текстуры. Shader суммирует плотность и рассеяние в одной интеграции. У каждого источника сохраняются свои начало координат, время, капсула, цвет и состояние восстановления. Атлас не владеет исходными simulation и не списывает ресурсы.
