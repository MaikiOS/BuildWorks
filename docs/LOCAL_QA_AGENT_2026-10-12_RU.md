## Что реализовано

`scripts/Run-LocalQAAgent.py` выполняет локальный цикл без обращения к Codex на
каждом действии: состояние/кадр → модель → новое состояние → короткий native
ввод → проверка результата. Текущий сценарий только открывает и закрывает
инвентарь через Tab. Разрешены решения inventory/observe/stop; неизвестные и
лишние команды отвергаются. Нет передвижения, строительства, переноса предметов,
выдачи ресурсов, запуска игры или изменения сохранений из скрипта.

Транспорт повторно использует `Invoke-QAControl.ps1`; сетевой API только у
локальной Ollama. Перед каждым действием проверяются nonce, QA-мир, focus/ready,
stopRevision, тип UI, сводка инвентаря и конечные координаты (допуск15см). После действия
видимость инвентаря подтверждается `InventoryGui.IsVisible`, не самоотчётом модели.
Успех требует двух подтверждённых состояний: открыт, затем закрыт.

QA .164 добавляет stopRevision: любая остановка, включая F12 во время ожидания
модели, меняет номер. Старое решение отклоняется непосредственно игрой. Потеря
фокуса тоже останавливает сценарий. Физический ввод контролируется существующим
каналом во время batch; его обнаружение между batch отдельно не добавлено.

Один процесс исполнителя, lock от параллельного запуска, максимум90с. Таймаут,
ошибка, неизвестное состояние или вмешательство прекращают сценарий без повторного
нажатия. На ошибке запрашивается остановка; запрос остановки не считается её
подтверждением. Завершённые игровые действия не откатываются. Отчёт с JSONL и
кадрами: `artifacts/local-qa-agent/<время>-<ID>`. Файл stop.flag в этом каталоге
останавливает следующий шаг; немедленная игровая остановка — F12.

CPU: четыре теста, включая полный подставной цикл/остановку после модели/ошибку

## Первый игровой запуск

После подтверждения установки .164: Thunderstore → **TerrainRamp-1.0-Test → Modded**,
прежний персонаж и мир **BW_QA_43d3719a**. На безопасном ровном месте остановиться,
закрыть инвентарь/меню, оставить игру на переднем плане и сообщить «в QA-мире».
Не выдавать набор заново и не менять мир ради этого опыта.

Агент сначала проверяет loader/nonce/кадр, затем запускает:

```powershell
python.exe scripts/Run-LocalQAAgent.py --run
```

Ожидается: инвентарь открывается и закрывается, персонаж остаётся на месте,
сводка вещей не меняется, отчёт completed содержит обе свежие native квитанции.
Ошибка: окно не меняется, остаётся открытым, персонаж движется, предметы меняются,
сценарий продолжает работу после F12 или отчёт расходится с кадром. Нажать F12;
не повторять неизвестную команду. Проверка F12 во время модели — отдельный запуск.

Без игры: `--self-test` только CPU; `--probe-decisions` использует GPU и сохранённые
кадры, без игрового ввода. Переход к молотку/снапам требует следующего сценария;
текущий pilot не означает готового универсального игрового агента.
