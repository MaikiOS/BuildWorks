# 0.19.123 — точный поиск привязок молотка

Этап исходников, не установка. QA0.19.117 в TerrainRamp-1.0-Test остаётся
прежней; обе DLL сверены. Четыре больших импорта и все12 отказов ещё открыты.

## Что изменено

Только автоматический поиск локального игрока для большого призрака BuildWorks
использует пространственный индекс целей. Внешний штатный метод по-прежнему
собирает цели мира и перебирает исходные дочерние точки в исходном порядке.
Ручной выбор, индексы, сами точки и существующий поворот после native snap
сохранены. Дочерние объекты не удаляются и не сокращаются.

Два внутренних вызова перенаправлены узким Harmony-transpiler. Индекс строится
один раз внутри внешнего вызова; следующий вызов получает новые позиции целей.
Вложенные вызовы и исключения восстанавливают предыдущий контекст. Малые или
обычные призраки, другой игрок, сторонние патчи, неподдерживаемые данные/радиусы
используют штатный метод через delegate. Проверяется фактическая дистанция
Unity; при расхождении остаётся штатный поиск. Предел снимка целей50000.

Geometry использует общий существующий KD-индекс с отдельной метрикой
округлённого расстояния: порядок первого target/source, включённая граница
радиуса и native sentinel сохранены. Старый поиск по квадрату расстояния для
назначения точек деталям не изменён по результатам регрессий.
