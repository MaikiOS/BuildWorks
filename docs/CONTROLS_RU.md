# Управление BuildWorks

[English](CONTROLS.md) | **Русский**

Нижняя строка редактора и HUD показывают только действия, доступные в текущем состоянии. Таблица ниже — справочник, а не замена контекстным подсказкам.

Под вьюпортом выделена область для клавиш режимов, действий инструмента,
истории/групп/скрытия и камеры. Ввод, меню и перетаскивание показывают свои
подсказки. Высота панели параметров сохранена.

## Редактор: выбор и видимость

| Действие | Управление |
| --- | --- |
| Добавить/убрать из выбора | Ctrl/Shift + ЛКМ |
| Скрыть выбранное | H |
| Изолировать выбранное или группу | Shift+H |
| Показать всё кроме выбранного | Ctrl+H |
| Показать всё | Alt+H |
| Просвечивание перекрывающих деталей | F7 или Отображение → Просвечивание |
| Удалить | Delete |

Просвечивание изначально выключено и действует только в редакторе. Невыбранные
детали, мешающие выборочным лучам к видимому выбору, исчезают; выбранное остаётся
непрозрачным. Камера, смена выбора и выключение возвращают отрисовку. Только
активная скрытая snap-цель получает тонкий контур. Скрытие в документе, материалы,
исходные prefab, чертёж и мир не меняются; временная преграда не перехватывает выбор.

В режиме контура (C) наведение на связанное ребро опоры показывает только синюю
линию, ЛКМ создаёт призраки. Отмена, Esc, смена инструмента и удаление исходника очищают оба.

## Трансформация

G следует настоящей поверхности другой детали, исключая выбранные; без попадания
нет подтверждения, а не переход на далёкую сетку. P явно выбирает экранную плоскость.
R вращает в плоскости камеры до ограничения; S — равномерный масштаб. При этих
операциях XYZ выбирает ось, повтор меняет мир/локальные координаты, Shift+ось
исключает ось. Q/E на поверхности меняет точку, колесо — поворот. Enter/ЛКМ — одно
подтверждение, Esc — точная отмена. Камера приостанавливает/перебазирует preview.
Семейства постоянной Гизмы выбираются в меню Манипулятор; скрытые ручки не ловят
клики. Свёрнутые подсказки сохраняют заметную строку следующего шага.

| Действие | Управление |
| --- | --- |
| Переместить/вращать | тянуть стрелку или кольцо ЛКМ |
| Копировать движением | Alt + тянуть стрелку |
| Временный магнитный move | Ctrl + тянуть |
| Ограничить опору осью | X/Y/Z |
| Точный numeric scrub | тянуть значение; Shift — точнее, Ctrl — быстрее |

## F9 в мире

| Действие | Управление по умолчанию |
| --- | --- |
| Включить/выключить precision layer | F9 |
| Зафиксировать ghost | F10 |
| Освободить курсор для ручек | удерживать левый Alt |
| Общий frame чертежа вместо мировой опоры | удерживать N |

| Отмена | Esc |
