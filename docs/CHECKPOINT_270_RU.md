После saved credit автоматически выбирается существующий cleanup; при старте каждый project ID проверяется один раз, по одному за кадр. Сначала продолжается `CleanupIntent`, иначе первая credited запись без cleanup. Ещё не полученные Items не мешают очистке уже полученного prefix; `CreditIntent` блокирует очистку. Свежая выдача автоматически не подбирается. Ошибка/неясность убирает ID из очереди и сохраняет причину, без бесконечного повтора.
