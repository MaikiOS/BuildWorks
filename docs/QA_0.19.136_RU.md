## 1. Границы масштаба

Используй уже импортированную карточку TEST16 Supported XYZ Snap из файла
16-supported-snap.blueprint. Если нужна папка: C:\Users\nfspr\AppData\Roaming\Thunderstore Mod Manager\DataFolder\Valheim\profiles\TerrainRamp-1.0-Test\BepInEx\config\BuildWorks\test-fixtures.
РЕДАКТИРОВАТЬ → СОХРАНИТЬ КАК… → QA136 Scale. Выбрать один пол, «Оси: детали».
Отключить «Сохранять пропорции», задать X=950%, ПРИМЕНИТЬ. S → X → мышь вверх
до предела и дальше → Enter. Ожидается1000% по X, действие подтверждается без
подбора точного положения мыши; Y/Z не меняются. Ctrl+Z возвращает950%.
Для минимума задать X=2%, ПРИМЕНИТЬ; S → X → мышь вниз за минимум → Enter:
остаётся1%, подтверждение работает. Esc до подтверждения отменяет действие.
СОХРАНИТЬ, закрыть/открыть копию: выбранная форма остаётся.
Ошибка: максимум400%, отказ Enter после overshoot, изменение других осей,
прыжок при подтверждении или потеря масштаба после открытия.
Непрерывный перенос курсора пока не реализован.

## 2. Две оси XZ

В той же копии QA136 Scale выбрать пол с исходным масштабом100% по всем осям,
«Оси: детали». S → X → Z: обе кнопки осей подсвечены. Двигать мышь вверх внутри
окна: меняются X/Z, Y остаётся100%. Ввести1.5 → Enter: X/Z=150%, Y=100%.
Ctrl+Z отменяет одной операцией; Ctrl+Y возвращает. Снова Ctrl+Z для исходной формы.
G → X → Z → мышь: движение только в плоскости XZ. Ввести1 → Enter:
смещение по X и Z на1м в выбранной системе координат; Y не меняется.
Ctrl+Z отменяет. Повторить S → Z → X: результат такой же. Esc отменяет предпросмотр.
СОХРАНИТЬ и повторно открыть: подтверждённые положение и форма сохраняются.
Повтор первой оси переключает локальные/мировые оси, сохраняя пару;
третья ось выбирает одну ось. Для вращения R пары не предусмотрены.
Ошибка: Y меняется, вторая ось заменяет первую, Enter даёт другую форму,
отмена оставляет изменение или Undo требует двух операций.
