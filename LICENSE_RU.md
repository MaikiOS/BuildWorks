BuildWorks, включая исходный код, бинарные файлы, документацию, оригинальную графику, материалы интерфейса и другие оригинальные материалы проекта (далее — «Программное обеспечение»), является частной интеллектуальной собственностью.

## 1. Личное использование бинарной версии

Разрешается скачивать, устанавливать и запускать официальную неизменённую бинарную версию BuildWorks для личного некоммерческого тестирования и игры в Valheim. Это разрешение не включает повторное распространение, сублицензирование, продажу, аренду, размещение для скачивания или включение в mod pack либо другой продукт.

## 2. Доступ к исходникам и Pull Request

Разрешается просматривать исходный код в официальном GitHub-репозитории. С учётом GitHub Terms of Service разрешается делать fork и копировать репозиторий через GitHub исключительно для изучения кода и подготовки Pull Request в официальный репозиторий BuildWorks.

Это разрешение не позволяет использовать исходный код или оригинальные материалы BuildWorks в другом проекте, публиковать производную работу, распространять изменённую сборку или выпускать независимый fork BuildWorks как отдельный продукт.

## 3. Вклад в проект

Отправляя Pull Request или другой вклад, вы подтверждаете право предоставить эти материалы. Авторское право на ваш вклад остаётся у вас, при этом владелец BuildWorks получает бессрочное, всемирное, безвозмездное, безотзывное, неисключительное право использовать, копировать, изменять, сублицензировать и распространять вклад в составе BuildWorks и последующих версий на любых условиях, выбранных владельцем.

Передача вклада не даёт прав на остальную часть Программного обеспечения. Решение о принятии вклада остаётся за владельцем.

## 4. Письменное разрешение на другое использование

Любое использование, прямо не разрешённое выше, требует предварительного письменного разрешения владельца BuildWorks. Запрос можно отправить через Issue официального репозитория или способ связи, указанный в профиле владельца на GitHub.

## 5. Ограничения

Кроме случаев, когда применимое законодательство не позволяет установить такое ограничение, запрещается:

- копировать, изменять, повторно распространять, публиковать, продавать, сублицензировать, сдавать в аренду или коммерчески использовать Программное обеспечение за пределами прямо данных разрешений;
- включать Программное обеспечение или оригинальные материалы в другой мод, mod pack, приложение, сервис, dataset или коммерческое предложение;
- удалять или изменять сведения об авторском праве, авторстве или лицензии;
- использовать название, идентичность или графику BuildWorks так, чтобы создать впечатление официального либо одобренного владельцем выпуска без письменного разрешения.

Никакие патентные права, права на товарные знаки или иные права интеллектуальной собственности не предоставляются, кроме ограниченных авторских прав, прямо перечисленных в лицензии.

## 6. Прекращение разрешений

Разрешения автоматически прекращаются при нарушении лицензии. После этого необходимо прекратить использование и распространение всех находящихся под вашим контролем копий, кроме копий репозитория, которые GitHub независимо сохраняет по своим Terms of Service.
