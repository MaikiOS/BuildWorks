# Этап282 — точное исключение пустых полей тумана; регрессия ещё открыта

21.10.2026. **Установлена локальная QA0.19.264. Приёмка v11 и скорость игры не закрыты.** Отклонённая владельцем .262 остаётся отрицательным результатом, а не успешной проверкой после этого этапа.

## Изменение и границы

После полного GPU IndexFields публикация получает бит4 только при нулевом числе занятых блоков. Бит связан с прежними owner/generation/sequence; metadata-only публикация его очищает. Ошибка сохраняет прежнюю публикацию. Renderer пропускает только доказанно нулевые динамические поля и использует прежние консервативные rest bounds. Не менялись шаги интеграции, отсчёты света, фоновое поглощение/рассеяние, правила возврата материи, очереди, стоимость или строительное состояние.

QA-метрики принимают flags3/7, требуют для7 нулевой count той же квитанции и прежнее совпадение идентичности/банка/последовательности. В отчёте каждой части теперь виден publicationFlags. Это измерение, не управление рендером.

## Сбои проверок сохранены

- Первое копирование264 получило «не удается найти путь» из-за лишнего BuildWorks в относительном пути. Установка не выполнялась. Путь исправлен.
- Host check затем выявил `Compiled fog resource differs from the verified bundle`: инкрементальная сборка сохранила старый встроенный ресурс после копирования с прежним timestamp. Полный Rebuild и повторный host check прошли; защита не ослаблялась.
- Старый physics-тест ожидал прежний бюджет. Для28logical/8192 явно задано7resident, а отрицательное выделение превышает актуальные256MiB; точные byte assertions сохранены.
- При чтении доказательств дважды ошиблись именами локальных файлов; использованы реальные пути из сохранённых RPC/списка файлов. Отсутствующих данных не дорисовывали.

## Что дальше

Главная регрессия остаётся: даже22кадра/с в покое и15на проходе недостаточны. Следующий срез — возраст контакта по реальному времени и повторная работа светового renderer. Сохранять точки отсчёта/порядок суммирования/возврат; прибавление очередей или урезание качества не считать исправлением. Новый ручной осмотр не готов. Физическая E/табличка, платная отмена, тяжёлые постройки и host+remote остаются открыты.

Локальная .264 содержит прежний неопубликованный shader267/271 и новые оптимизации282. Их GPU/native результаты нельзя приписывать старому source-only shader. Для публикации минимального shader-diff нужен отдельный точный прогон; binary bundle/лабораторные assets не синхронизируются. Независимый read-only review flags/guards/rest bounds PASS; это не визуальная приёмка.
