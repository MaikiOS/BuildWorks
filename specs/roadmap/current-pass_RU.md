# Текущая проверка BuildWorks в игре

[English](current-pass.md) | **Русский**

Проверяем **0.19.48**, только в **TerrainRamp-1.0-Test**. Сейчас ответь только на **1**.
[Серия .45](archive/pass-0.19.45_RU.md) — история, повторять её не нужно.
Unity прошла; проверка в настоящем Valheim ещё нужна. В этом проходе меняются
только рисунки/отклик точек. Посмотри 1 на обычном расстоянии и ближе. Если
нечитаемо — пришли скриншот до пунктов 2–8. Их номера и управление не изменены.

## Подготовка

Тестовый мир, копия чертежа. Молоток → BuildWorks → Чертежи → Редактировать.
Нужны две соседние деревянные стены; добавь через Tab при необходимости.
Для клавиш держи курсор над вьюпортом и выйди из текстовых полей.
Перед новым пунктом отмени предыдущее действие через Esc.
**Пункты 5–8 начинаются с панели в мире; пункт 7 также открывает окно
редактора. Не устанавливай чертёж.**

## Пункты для ответа

1. **Знаки точек.** Выбери стену → Ctrl+2 → Параметры инструмента → Точки: все.
   Посмотри золотые ванильные замки, синие скобы углов, зелёные зажимы середины
   и розовые центры. Shift+ЛКМ закрепляет точку: фиолетовый штырь.
   Ctrl+ЛКМ по нашей точке выбирает её для привязки: белые скобки поверх её цвета.
   Наведи на знак: яркая строка снизу называет тип и действия Shift/Ctrl.
   **Ожидаем:** стена не окрашена, точки не скрыты и не смещены. При совпадении
   наша точка внутри ванильного обода: середина и обод выбираются отдельно.
   Опора не добавляет ложный ванильный знак; исходные типы остаются видны.
   Напиши, читаются ли типы, точный центр и совпадения на обычном расстоянии.
   Сравни стену и косой брус. Сейчас ответь только на этот номер.

2. **G и короткое Q/E.** Выбери косой брус → G. Поводи над пустой сеткой,
   затем около другой стены. Останови мышь; нажимай E до возвращения «Авто»,
   затем Q. Покрути колесо; Esc.
   **Ожидаем:** перенос по поверхности как призрак установки; внизу «Авто»
   или выбранная ванильная точка. По умолчанию Q/E перебирает только их и сразу
   перестраивает деталь без движения мыши. Колесо поворачивает; Esc возвращает.

3. **Окно привязки.** Выбери стену → G → Привязка сверху вьюпорта.
   Наведи и выбери ванильную строку. Включи дополнительные точки и выбери нашу.
   Закрой кликом снаружи; R, затем G. Подвигай курсор до явного изменения
   положения; Enter; Ctrl+Z.
   **Ожидаем:** наведение показывает настоящую точку; окно ничего не подтверждает.
   Наши точки включаются отдельно; явный выбор сохраняется после G → R → G.
   Enter подтверждает один раз, один Undo возвращает исходное положение.
   Нажатия в окне не начинают другую трансформацию.

4. **«Авто» и мебель.** Стена → G → Привязка → Авто; выключи дополнительные
   точки. Приблизь к другой стене примерно на 2 м, затем к золотой точке; Esc.
   Добавь стул через Tab, поставь в редакторе, выбери → G → Привязка.
   **Ожидаем:** цели видны до притяжения; «Авто» предпочитает ванильную пару
   и удерживает при малых движениях. Мебель без ванильных точек предлагает
   подписанные наши; мебель с ванильными использует их. Esc возвращает исходное.
   Напиши название мебели, если пригодных целей нет.

5. **Ванильные карточки.** Сохрани тестовый чертёж ровно из двух обычных
   деревянных стен. Выйди из редактора. В молотке в мире сначала посмотри
   одну обычную стену, затем выбери чертёж без установки.
   **Ожидаем:** миниатюра/имя/короткое описание, ниже карточки иконка/имя/количество;
   сумма древесины (обычно 4, если одна стена стоит 2); верстак отдельной
   иконкой. Не прежний текстовый список ресурсов.

6. **Суммы, доступность и длинный список.** Возьми отдельный тестовый чертёж
   с разными ресурсами/станками, сохрани и выбери без установки. Сравни суммы
   со стоимостью составляющих. Если строк несколько, открой меню молотка для
   свободного курсора и прокрути над панелью ресурсов.
   **Ожидаем:** ресурсы суммируются, станки без повторов; нехватка оплачиваемых
   требований обозначена, доступность обновляется. Карточки расширяются/
   переносятся внутри экрана, слишком длинный список прокручивается.
   Если типов мало, ответь «длинный список не проверял» — специально строить
   огромный чертёж ради этой проверки не нужно.

7. **Язык.** Переключи на English; выбери обычную деталь, затем чертёж.
   Редактировать → выбери стену → G → Привязка. Верни русский и повтори выбор.
   **Ожидаем:** карточки/описание/окно обновляются без перезапуска. Твоё имя
   чертежа не переводится. Скриншот непереведённых/обрезанных подписей.

8. **Возвращение обычного HUD.** После призрака чертежа выбери стену, затем
   Ремонт. Убери/возьми молоток и выбери стену. Снова Редактировать; G; Esc.
   **Ожидаем:** штатная панель/карточки восстановлены, лишних ячеек и висящей
   прокрутки нет; отмена в редакторе не оставляет точек/копий и не подтверждает.

## Как ответить

Один ответ на номер: `1 — работает`, `2 — проблема: …`, до `8`.
При проблеме укажи номер, инструмент, точные клавиши/движение мыши и результат;
для графики приложи скриншот. Где нужно, напиши «не проверял».
Дополнительных серий с буквами нет; принятые трансформации/камеру .45 не повторяем.

Это проверка отображения/ввода, не доказательство расхода/возврата ресурсов,
сохранения/перезагрузки мира или сети. Другие профили и кривые не проверяем;
кривые требуют отдельного обсуждения.
