# .148 — временная память исходных чертежей

Код `3a23969`. Normal/QA0.19.148 собраны; установлена по-прежнему QA0.19.146.
Valheim/Unity/input не запускались: Ostrix работает за компьютером.

## Подтверждённая причина и изменение

BlueprintSourceDocument сначала строго кодировал исходник в UTF8 для проверки
размера, затем создавал большую строку format+name+text и второй массив для SHA.
Хеш теперь получает прежние байты двумя TransformBlock и пустым завершающим
блоком. Дополнительных зависимостей, кешей или удерживаемых буферов нет.

Последовательность байтов и ID прежние. Строгая проверка текста, BOM/CRLF,
пределы байтов, источник/строки, неизвестные поля и immutable-cache сохранены.
Префикс использует прежний Encoding.UTF8 fallback: изменение приёма некорректных
surrogate в имени не входит в этот этап. Некорректный Unicode текст всё ещё отклоняется.
Схема/миграция, масштаб, ресурсы и права не менялись.

исходника7340045 UTF8 байтов выделения конструктора в .NET10:

процесса или Valheim. Тест проверяет ID независимым прежним concat+SHA алгоритмом,
пустой/Unicode/BOM/CRLF исходник, fallback имени, некорректный текст и байтовый предел.
