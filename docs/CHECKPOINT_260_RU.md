## Туман: изолирован дефект тестового захвата

Источник различия259 проверяется без подгонки игрового shader. Frozen/sequential накладывает несколько объёмов последовательно, текущий atlas объединяет плотность/свет перед интегрированием. Эти операции нелинейны; совпадение одной секции не означает эквивалентность четырёх.

Первая попытка joint-control на4 dense owners превысила существующий128МиБ лимит: `InvalidOperationException: Fog atlas exceeds its render memory budget.` Unity проглотила исключения OnRenderImage; Camera.Render вернулся, а старый helper записал недостоверные пиксели и выставил captureComplete. **Этот результат отвергнут**, даже при exit0. Исходные20исключений/кадры/отчёт сохранены: `artifacts/checkpoint-260/matched-joint-probe/` и `fog-longwall-matched-260-joint/`; отдельное решение `rejected-four-owner-control.json`. В четырёх прежних логах259 таких исключений не найдено; они не переписывались.

Минимальное исправление собственного matched-harness: обернуть callback, сохранить исходное исключение, дать Camera.Render завершиться и затем передать ошибку до ReadPixels/PNG; требовать ровно один callback и восстанавливать delegate/RT в finally. Игра/общий renderer не менялись. Регрессионная проверка намеренно бросает исключение через тот же Render helper:1 вызов, ошибка передана,0PNG. Проверенный вывод `fog-render-failure-260-v2/verification.json`.

Без ослабления лимита выполнен joint-control двух реально перекрывающихся секций. По4траекториям проверяются overlap и5 выбранных кадров0/66/96/150/360 при fixed30Hz. Поля/исходные текстуры/камера одинаковы; средний поток использует существующий плотный совместный atlas, правый — published atlas.
