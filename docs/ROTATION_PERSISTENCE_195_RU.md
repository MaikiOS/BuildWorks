# Точный поворот новых деталей чертежа — .195

Причина .194 подтверждена в текущей DLL Valheim: ZDO хранит Euler, а сохранение мира через WriteSmallRotation усекает значения с шагом 0,5°. В оплаченной постройке Forest Hut после перезагрузки 10 из 28 поворотов изменились; положение, масштаб и инвентарь сохранились. Это не засчитано как полный успешный reload.

В .195 новые успешно размещённые детали чертежа получают два Quaternion-поля ZDO-extra: точный поворот и контрольное значение, вычисленное настоящим дисковым кодеком игры. Чтение принимает только конечные единичные Quaternion и совпадение native значения с точным либо контрольным. Настоящий SetRotation удаляет оба поля; ручное изменение имеет приоритет. Старые объекты автоматически не переписываются. Обычный режим WorldPrecision этой правкой не меняется.

Независимое чтение выявило ошибку первого варианта: ConsumeResources вызывается до PlacePiece. Удаление созданного объекта при отказе записи до регистрации оплаты теряло ресурсы. Запись перенесена в успешное завершение TryPlacePiece после регистрации объекта и его оплаты, до завершения серии. Проверка свежего создания выполняется до native списания. Отказ записи использует существующую отмену: завершение снимка списания → подтверждённое удаление объекта и сетевой записи → однократный возврат фактически внесённых ресурсов. Новая система компенсаций не добавлена.

Если сторонний обработчик подменил идентичность новой детали на ZDO исходника/призрака, автоматическое удаление и возврат блокируются с ошибкой: нельзя безопасно удалить чужую запись или доказать право на компенсацию. Этот исключительный случай остаётся неразрешённым; гарантия возврата на него не распространяется.

Автоматически проверены: Unity118 (реальные production writer/reader и Harmony patches, математические операции Unity, инертное хранение), normal/QA build 0/0, HostContract текущего Build25909357, Geometry с регрессией отложенного завершения оплаты, Store, localization1104, QA control/isolation. Workbench624 выполнен до последнего переноса writer; этот непредставленный в UI Workbench участок дополнительно проверен повторными сборками/HostContract/Geometry. Независимые correctness review PASSED и Ponytail Ship получены. Защита буквального совпадения source/ghost без ZDO исправлена в обоих путях удаления; восемь actual-source проверок включены в HostContract. Результат native .195 приведён ниже.

Установлена .195 (E19249E4…F8875EA), Geometry74E2F1CB…54F90FB. Штатный Deploy-TestBuild,127 защищённых файлов неизменны. Артефакты .195: artifacts/rotation-persistence-195. Инертный reload не считается проверкой диска Valheim или удалённого клиента.
