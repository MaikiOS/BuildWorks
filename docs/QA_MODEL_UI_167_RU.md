# Локальная модель и UI .167 — офлайн, 2026-10-12

Подготовка [12 полных сценариев](LOCAL_QA_FULL_SCENARIOS_RU.md) завершена;
это следующий шаг исполнителя, а не новые игровые микрозадания. Установлена .165:
новая DLL не устанавливалась, игра, модель и GPU не запускались после паузы.

`Run-LocalQAMission.py` теперь принимает `click` и `text` только при явном
`ui_policy` задания. Правило содержит точные `scope/name/kind`, разрешённые
действия и пары `value/submit`. Нет wildcard, произвольных координат или допуска
консоли. Native наблюдение .167 передаёт имя контрола, ближайшего предка
BuildWorks и признак усечения значения. Это описание UI, не идентичность чертежа.

Модель выбирает ID из увиденного состояния. Перед отправкой та же команда и ID
повторно проверяются по свежему наблюдению; исчезнувшую цель нельзя заменить
похожей. Поле должно быть доступным для записи и реально сфокусированным.
Поддержаны обычные InputField/TMP_InputField и существующий BlueprintEditorInputField.
Нажатие и текст проходят прежним native вводом, без прямого вызова Button.onClick.

Критерий `ui_values` требует полного списка UI, ровно одного контрола с заданными
scope/name/kind, полного неусечённого значения и точного совпадения. Усечённый
список или неоднозначный селектор не дают успеха. Подтверждённое значение поля
не доказывает изменение чертежа, сохранение файла, строительство или расходы.

Журнал `events.jsonl` записывает `dispatch` до native-вызова: решение, причину,
команду, исходную квитанцию и цель UI. После сохраняются native-квитанция,
длительность, новое наблюдение и путь кадра. При таймауте отправленная команда
остаётся в журнале с неизвестным исходом; автоматический повтор запрещён.
Контракт полного журнала всех контрольных точек остаётся в `full-suite.json`.

Проверено автоматически:

- Python mission:6 тестовых методов,15 полных имитированных проходов, включая
  смену ID, невидимую ранее цель, premature finish, readonly и неизвестный исход.
- Python scenarios:3 теста пакета; все12 сценариев остаются readiness blocked.
- Производственный QA-протокол43/UI44/publisher; normal и QA .167 без warnings.
- Compiled QA/native input/isolation, HostContract и989 локализаций прошли.
- Независимый correctness PASSED, Ponytail Ship; `verify` отсутствует.

Sandbox-прогон Python упал на атомарной замене status.tmp → status.json:
`PermissionError: [WinError 5]`. CPU-повтор вне sandbox прошёл. Проверки используют
имитации модели/игры и временные файлы; это не доказательство настоящего UI.
SHA установленной .165 и Geometry сверены и не изменились.

Остаются страницы/поиск UI-целей, точная идентичность выбранного документа,
снимки объектов и экземпляров предметов, ledger расходов/возврата, проверка
контрольных точек полного сценария и возобновление после reload. Произвольные
операции с ресурсами нынешний пилот не разрешает. S09/S11 также зависят от функций
продукта, S12 — от отдельной разрешённой сетевой среды. Поэтому полный пакет
пока нельзя передать узкому пилоту и назвать выполненным.
