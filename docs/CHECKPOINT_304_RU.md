## Найденное ограничение и следующий шаг

Подбор ещё неудобен: источники расположены друг над другом с шагом0,05м,
журнал допускает только последовательный prefix. Native hover верхнего предмета
выбирал вторую строку, E выдавал ложное для этого случая reconciliation-сообщение.
Наблюдаемые Wood63/0Collections/два точных источника не изменились. Hash был снят
после отказа и оставался прежним при последующих наведениях; отдельного pre-error
hash нет. Старая строка Failure оставалась и после успешного получения до reload.

Первый предмет удалось выбрать только узким наведением на нижний выступ:
native aim-map при pitch39,5/41/42,5 попадал во второй,44 — в первый.
Это доказательство доступности обработчика, не удобства для обычного игрока.
8.7–8.8 остаются открытыми. Следующее изменение: проверить всю раскладку новых
источников до spawn, разнести их без перекрытий и явно показать порядок; не менять
формат/защиты журнала и не перемещать/перевыдавать старые источники автоматически.
Широкие предметы, crash windows, secondary collapse, host+remote и owner UX открыты.
