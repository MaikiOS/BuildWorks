использовать уже импортированную запись. Исходник находится в

Открыть **РЕДАКТИРОВАТЬ**, выбрать один пол, **СОХРАНИТЬ КАК…** → **QA132 Scale**.
Нажать S → X и двигать мышь вверх/вниз: меняется только X. Набрать `1,5` → Enter:

## 2. Соединение в мире и сохранение нового результата

В той же папке — `17-supported-snap-a.blueprint` (**TEST 17 Snap A**) и
`18-supported-snap-b.blueprint` (**TEST 18 Snap B**). Использовать имеющиеся карточки.
Начать на свободной ровной части тестовой площадки. A содержит 30°, B — 120°:
дополнительные 90° молотком не добавлять. Поставить A со столбиком на земле;
выбрать B, подвести настоящий угол пола к свободному углу A. Осмотреть с двух
сторон: выбранные углы совпадают, нет скачка высоты/масштаба, столбик B на земле.
Построить B, подождать 30 секунд: результат совпадает с призраком и устойчив.
Выйти с сохранением, войти в тот же QA-мир: новое соединение осталось прежним.
Ошибка: призрак прилипает со смещением, меняет ориентацию, результат отличается,
разрушается или меняется после входа. Не подгонять ошибку вручную; нужен снимок.

**РЕДАКТИРОВАТЬ** → выбрать **QA missing target**, с Ctrl добавить обе стены →
**ЗАМЕНИТЬ ОТСУТСТВУЮЩУЮ**. Стены уже в предпросмотре переходят в позицию и
ориентацию записи, сохраняя размеры/взаимную раскладку. **ОТМЕНА** возвращает три
исходные записи. Повторить → **ПРИМЕНИТЬ**: две стены, группа «Замена»; один
Ctrl+Z/Ctrl+Y возвращает/повторяет замену. Затем Ctrl+Z, выбрать только missing →

позе. Подтвердить, **СОХРАНИТЬ КАК…** → **QA132 Replacement**, закрыть/открыть копию.
Ошибка: остаётся прежнее положение, добавляется сдвиг, меняется размер, отмена

восстанавливается: рамка показывает записанный объём; поверхность новой модели
