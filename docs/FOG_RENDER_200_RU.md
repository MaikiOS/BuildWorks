## Диагностика и точные границы

Первый visual check получил delta0,014: Edit Mode не вызывал callback тестового компонента. Добавлены ExecuteAlways и обязательная проверка вызова; допуск не расширялся. Ранний JSON, записанный до assert, не является PASS; исключение/exit1 сохранены в failed-idle-1. Отказ NuGet `Access to the path is denied` устранён разрешённым повтором сборки. Одно сравнение файлов ошиблось из-за автоматического преобразования JSON-даты; SHA/UTCmtime после DateKind String совпали. Первый games_start получил transient runtime.json rename Access is denied; статус проверен, штатный повтор прошёл без сброса состояния.

Первая native попытка корректно отклонила стену вне padded region: начало prefab по высоте не равно низу геометрии. Исправлен только QA-стенд: отдельное начало области по фактическому центру и высота по нижнему краю, без изменения масштаба. Финальный native прогон проверяет это исправление. При ранних пробах рядом с прежними обломками игра автоматически подобрала Wood1→5→9; это не неизменный инвентарь. Между первым и вторым входом видимая прочность активного молотка18,9→4,4%; причина этой ранней разницы не установлена, бесплатного ремонта/возврата не делалось. Во втором и финальном прогонах молоток оставался4,4%. Не считать эти ранние сеансы доказательством сохранности всех предметов.

Native кадры заметно светлее лабораторных; правильная текстура и реакция тела подтверждены, но соответствие цвета/освещения утверждённому виду пока не принято. Следующий визуальный шаг — измерить реальные параметры native материала/камера-HDR/порядок обработки и сохранить вид v11, не подбирать произвольную общую затемняющую поправку.
