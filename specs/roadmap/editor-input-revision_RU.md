# Пересмотр управления редактором BuildWorks и проверочные сценарии

[English](editor-input-revision.md) | **Русский**

Утверждено Ostrix 2026-10-01; отзыв по .44 отменяет первый G из .43.
Выбор сразу подсвечивает деталь и показывает ручки; управление мира/F9 не меняется. Автоматические
доказательства — в HANDOFF; игровая приёмка владельцем ещё ожидается.

## Что было подтверждено в .42 до изменений

Select сейчас автоматически показывает гизму через `SelectionGizmoTool`; G
сразу начинает перенос через `BeginKeyboardPreview`. Обычные 1–4 выбирают
инструменты, меню тоже обрабатывает цифры. Канала текстового ввода операции в
`IBlueprintEditorInput` нет; поля параметров его не заменяют. Перебазирование
мыши использует текущую правку, поэтому точному числу нужен независимый снимок
начала действия. СКМ уже управляет камерой с порогом движения шесть пикселей.
Масштаб ловит только линии в радиусе шесть пикселей, а не всю видимую область.
Орнамента и текстур концепта нет: ручки состоят из геометрии, линий и цветов.
Экспорт SVG для кнопок уже существует; новая библиотека отрисовки не нужна.

## Действующее управление

| Состояние | Нажатие | Результат |
| --- | --- | --- |
| Выбор с редактируемой деталью | Выбрать деталь | Золотистая подсветка и вся гизма сразу, без правки |
| Выбор или готовая гизма | G | Перенос выбранного мышью по поверхности |
| Гизма готова | X, Y или Z | Сразу перенос по оси без второго G |
| Гизма готова | R или S | Вращение или равномерный масштаб мышью |
| Перенос или вращение | XYZ; повтор оси | Ограничение; мир/локальные координаты |
| Перенос | Shift+ось | Плоскость без выбранной оси |
| Перенос по поверхности | Q/E, колесо, P | Точка, поворот, явная экранная плоскость |
| Действие начато | Число | Замена результата мыши относительно начала действия |
| Действие начато | Enter/ЛКМ во вьюпорте | Проверка и одно подтверждение |
| Действие начато | Esc | Точная отмена, возврат к готовой гизме |
| Гизма готова | Esc | Возврат к Выбору с гизмой; Esc в Выборе снимает выделение |
| Инструмент вьюпорта | Ctrl+1/2/3/4 | Выбор/Гизма/Массив/Контур; сначала отмена preview |
| Выбор или установка | Короткий СКМ по установленной детали | Удаление этой детали при отпускании |
| Вьюпорт | Тянуть СКМ, Shift+СКМ | Орбита/панорама, без удаления |

G/R/S/оси доступны сразу из Выбора; предварительный G больше не нужен.
Ctrl+2 включает отдельный инструмент Гизма. Все ручки включают оси/плоскости перемещения,
вращение, равномерный масштаб, исходные точки и закрепление. Ручные фильтры
отображения оставлены; операция трансформации открывает все ручки. Массив и Контур
сохраняют собственные параметры и математику, не чужое состояние трансформации.

## Точные числа и завершение действия

Снимок начала содержит ID выбора, трансформации, центр, закрепление и координаты
оси. Перебазирование камеры/мыши не меняет этот снимок. `R → X → 30` — ровно
30° от начала операции, не ещё 30° после движения мыши. Перенос `2` — два метра
от начала; масштаб `1,5` — умножить начальные размеры на 1,5 с пределами 1–400%
для каждой детали. Проценты в панели параметров сохраняют отдельный прежний смысл.

После начала набора число управляет результатом, мышь не прибавляет смещение.
Основные цифры/цифровой блок, минус, точка/запятая и Backspace/Delete редактируют
число. Пустой/неполный ввод вроде `-` или `1,` не подтверждает действие случайно.
Только конечные числа в допустимых пределах, без выражений в этом проходе.
Для одного числа свободному переносу сначала нужна ось. Ошибочный масштаб
показывает ошибку, не обрезается автоматически. Очистка числа возвращает мышь без
скачка. Масштаб по отдельной оси не предлагается: текущий масштаб равномерный.

Смена R/S/переноса откатывает прежний preview и начинает новое действие от
неизменённого документа. Ctrl+1–4 сначала делает то же, затем меняет инструмент.
Ctrl+Z в preview только отменяет его, не откатывая сразу прошлую правку; повтор
нажатия вызывает историю. Ctrl+S/копия/группа не изменяют незавершённую операцию.
Навигация СКМ/ПКМ приостанавливает её без изменения начала; потеря фокуса отменяет.
Вводом владеет только один жест: трансформация, Массив, Контур, установка или
камера. Отпускание старой кнопки после отмены не подтверждает следующую операцию.
Esc закрывает внутреннее поле/меню/действие, не несколько уровней разом.

## Удаление СКМ и приоритеты

На нажатии запоминаются допустимая деталь и позиция курсора. Удаление на отпускании
во вьюпорте только если был клик по этой детали без захвата UI/ручки/перетаскивания/
модификаторов. Если порог камеры был превышен хоть раз, возврат мыши назад не
превращает жест в удаление. Начало на пустоте не удаляет деталь под концом жеста.
Shift/Ctrl/Alt+СКМ — навигация либо зарезервированный жест, не удаление.
В активной трансформации СКМ — только камера. При установке удаляется уже стоящая
деталь, призрак сохраняется. Заблокированные/скрытые/missing/уже удалённые цели
не подходят.

Приоритет: поле/диалог → меню → активный жест → инструмент → выбор/камера.
Ctrl+1–4 обрабатываются до прежнего общего запрета модификаторов; обычные цифры
больше не переключают инструменты. Поиск/меню не передают цифры в трансформацию.
Полёт ПКМ получает WASD/QE, не S масштаба или Q/E привязки. UI-клик не подтверждает
действие во вьюпорте.

## Оформление

Реализованы шесть оригинальных редактируемых рисунков:
`assets/blueprint-editor/icons/source/gizmo-*.svg` — металлические градиенты,
гравировка и заклёпки. `scripts/Build-BlueprintEditorIcons.ps1` экспортирует
прозрачные PNG 128×128 в `src/BuildWorks/Assets/BlueprintEditorIcons` и один общий
лист. Используется существующий загрузчик: нет новой библиотеки SVG, чужих
рисунков или растровой картинки, выдаваемой за вектор.

Сохранить принятые силуэты. Отдельные редактируемые источники: наконечник,
плоскость, конец дуги, масштаб, исходные/целевые метки. SVG хранит контуры и
гравировку, отдельно сгенерированные прозрачные текстуры — металл, где это нужно.
PNG не называется вектором. Экспортированные ресурсы встраиваются, не читаются
из внешней папки концептов. Использовать существующую геометрию с текстурами,
освобождать ресурсы при закрытии. Оформление мира/F9 в эту правку не входит.

Ручки тусклые вдали от курсора и плавно ярче по расстоянию до настоящей фигуры
на экране, а не по метрам в мире. Только победившая ручка яркая при наведении,
активная — при движении. Оси различимы; сплошного свечения всех ручек нет.
Масштаб заменить заполненной гравированной фигурой около 35 логических пикселей
в стороне от плотных колец. Нажимается весь силуэт с небольшим запасом, совпадения
разрешаются однозначно. Орнамент проверять в рабочем размере, не только на концепте.

## Обязательные проверки

Расширять реальные Controller.Update/LateUpdate и EventSystem тесты Workbench,
не отдельную имитацию новой логики.

| Проверка | Сценарий | Что обязано получиться |
| --- | --- | --- |
| Видимость | Выбор деревом/мышью, G, Esc | Подсветка и ручки сразу; G — preview; Esc отменяет без потери выбора |
| Начало операции | R X, мышь, 30, Enter | Ровно 30° от начала; один Undo возвращает точную позу |
| Перенос/масштаб | Мышь, -2,5; S 1,5 | Начальный снимок, запятая/точка/цифровой блок, пределы масштаба |
| Число | Пустое, минус, запятая, стирание, переполнение | Нет случайного подтверждения, NaN или удаления |
| Ограничения | Повтор XYZ, плоскость, ось вдоль камеры | Понятные координаты, нет подтверждения ошибочного луча |
| Смена режимов | R/S/перенос, Ctrl+1–4 во время preview | Старое точно отменено, больше не действует |
| История | Esc, Ctrl+Z, redo, нулевая правка | Отмена без истории, один Undo, ноль не создаёт правку |
| Камера | СКМ/полёт ПКМ/колесо при мыши и числе | Нет скачка, удаления или смены начала операции |
| Клик СКМ | Выбор/установка, потом Undo | Одна стоящая деталь удалена один раз, призрак сохранён |
| Тянуть СКМ | С детали/пустоты/UI, вернуться назад | Только камера, без удаления/прохода UI насквозь |
| UI/фокус | Поле, поиск, меню, отпустить снаружи, перезайти | Правильный владелец ввода, нет старого жеста/числа |
| Группы | Вложенные, опоры, заблокированное | Верный центр, стабильные ID, нет двойной правки |
| Попадание | Совпадающие ручки, новый масштаб, приближение/UI scale | Наведение совпадает с кликом, нет невидимых перехватов |
| Отрисовка | Покой/близко/наведение/движение/за моделью, EN/RU | Плавность, читаемость, освобождение ресурсов |
| Массив/Контур | Применить/отмена/сменить, числовые поля | Прежняя математика, без висящих линий/копий |
| Граница игры | Открыть заново, мир/F9, сохранение/загрузка | Нет изменения управления мира или Store |

Матрица — договор регрессий, не обещание проверки каждой вариации.
ControllerInputAcceptance проверяет настоящий Update/LateUpdate: видимость,
числа от исходной позы, неверный ввод, оси, отмену, смену инструментов, историю,
паузу камеры и клик/движение СКМ. RuntimeEditorAcceptance и
EditorInteractionAcceptance проверяют текстуры, подсветку и попадание по масштабу
на установленных native-моделях. Игровая и визуальная приёмка — current-pass_RU.md.
