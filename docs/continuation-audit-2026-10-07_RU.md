## Зависимости следующих этапов

1. **.86 — правила передачи ItemStand.** Обычный игрок отдаёт предмет того же prefab со своими
   quality/variant/durability/customData и прочими полями. Native serializer фиксирует пакет до передачи;
   успех требует расхода ровно одной единицы и совпадения сохранённого пакета именно этого предмета.
   Точный исходник остаётся в чертеже. Это не admin restore. Затем согласовать world preview с выбранным предметом.
2. **Малый внешний чертёж целиком.** Проверить диалекты заголовков, source binding и вариации материалов;
   единый placement frame для editor/Hammer/native plan; без произвольного уменьшения постройки.
   Нужны настоящий внешний файл, готовые ресурсы/предметы и точный сценарий place/cancel/reload.
3. **Неполный и тяжёлый редактор.** Сохранить неопределённость intrinsic scale/габаритов missing prefab;
   разрешить редактор, блокируя world до явной замены. Затем бюджетируемое открытие >512, отмена и замеры.
4. **Содержимое и полномочия.** Независимые placement choices; legacy containers/armour/free items;
   survival использует предоставленные предметы, admin восстанавливает архив только после server authorization.
   Надписи/состав/конструкция отделены от износа/топлива/инвентаря; старые сетевые ID не переносятся.
5. **Объём выделения.** Площадь, верх/низ, явное правило пересечения границы, список и ручные исключения,
   сообщение об ограничении загруженной области. Визуальный вариант сначала показать и проверить.
6. **Полная приёмка.** Отдельный подготовленный тестовый профиль/мир/персонаж, без ручного сбора ресурсов;
   малый и тяжёлый внешние файлы, missing mods, отмена/сбой, ресурсы, reload и host+remote client.
   Основной мир и сохранения не меняются. Плановая стройка/земля остаются следующим этапом.

## Проверка и ограничения среды

Свежий .85 baseline: Release --no-restore, Geometry, Store с реальным353-файловым ZIP,
Localization848, EditorBridge, WorldLayout14, HostContract и deployment guards PASS.
Отказы sandbox затронули NuGet, atomic store writes и Roslyn named pipe; те же необходимые
проверки повторены вне sandbox. Длинная временная папка артефактов вызвала
`Не удалось найти часть пути`; Store повторён с обычной короткой временной папкой.
Шесть старых WHITESPACE замечаний конвертера исправлены только форматированием.
verify helper отсутствует в обоих skill roots и PATH; применены прямые проверки и независимые review.

Unity Workbench выполняет настоящий editor/adapter code на inert fixtures и сохраняет изображения.
Это доступное средство наблюдения. Native computer APIs в текущем CUA отключены:
управление настоящим Valheim этим инструментом недоступно. Ни Workbench, ни DLL, ни parser PASS
не доказывают строительство, сохранность мира, сетевую авторизацию или отсутствие дюпов в игре.
Готовый survival world/character пока отсутствует; прежние инструкции .80 требуют ручной подготовки
и не являются готовым стендом по текущему заданию. Установленная .82 не объявляется .86.
