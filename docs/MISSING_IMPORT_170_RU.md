# Импорт без единой доступной детали — исходники .170

12 октября 2026. Установлена прежняя .169; новой установки и игрового ввода не было. Локальная модель остановлена по просьбе Ostrix. Ручная серия: [MANUAL_QA_169_RU.md](MANUAL_QA_169_RU.md).

## Воспроизведение и изменение

В .169 `TryImportReviewed` запрещал полностью недоступный документ только при явном исключении missing. Режим сохранения записей принимал его, включая такой документ внутри ZIP. Это противоречит цели: создание чертежа без единой доступной детали запрещено.

Общая проверка импорта теперь использует уже снятый снимок наличия prefab. При известном загруженном host полностью недоступный документ останавливает весь импорт до запуска записи. UI отключает подтверждение и объясняет причину. Частичный missing сохраняется; отсутствие рецепта не считается отсутствием prefab. Без resolver/загруженного host отсутствие модели не выдумывается. Открытие существующей записи и её резервный экспорт не запрещены.

Новые проверки: standalone и смешанный ZIP, сохранность исходника/каталога/предыдущего результата, отсутствие фонового импорта после отказа; экспорт сохранённой missing-записи; настоящий `Tick` блокирует импорт, оставляет «Назад»/закрытие и допускает резервный экспорт.
