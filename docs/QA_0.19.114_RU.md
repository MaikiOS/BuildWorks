# Проверка .114 — сохранённая рамка и неизвестный размер

Готовый файл: `tests/fixtures/metadata/13-recorded-bounds.buildworks.json`.
Имя: **QA114 Recorded Bounds**. Найти: профиль Default → BuildWorks → tests →
fixtures → metadata. Скопируй полный путь к файлу для окна импорта.

Это авторский синтетический стенд: оба prefab намеренно отсутствуют, мод для них
не существует. Первая запись содержит заданные тестом границы; вторая — нет.
Тест не выдаёт размеры за измерение настоящей отсутствующей модели.

Исходное состояние: установленная QA .114, изолированный TerrainRamp-1.0-Test,
подготовленные QA мир/персонаж. Материалы, рецепты, установка чужих модов и
строительство не нужны. Запуск при разрешённой игровой проверке — Thunderstore
→ **Modded**. Эта инструкция сама игру не запускает.

1. Каталог редактора → «Импорт файла». Выбери файл, нажми «Импорт файла».
   Оставь «Отсутствующие детали: СОХРАНИТЬ ЗАПИСИ», затем «Подтвердить импорт».
   Ожидается предупреждение о двух отсутствующих ID. Режим копии без отсутствующих
   деталей недоступен: доступных деталей не останется.
2. Открой полученную отдельную копию через «РЕДАКТИРОВАТЬ». В дереве две записи.
   **QA recorded envelope** — рамка, **QA unknown dimensions** — малый маркер.
   Ожидаемые размеры рамки до поворота:4×2×0,5м; поворот30° вокруг Y. Её центр
   находится на1м выше начала координат первой записи. Маркер второй — X=6м.
   Рамка показывает сохранённую коробку, не внешний вид объекта.
3. Выбери рамку в дереве, передвинь гизмой. «Сохранить» → имя
   **QA114 Bounds Edited** → «Сохранить». Закрой редактор, снова открой эту копию.
   Рамка, её изменение и отдельный малый маркер должны сохраниться. Сохраняется
   редактируемая импортированная копия; исходный файл не должен измениться.
4. Выбери обе записи, инструмент «МАССИВ», режим «УПАКОВАТЬ», потяни стрелку ряда.
   Ожидается объяснение, что сохранённых рамок недостаточно: нужна модель или явно
   заданный шаг. Привязки к рамке как к настоящей поверхности не должны появляться.

Признаки ошибки: запись пропала; рамка стала сплошной выдуманной моделью; размер
или смещение удвоились; маркер неизвестной записи приобрёл «точные» габариты;
невозможно сохранить/reopen; исходник изменился; рамка работает как опора/модель.

Автоматически отдельно проверен сбор настоящего MeshFilter-снимка на Unity-объекте
с вложенными трансформациями и обновление при сохранении. Этот ручной сценарий
не подтверждает native стройку/reload мира, multiplayer, skinned-габариты или v11.
