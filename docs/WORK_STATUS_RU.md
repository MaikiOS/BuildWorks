# Требования и состояние BuildWorks

Обновлено: 2026-10-18. [Полная текущая матрица](CURRENT_STATUS_RU.md) отделяет исходники, автопроверки, установку, Valheim, приёмку Ostrix и сеть. [Контракт](../PROJECT_CONTRACT_RU.md) сохраняет полный объём; [ROADMAP](ROADMAP_RU.md) задаёт очередь. Исторические отметки «установлено/следом» не являются текущим состоянием.

| Требование | Статус / оставшаяся работа |
| --- | --- |
| Аудит, источники доказательств и живой список | Существующий индекс SocratiCode проверяется по корню Default; отсутствие символа не означает отсутствие индекса. Новые файлы сверяются прямым чтением исходников; слепой переиндексации нет. Текущие файлы/receipts важнее старых заявлений |
| Внешний/свой чертёж→редактор→стройка→reload | Один Forest Hut (28) деталей доказан; весь поддерживаемый корпус/сеть не принят |
| Формат/конвертация/экспорт | Частично: store24/portable13, явные границы источников и потерь; неизвестное не считается восстановленным |
| Missing-записи/замены/метаданные | Реализованы записи/рамки/копии; неизвестные модель/размеры честно обозначаются, нужен широкий регресс |
| Редактор/опоры/привязки/камера/масштаб | Многие случаи приняты; парные оси/перенос указателя/повёрнутые системы и новые UX-случаи остаются |
| Предметы/хранилища/права | Основы есть, долговечное завершение/возврат/сбои/все держатели/admin/сервер не завершены |
| Объёмное выделение | Частично; завершение высоты/актуальный состав проверены в .215 Unity/Valheim40/40+ID; гизма площади/полное обновление мира открыты; рамка Unity48, ручная приёмка ждёт |
| Постоянный проект/колышек/табличка | .225 unpaid19/19+14/14; .226 native-достройка/reload16/16+10/10 на4стенах. Обычный Create/туман/оплаченная отмена/общий recovery/remote открыты |
| Текущий проверенный этап | [.226](CHECKPOINT_226_RU.md):4стены/8Wood суммарно, exact TRS/receipt/paired save/reload, без повторного расхода. Установлена; полной готовности/визуальной/сетевой приёмки нет |
| Утверждённый v11 | [.213](FOG_NOISE_FRAME_213_RU.md): общая фаза шума проверена и установлена; native .213 не проверена; домен/владение/FPS открыты. [.212](FOG_RECOVERY_212_RU.md): межкадровая ошибка исчезновения воспроизведена и исправлена, Recovery24/Scratch/Lazy/сборки/контракты прошли; QA установлена. Игровой маршрут35/35 и оба recovery0 прошли, инвентарь неизменен; Ostrix отверг растворение/возврат и скорость прохода; эффект v11, сервер и постоянная табличка открыты |
| Тяжёлая цепочка/плановая стройка/EarthWorks | Замеры всех стадий и игрового порога впереди; полноценная EarthWorks-интеграция отложена |
| Русский UI/проверки/снабжение | Каталоги1118ключей; normal/QA, Store/Geometry/host и ограниченные native-сценарии проверены. Полная ручная/сетевая серия остаётся открытой |
| Категории/автофайл/Share/группы/серверный каталог | Файловые функции есть, часть .197 проверена; полный batch/host+remote/передача игрок→игрок открыты |
