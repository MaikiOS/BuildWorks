# Результаты Ostrix: ручная серия после QA .176

Не просить повторять уже принятые auto17/18, масштаб, SaveAs, обычную камеру и прежние случаи без изменившегося общего кода. Следующий короткий ручной набор — только исправленные дефекты. Все остальные пункты остаются в живом списке/полном WORK_STATUS; этот отчёт не меняет API цели.
