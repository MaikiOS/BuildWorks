# Компактные локальные поля v11 — .204

2026-10-16. `BlueprintFogSimulation` поддерживает необязательный размер сетки. `CompactGrid` округляет размеры к compute-группам8×8×4, сохраняет физический шаг не крупнее(0,075;0,06375;0,0675) м и ограничивает каждый размер256 и общий объём614400 ячейками. Некорректные размеры, переполнение бюджета и грубая сетка отклоняются до выделения GPU-полей.

Отдельный local keyword `BUILDWORKS_FOG_COMPACT_GRID` передаёт фактическое разрешение compute. Default явно отключает keyword и сохраняет исходный статический96×80×80 путь. Все десять RenderTexture и dispatch используют одну сетку. Пул суммирует фактические размеры каналов вместо числа владельцев, умноженного на лабораторный комплект.
