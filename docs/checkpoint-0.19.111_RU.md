# .111 — явная копия без состояния стойки брони

Это ограниченный режим конвертации, полная поддержка ArmorStand не реализована.
Native17/portable7 не меняются. По умолчанию неподдерживаемое состояние сохраняется
и продолжает блокировать размещение. Импорт и экспорт предлагают отдельную копию
без экипировки и позы, показывают источники/prefab/количество до подтверждения.
«Назад» сбрасывает выбор исключения.

Допускается только исходная запись ArmorStand формата .blueprint с проверенной
структурой поза/число слотов/предмет/вариант, точной связью с исходной строкой,
без ZDO, вероятности появления и неизвестных заголовков. Другие Info/ZDO/связи/
вероятности и неизвестные преобразования не исключаются. Масштаб отсутствующего
prefab не выдумывается. Настройки хранилищ и креплений остаются независимыми;
небезопасные варианты очистки заблокированы.

Точный исходный текст и bytes импортируемого файла сохраняются. Повторный импорт
копии не возвращает исключённое состояние из архива. При изменении содержимого
старый PNG не переносится: он мог показывать уже исключённую экипировку. Список
потерь сгруппирован по источнику/prefab, обрезается рамкой и прокручивается.
Индекс исходных строк используется повторно без двойного разбора больших файлов.

Основание: [capture PlanBuild](https://raw.githubusercontent.com/sirskunkalot/PlanBuild/master/PlanBuild/Blueprints/Blueprint.cs)
и [placement PlanBuild](https://raw.githubusercontent.com/sirskunkalot/PlanBuild/master/PlanBuild/Blueprints/Components/PlacementComponent.cs)
хранят/применяют экипировку и позу отдельно от root transform. Чужой игровой код
не копируется и не исполняется в BuildWorks.

Проверки: normal/QA0/0, GeometryTests, полные StoreTests/корпус, HostContract,
локализация862, полная QA isolation, whitespace, Unity Workbench276 и независимый
correctness/ponytail обзор. В корпусе401 подходящая запись; у3 документов стойки
являются единственным неподдерживаемым состоянием. Это не доказательство стройки.
По умолчанию350/353 документов совместимы по формату,25951 запись состояния
остаётся заблокированной. Общего обхода неизвестных данных не добавлено.

Собственный файл: tests/fixtures/armor-state/10-armor-state.blueprint.
Сценарий: QA_0.19.111_RU.md. Valheim не запускался. Стройка пустой стойки,
расход/отмена/reload/network и восстановление экипировки остаются открытыми.

При проверке исправлены новые тестовые сценарии подготовки/кадров/отдельной копии;
для прокрутки добавлен действительно длинный список. Скрипт снимков ожидал252,
пока в обязательный перечень не добавлены два новых состояния. Formatter получил
отказ sandbox named pipe; та же read-only проверка с доступом к IPC прошла.

Дополнительные обязательные проверки LocalizationTests, DeploymentChecks,
EditorBridge и WorldLayoutChecks прошли. Последняя теперь выполняет настоящую
Session на неактивных native Piece/ZNetView внутри изолированного Unity вместо
fake-null неинициализированных Unity объектов. Реальные планы50000 деталей и
атомарный отказ missing/persistence прошли; игровой жизненный цикл/стройку/save
это не доказывает. EditorBridge фиксирует и проверяет базовый масштаб примера,
не обращаясь к отсутствующей scene. Исправлены старые fixtures без изменения
production guards. Первый повтор bridge получил отказ sandbox при записи только
в artifacts; тот же запуск с разрешением прошёл. Помощника verify нет; выполнены
прямые проверки.
