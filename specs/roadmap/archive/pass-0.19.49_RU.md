# Проверка точек и гизмы BuildWorks в игре

[English](current-pass.md) | **Русский**

Проверяем **0.19.49**, только в **TerrainRamp-1.0-Test**. Отвечай по номерам ниже,
не по [старой серии .48](archive/pass-0.19.48_RU.md).
Стенд прошёл; читаемость и физическое управление в Valheim ещё не проверены.
Сначала посмотри **1–3**. Если нечитаемо — пришли скриншот до продолжения.

## Подготовка

Открой копию тестового чертежа: Молоток → BuildWorks → Чертежи → Редактировать.
Нужны две обычные деревянные стены, косой брус и стул; добавляй через Tab.
Перед каждым пунктом редактора: Esc отменяет незавершённое действие, выбери
указанную деталь в дереве, Ctrl+2 включает гизму. Курсор над вьюпортом,
текстовые поля не активны.
A — временная опора трансформации, не сохранённая опора чертежа/группы.
B задаёт направление A→B для рабочей оси X; это не инструмент кривых и
не автоматическое совмещение рёбер. Оба размера меняют ручки, не саму деталь.

## Пункты для ответа

1. **Постоянный размер на экране.**
   В редакторе выбери стену. Сверху вьюпорта: Манипулятор → **Размер: на экране**.
   Закрой меню; приближай/отдаляй через Ctrl+колесо над вьюпортом.
   **Ожидаем:** стрелки, кольца и знаки точек сохраняют примерно одинаковый
   размер в пикселях. Стена выглядит крупнее/мельче, но её числовой масштаб
   не меняется. Нажми видимую точку: область нажатия соответствует рисунку.

2. **Размер в 3D.**
   Та же стена → Манипулятор → **Размер: в 3D**. Закрой меню; приближай/отдаляй.
   В меню Камера переключи перспективу/ортографию и поменяй приближение в
   ортографии. Верни перспективу; измени угол обзора, затем сбрось к игровому.
   **Ожидаем:** ручки имеют постоянный размер относительно модели в 3D:
   вблизи крупнее, вдали мельче. Камера не увеличивает их размер в метрах.
   Попадание следует рисунку. При желании настрой размер точек/ручек в
   Манипуляторе — масштаб самой детали от этого не меняется.
   Верни экранный режим и проверь, что поведение пункта 1 возвращается.

3. **Два типа точек и появление.**
   Сверху выбери **Ваниль + наши** и **У курсора**. Выбери стену, потом косой
   брус. Подводи/отводи курсор от мест точек.
   Переключи У курсора на **Все точки**, затем Ваниль + наши на **Только ваниль**.
   Верни Ваниль + наши / У курсора.
   **Ожидаем:** золото — ваниль; синий — все наши точки, без отдельных цветов
   угла/середины/центра. По умолчанию они появляются около курсора.
   Все точки показывает весь набор выбранной модели; Только ваниль ограничивает
   его. Неактивные точки за поверхностью тусклее. Координаты не смещаются.
   При точном совпадении наша точка внутри ванильного обода.

4. **Выбор A и поворот от исходного положения.**
   Стена → ЛКМ по точке. Отведи мышь; R, подвигай мышь, затем X, подвигай снова,
   введи 30, Enter. Один раз Ctrl+Z.
   **Ожидаем:** выбранная точка остаётся явно отмеченной, сохраняя свой тип;
   гизма переходит в A. R вращает вокруг A. Выбор X обнуляет предыдущее
   свободное вращение; 30 заменяет движение мыши точным углом 30° от начала
   операции. A неподвижна; один Undo возвращает всё действие. Стена не окрашена.

5. **Масштаб вокруг A.**
   Выбери стену и точку A не в центре → S; подвигай мышь, введи 1.5, Enter;
   один раз Ctrl+Z. Повтори S, подвигай, затем Esc.
   **Ожидаем:** 1.5 — 150% исходного масштаба, не дополнительное умножение
   результата мыши. A неподвижна. Один Undo возвращает исходное; Esc отменяет
   без записи изменения. Попробуй нарисованную ручку масштаба с гравировкой:
   нажимается заполненный центр, не только граница.

6. **Дополнительная рабочая ось A→B.**
   Стена → ЛКМ по A → **Выбрать B** сверху → ЛКМ по другой точке B.
   R → X; подвигай мышь → Esc. Повтори R → X → X → X → Esc.
   Нажми **Сбросить A → B**. Кнопкой сверху перебери Оси: детали/мира/вида.
   **Ожидаем:** линия A→B стабильна; A остаётся опорой, X направлена A→B.
   Повтор X переключает Ребро → Мир → Ребро; подпись и движение согласованы.
   Esc восстанавливает прежние оси. Сбросить A → B убирает линию и возвращает
   локальные оси. Выбрать A повторно как B нельзя. Вид использует направления
   камеры, но не поворачивает/соединяет автоматически рёбра двух моделей.

7. **Перенос точка к точке.**
   Стена → ЛКМ по её золотой ванильной A → G. Подведи к другой стене примерно
   на 2 м; наведи около ванильной цели, затем Enter. Один Undo.
   Повтори G и отмени Esc.
   **Ожидаем:** цели соседней детали появляются до примагничивания.
   A — точка захвата; она попадает в цель, а цель не заменяет A.
   Деталь следует поверхностям как призрак установки. Enter записывает одно
   изменение, Esc возвращает исходное положение. Проверь оба режима размера;
   при неясной/трудно выбираемой цели напиши, какой режим был включён.

8. **Авто и фильтр источников.**
   Выбери косой брус (смена выделения сбросит A) → G → Привязка → Авто.
   Дополнительные точки выключены. Останови мышь; нажимай Q/E.
   Включи дополнительные точки, затем сверху Только ваниль; снова Q/E.
   Esc. Выбери стул → G при Ваниль + наши; открой Привязка.
   **Ожидаем:** по умолчанию перебираются только Авто/ваниль, переключение
   происходит сразу без движения мыши. Только ваниль убирает наши точки из
   выбора источника/цели; намеренно выбранная наша A остаётся видимой и пригодной.
   Мебель без ванильных точек предлагает наши при Ваниль + наши; Только ваниль
   не придумывает ей ванильные точки. Клик по меню не подтверждает перенос.

9. **Карточки ресурсов чертежа в мире.**
   Сохрани отдельный чертёж ровно из двух обычных стен, выйди из редактора.
   С молотком выбери обычную стену, затем чертёж без установки.
   Переключи English/русский и выбери повторно. Если есть чертёж с разными
   ресурсами, посмотри его длинный список и прокрути при открытом меню молотка.
   **Ожидаем:** миниатюра/имя/короткое описание, ниже штатные иконки ресурсов,
   общие количества и станки без повторов. Обычно древесина 4, если стена стоит 2.
   Текст не накладывается на карточки; подписи переводятся. Твоё имя чертежа
   не переводится. Про длинный список отдельно напиши, проверял ли его.

10. **Очистка и язык.**
    После призрака чертежа выбери стену, Ремонт, убери/возьми молоток.
    Открой редактор, переключи English/русский, выбери A/B, начни G и Esc;
    выбери другую деталь и переключи Ctrl+1 / Ctrl+2 / Ctrl+3.
    **Ожидаем:** обычная панель восстановлена, лишних карточек/прокрутки нет.
    Новая верхняя строка, подсказки и меню переводятся. Смена выделения сбрасывает
    A/B и её линию. Смена инструмента отменяет незавершённую трансформацию.
    Нет зависшего режима, случайного удаления или подтверждения.

## Как ответить

Один ответ на номер: `1 — работает`, `2 — проблема: …`, до `10`.
При проблеме: номер, экранный/3D размер, инструмент, точное действие и скриншот
для графики. Где нужно — «не проверял». Дополнительных серий с буквами нет.

Это проверка редактора/ввода/отображения, не расхода/возврата ресурсов,
сохранения/перезагрузки мира или сети. Другие профили и кривые не проверяем.
