# Статус исходной альфы BuildWorks 0.19.37

[English](ALPHA_0.19.37.md) | **Русский**

Позиционирование проверенной косой детали оказалось правильным после переключения Q/E. Эта альфа закрывает оставшийся недостаток обратной связи в редакторе чертежей.

## Изменение

- нижняя подсказка постоянно показывает текущий режим source-точки во время размещения;
- Q/E обновляет её сразу;
- точки деталей редактора становятся видимыми в радиусе 2 м от активной source-точки;
- прежний магнитный порог 0,55 м не изменён;
- переиспользованы существующий рендер точек и placement-проход, без отдельного сканера или нового алгоритма snap.

## Автоматические доказательства

- Release: 0 предупреждений, 0 ошибок;
- каталоги и runtime-токены локализации: 596/596, коллизий нет;
- отдельная регистрация English/Russian: PASS;
- Geometry 104, Store, EditorBridge 3, WorldLayout 10, HostContract: PASS;
- Unity Workbench: 81/81 PASS;
- хеши установленной пары совпадают с проверенными артефактами в `TerrainRamp-1.0-Test`.

Игровая приёмка preview целей и русского языка остаётся открытой. Проверенная пара DLL упакована в `BuildWorks-0.19.37-alpha.zip` для GitHub prerelease.
