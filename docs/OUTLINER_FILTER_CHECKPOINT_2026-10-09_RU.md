2026-10-09. Реализовано в исходниках, проверено автоматически. Новая версия
ещё не установлена: в `TerrainRamp-1.0-Test` остаётся QA0.19.116,
SHA256 `867E5E474A3C1B335500E47F1B2DC3A6250AC1FAA36E6D92E766E904F33DCF3A`.
Игра, миры и сохранения этим этапом не затрагивались.

Кнопка **ФИЛЬТР** открывает явный список: все, выбранные, скрытые,
заблокированные, отсутствующие, неизвестный источник/тип, непустая надпись,
масштаб не100%. Поиск можно ограничить именем, ID детали/записи,
записанным источником/версией или типом. Неизвестные сведения обозначаются
как неизвестные; назначение детали по похожему имени не угадывается.
Фильтр масштаба использует подтверждённый относительный масштаб, не пытается
разобрать неизвестный исходный масштаб отсутствующей модели.

Совпадения показываются с путём родительских групп. Свёрнутые ветки временно
раскрываются; сброс возвращает прежнее сворачивание. Фильтр меняет только
список, не сцену, выбор, структуру или историю. **Выбор группы и Ctrl+A
по-прежнему затрагивают детали вне фильтра**; это объяснено в меню.
Поиск также учитывает имена/ID свободных опор. Меню прокручивается; поле
поиска получает фокус после выбора области. Нулевой результат даёт сброс;
пустой чертёж без фильтра не показывает ложное сообщение об отсутствии совпадений.

## Ручная проверка — после новой установки

**Сейчас выполнять не нужно:** QA.116 не содержит этих фильтров. После
установки записать точную версию/SHA. Запуск: Thunderstore →
`TerrainRamp-1.0-Test` → **Modded**, тестовый мир/персонаж `BW_QA_43d3719a`.
Для этого сценария ресурсы и строительство не нужны.

Файл:
`C:\Users\nfspr\AppData\Roaming\Thunderstore Mod Manager\DataFolder\Valheim\profiles\Default\BuildWorks\tests\fixtures\metadata\20-tree-filters.buildworks.json`.
Карточка **QA E08 Tree Filters**, категория OTHER: две стены и намеренно
отсутствующая запись, три группы. Размер рамки синтетический, источник мода
не указан: это не сведения о настоящем стороннем моде.

1. В каталоге редактора → **Импорт файла**, выбрать файл20, сохранить
   отсутствующие записи → **Подтвердить импорт** → карточка → **РЕДАКТИРОВАТЬ**.
2. Стрелкой свернуть **QA assembly**. **ФИЛЬТР** → **Отсутствующие детали**.
   Видны QA assembly → QA room → QA missing target; другая группа/стены
   скрыты только из списка. Геометрия сцены не исчезает.
3. **ФИЛЬТР** → **Сбросить фильтры и поиск**. QA assembly снова свёрнута.
4. **ФИЛЬТР**, прокрутить ниже → **Поиск: ID детали или записи**.
   В поле ввести `BuildWorks_QA_KnownEnvelope`: видна та же родительская
   цепочка. Сбросить. **Поиск: имя**, ввести `QA own wall B`: видна
   QA other → QA own wall B. Сбросить.
5. **Поиск: записанный тип**, ввести `QA fixture`: видна отсутствующая
   запись с родителями. **Источник неизвестен** включает записи без
   подтверждённого источника; точное имя стороннего мода не придумывается.
6. Ввести заведомо отсутствующий текст, нажать строку сброса, проверить
   прежнее сворачивание. Закрыть редактор без сохранения: фильтрация сама
   не должна создавать изменение чертежа или запись Undo.

Ошибка: потерян родитель, изменилась группа/сцена, сброс оставил скрытый
фильтр или раскрыл свёрнутую ветку навсегда, кнопки недоступны прокруткой,
показан выдуманный источник. Игровой ввод и читаемость ещё требуют этой
приёмки; строительство/reload/сеть этим сценарием не проверяются.
