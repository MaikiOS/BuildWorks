# .177 — первые исправления по ручному отчёту

13 октября2026. Установлена QA **0.19.177** в **TerrainRamp-1.0-Test**. Это часть исправлений, не завершение всех замечаний.

- G с двумя выбранными осями подсвечивает ручку соответствующей плоскости (нормаль — оставшаяся ось). Математика перемещения не заменялась.
- Активный перенос курсора не останавливается от одного наведения на верхнюю панель; поиск безопасного места доходит до центра вместо молчаливого отказа после восьми шагов. Клик по панели сохраняет отдельное действие UI и не подтверждает преобразование.
- Неподтверждённый backend-перенос сохраняет предпросмотр: клавиатурная операция переносит отсчёт к фактическому курсору, физическая гизма ждёт отпускания/подтверждения/отмены. Потеря фокуса и Esc по-прежнему отменяют. Неизвестный перенос не принимается за успешный и не вызывает повторную команду.
- При отсутствии записи молотка показывается причина фактического resolver, а не только «чертёж недоступен». Для QA175 Forest Hut текущий QA-лог называет четыре `wood_wall_roof`;28 записей/исходные transforms сохранены. Нет доказательства, что ID устарел, рецепт просто закрыт или деталь отсутствует именно в table. **Строительство этой хижины не исправлено/не подтверждено**; ограничения рецепта и стоимости не обходились, чужой prefab не подставлялся.
- Повреждённая JSON-структура получает ошибку файла без фиктивного номера строки и `{0}`. Принятый отказ all-missing сохранён.

Авто17/18 и масштаб приняты Ostrix для проверенных случаев; их механику в .177 не переписывали. Штатная пара Valheim остаётся основой; BuildWorks дополняет преобразованные точки/выравнивание, а индекс ускоряет только большой поиск. [Подробная граница прежнего auto-join](PASSIVE_SNAP_163_2026-10-12_RU.md).

Проверки: полный Store с пятью новыми отказами неправильных документов; normal/QA0 ошибок/0 предупреждений; Host Steam25730771; локализация991; полный Unity Workbench492 кадра. Проверки плоскостей — пары XY/XZ/YZ в World/Local; G/R края — Local; S края — исходный frame; новые12 случаев кликов активных ViewportFocus/ViewportSectionButton1 при G/R/S с Ctrl/без. Это инертный ввод в настоящем controller/view, не native warp в Valheim. Correctness PASSED, финальный Ponytail Ship. Предыдущий Ship пропустил toolbar-блокер и отозван; исправление и повторный полный прогон прошли. `verify` отсутствует, использованы прямые проверки/обзоры.

В полном UI-прогоне исправлены два устаревших теста: поле высоты F9 уже TMP_InputField, не Button; смена контекста требует Назад→новый обзор→явный выбор. Цвет активной ручки проверяется с точностью Color32; Grid/Projection находятся в скрытых settings sections, поэтому regression использует реально активные header-кнопки. Отслеживаемые Workbench snapshots обновлены штатным Capture-UiWorkbench из текущих канонических исходников; прежняя snapshot-копия части модулей отставала. Это синхронизация тестового стенда, не дополнительная переработка gameplay. Ошибки и окончательные результаты сохранены в `artifacts/checkpoint-0.19.177`.
