# Целое задание локальной модели — QA .165

Ostrix исправил направление: Codex передаёт цель целиком локальной модели,
которая сама выбирает действия; ручные нажатия Codex не заменяют автономного агента.
По явной передаче управления выполнен `inspect-yard.json`: открыть/осмотреть
инвентарь, закрыть, повернуть камеру вправо примерно20° без движения и изменения
предметов. Никакой последовательности стадий в исполнителе нет.

`Run-LocalQAMission.py` даёт qwen3.5:4b цель/ограничения, свежий кадр/native state,
историю и результаты проверок. Ответ ограничен JSON действия. Низкоуровневые
действия исполняются существующим native QA-каналом. Каждый следующий шаг снова
выбирает модель; Codex между шагами не управляет игрой.

## Защита и границы

Общий exclusive lock, свежая сессия/мир/stopRevision, focus/ready, граница площадки,
неизменный инвентарь и положение проверяются до/после ввода. Изменение UI/камеры
во время inference отменяет решение. Неизвестный результат не повторяется.
`finish` не является успехом: нужны все native критерии. Общий бюджет не является
жёстким process-kill; после дедлайна новая команда не dispatch-ится.

Click/text пока исключены: одного selectedUi недостаточно для проверки цели
клика. Нет полного каталога/редактора/стройки/предметного ledger/reload resume.
Не заявлены зрение без native данных, FPS/память, длительная автономность,
физическая F12 и сеть. Ни обычная DLL, ни установленная QA .165 не изменялись.

CPU mission4 и pilot5 прошли. Независимое чтение correctness и Ponytail: PASSED/Ship.
`verify` отсутствует. Эти проверки не доказывают весь объём игрового агента.

## Пауза и продолжение

По просьбе Ostrix игровые испытания остановлены: обе серии уже завершены,
shared lock отсутствует, QA-Stop отправлен и stop.flag исчез. Последняя старая
квитанция содержала revision6; после idle Stop она не обновляется сама.
При попытке read-only уточнения получен точный отказ `Не удается найти процесс
с идентификатором 50348` — прежний процесс завершён. Игра не перезапускалась.
Нового inference/ввода после паузы нет.

Вместо новых микро-задач подготовлен [пакет12 полных сценариев](LOCAL_QA_FULL_SCENARIOS_RU.md).
До следующего разрешения только офлайн-работа. Полный исполнитель/доказательства
должны быть доведены до этих сценариев, а не наоборот.
