# .231 — туман связан с журналом строительного проекта

19.10.2026 · [English](CHECKPOINT_231.md)

Сохраняемый локальный проект теперь создаёт v11 для своих незавершённых частей. Это следующий этап после renderer .230; обычное размещение из молотка пока не создаёт такой проект.

## Изменение

`BlueprintConstructionProjectRuntime` передаёт неизменяемый чертёж и точные `Part.WorldPose` в `BlueprintConstructionProjectFog` на игровой камере. У всех допущенных проектов один embedded bundle, один фиксированный пул и один atlas/объёмный проход. На проект не создаётся полный набор полей или отдельный atlas. Relative scale умножается на исходный масштаб prefab один раз; готовые мировые позы повторно от корня не вычисляются.

Маска берётся из настоящего журнала: нет записи/`NoEffect` — показать; `Intent`/`Observed` — скрыть, сохранив источник; `Committed` — окончательно убрать. При чтении сохранённого проекта уже завершённые части вообще не создают туман. Изменение состояния execution обновляет маску, открытие/закрытие окна таблички её не уничтожает.

Отказ новому визуалу сохраняет план, журнал, табличку и соседние источники. В окне проекта показывается отдельная ошибка предварительного вида. Эффект не управляет `BlocksInput`, оплатой, строительством или возвратом. Неоплаченная отмена сначала сохраняет terminal record и только затем удаляет визуал. Подготовка/выгрузка закрывают iterator и источники, подтверждают GPU drain, освобождают atlas/assets и восстанавливают Depth камеры. По обзору исправлен случай, когда неудачная загрузка assets могла запомнить уже изменённый Depth как исходный.

## Осталось

Обычный Create из молотка, стоимость/достройка на фоне настоящего призрака, отмена с возвратом и общий recovery. Нужны проходы через длинную стену с четырёх сторон, дом и визуальное сравнение с v11, FPS/тяжёлые чертежи, физическая E/HUD и сеть. Смена камеры, настоящие GPU/source faults и исключение при drain в этой серии не вводились.

Текущий backend ограничен 32 logical владельцами, общей областью интеграции 64 м и 32768 work units. Дополнительный/удалённый проект получает явную причину отсутствия визуала; уже допущенная история не вытесняется. Это технические границы текущего этапа, не завершённая поддержка больших построек. Землю не меняем; EarthWorks позже. Все 14 блоков цели сохранены, Goal API остаётся active.
