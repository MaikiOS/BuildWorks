# .108 — загрузка большого чертежа и дерево объектов

Автоматические проверки пройдены. Установка и проверка в Valheim учитываются отдельно.

Редактор загружает документы больше128 деталей порциями: максимум16 новых деталей
или8 мс на Update, с гарантированным продвижением хотя бы на одну деталь.
Окно показывает прогресс и позволяет отменить загрузку. Редактирование до её завершения
заблокировано; отмена и ошибка освобождают уже созданную сцену без записи библиотеки.
Время создания одной сложной детали и финальные проходы сцены этим бюджетом не ограничены.

Дерево больше256 строк создаёт кнопки только для видимой области с небольшим запасом.
Полный состав, группы, опоры, содержимое и записи отсутствующих моделей остаются в документе.
Повторяющиеся предупреждения объединяются без квадратичного склеивания строк.
Остальные входы в редактор направляются в существующий основной контроллер.

Обычная сборка сохраняет предел512 деталей. QA-сборка допускает50000 только после
проверки загруженного изолированного локального мира, персонажа и отсутствия peers.
Unity Workbench использует тот же увеличенный предел отдельно от игры. Ограничения
формата, конечных чисел, размера файлов, памяти и геометрии не отключены.
Предел захвата мира512 пока не изменён. Тяжёлые Undo, выделение, сохранение и финальные
проходы ещё требуют профилирования; это не обещание плавной работы50000 деталей.

Проверено:

- Normal/QA сборки:0 ошибок и0 предупреждений.
- GeometryTests и StoreTests; HostContract, локализация856 ключей, QA isolation и whitespace.
- Фактический редактор Unity: внешний файл1025 деталей, не более16 новых visuals на Update,
  отмена/повторное открытие, ошибка загрузки и очистка, последняя строка виртуального дерева,
  перемещение отсутствующей детали, Undo/Redo, сохранение/повторное чтение всех записей
  и неизменного исходного текста. Прогон:68 Update, около1.9 с вместе с yielded frames.
- Полный Unity Workbench:252 снимка,4 разрешения и3 масштаба интерфейса.
- Независимый read-only correctness/ponytail обзор:PASS.

Первый повторный запуск Workbench был занят отдельным FogGhostStudy.Preview; он не
останавливался. Проверки прошли в копии `artifacts/ui-workbench-108`. Скрипт принимает
только копии непосредственно под tools/artifacts. Исправлены старые тестовые ожидания
512 для Unity Editor и формата15 вместо текущего16; формат данных не менялся.

чертежей, сервер, постоянные задания и административное восстановление остаются открыты.
