# .174 — локальный возврат переданных предметов

13 октября 2026. Это подготовка безопасной отмены, а не включение наполненных хранилищ в строительство.

## Реализовано

- `TryBeginReturn` использует живые ссылки на действительно переданные вещи и полный журнал родительской операции. Неопределённая передача, чужой мир/игрок/target, legacy v1, изменённый состав или отсутствие доступа запрещают возврат.
- Возвращаются текущие свойства предоставленных предметов, включая повреждения после передачи. Архивные атрибуты чертежа и начальное состояние вещи не восстанавливаются.
- Все отдельные пустые ячейки игрока резервируются до начала. Слияния, выбрасывания и поиска новой ячейки после начала нет. Состав, свойства, ячейки, размеры сетки и доступ проверяются до записи и перед native вызовом.
- Прямой перенос замораживается перед созданием дочернего журнала, включая отказ создания/записи. Детерминированный ID дочерней операции и `CreateNew` запрещают второй writer для того же родителя.
- Используется прежний positional `Inventory.MoveItemToThis` в обратном направлении. Bool и исключения не заменяют наблюдение фактического состояния обеих inventory; повтор native попытки запрещён.
- Journal v2 содержит направление и родителя. Для возврата container является source, player — destination; revision/hash относятся к container. V1 читается и удерживается, но не допускается к возврату.
- Даже после полного локального возврата оба журнала остаются unresolved. Удаление target и возврат строительной цены этим не разрешаются.

## Осталось

Возврат работает только с сохранёнными ссылками текущей сессии. Нет перепривязки после перезапуска, доказанного сохранения профиля персонажа/мира, server ack, полной компенсации строительной цены и Container placement. Неподтверждённые операции удерживаются; нельзя удалять их журналы для обхода защиты.
