Первое Create отказало **до записи проекта**: после прежнего маршрута персонаж находился в другой точке, а четыре проверяемых места не подходили по ровности/загрузке/занятости. Найден подтверждённый старт прежних опытов; выполнена только телепортация на существующую площадку, затем повторная строгая проверка разрешила создание. Землю и старые постройки не меняли.

Два кадра проверены визуально: узнаваемый дом остаётся видимым, при контакте есть светлый туман, после выхода форма восстановлена. Оба кадра имеют `cameraRestored=true`. Это статические изображения, **не приёмка анимации или точного вида v11 пользователем**. Кадры стоили130,9мс/103,0мс; значение не есть GPU duration. Срез hold также затратен:118,6мс capture/24,3мс analysis. Вызов успешного tool дополнен проверкой реальных полей, кадров и inventory.

Изменились только QA-сохранения и новая запись собственного отменённого проекта `707092bbb7034c9fb7be7313f671af34` в хранилище QA-world1137745799 с её lock-файлом. У записи проверены checksum, ID, world, revision2 и непустая операция отмены. Это сохраняемый след отмены, его не удаляли ради чистого отчёта. Настройки остальных модов и обычные миры не менялись. В двух route-отчётах warnings/errors отсутствуют; ранние optional Backpack API warnings сохранены в отказавшей подготовке.
