# .110 — сохранённая основа масштаба

Автоматические проверки и независимый correctness/ponytail обзор пройдены.
QA .110 установлена штатным скриптом; DLL совпали,48 QA файлов и библиотека
неизменны. Checkpoint:fa66b1d. Игра не запускалась.

В native17/portable7 добавлен необязательный baseScale. Итоговый размер детали:
(baseScale либо базовый размер доступного prefab) × пользовательский множитель.
Импорт фиксирует исходный абсолютный размер один раз, без деления на canonical
prefab и без произвольного уменьшения. Мировое размещение вычисляет отношение
итогового размера к Hammer prefab, проверяет диапазон и сетевое сохранение до
добавления деталей в план. Все визуальные пути и привязки используют ту же основу.

Старые16/6 читаются без выдуманной основы. Явное сохранение в редакторе фиксирует
основу уже показанной доступной модели; отсутствующие детали сохраняют неизвестность.
Захват использует localScale. Родитель, чья матрица масштаба/искажения/отражения
не воспроизводится сохранённым поворотом и root scale, отклоняется с объяснением.
Исходники внешних файлов не меняются. Старые сборки не читают новую версию17/7.

Пройдены normal/QA сборки0/0, GeometryTests, StoreTests, HostContract, локализация857,
полная QA isolation, whitespace и Unity Workbench252. Actual controller/thumbnail/
ghost/save/reopen проверены при canonical(2,.5,3), Hammer(.5,2,.25), source1,
затем пользовательском множителе.5. Есть rotated/nonuniform snaps, nullable/version
gates, legacy pin, partial updates, overflow и scaled/sheared/mirrored parent tests.
Регрессия настоящего Lava Lantern .109 сохранена и прошла.

Независимый обзор обнаружил мировой предел в редакторской ветке resolver.
Исправлено: forEditor проверяет RootScale, стройка — PlacementScale. Реальная
миниатюра размера.001 проходит, мировой размер.001 относительно prefab1 отклоняется.
Скомпилированная ветка forEditor проверена HostContract; сам полный Session resolver
не исполняется в Workbench, где граница Valheim заменена. Сборки/HostContract/252
Workbench повторно прошли; финальный независимый повторный обзор PASSED, блокеров нет.

Совместимость: новый идентификатор конвертации может создать одну новую .110 копию
рядом со старой v16 копией. Старые копии не переписываются, чтобы не менять их размер
или пользовательские правки. Повторный выбор той же .110 версии использует одну копию.

Первый runtime-прогон выявил старое ожидание множителя в exchange-тесте; теперь
проверяются сохранённая основа, множитель и абсолютный размер после ZIP round-trip.
Отдельный sandbox-запуск упал до тестов в Unity Mono HttpListener с кодом-536870911;
повтор того же стенда вне песочницы прошёл. Это не ошибка запущенной игры.

Сценарий без добычи: [QA_0.19.110_RU.md](QA_0.19.110_RU.md).
