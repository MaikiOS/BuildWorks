# Контракт вариантов материалов

[English](MATERIAL_VARIATION_CONTRACT.md) · [Доказательства](CURRENT_STATUS_RU.md)

`BlueprintMaterialState.Supports` проверяет фактический prefab host. Пустой seed означает обычное поведение; поддерживаемый неотрицательный RandMatSeed может применяться. Некорректное/неподдерживаемое состояние не восстанавливается молча. Неизвестные поля сохраняются с происхождением, без обещания вида/поведения.

При размещении создаётся новая идентичность и применяются лишь поддерживаемые конструктивные свойства. Надписи/конструкция отделены от износа/топлива/инвентаря/admin-состояния. Редактор, миниатюра, призрак и готовая деталь должны использовать один выбор материала. Reload дома не является отдельной приёмкой всех вариантов.

Host уточняет консервативную файловую проверку до import review. Экспорт сообщает неподдерживаемое и не обещает чтение расширений другим модом. Полная модовая/native timing/сетевая серия открыта. Прежние ошибки привязки/стройки сохранены в [истории контракта](MATERIAL_VARIATION_HISTORY_206_RU.md).
