# Compact visual и несколько владельцев v11 — .205

2026-10-16. `BlueprintFogSource` в новом режиме получает область целой детали по действительно индексированным вершинам после prefab/дочерних/заданных TRS. Сохраняются физический шаг source-voxel и padding. Размеры ограничены256 по оси и1 935 360 ячейками. Большая или далёкая от локального начала деталь отклоняется до Bake, без обрезания и изменения масштаба. Default сохраняет лабораторные bounds и размеры.

`BlueprintFogVisual(compactRegion:true)` использует этот source и компактную simulation-сетку .204. `BlueprintFogChannels(ownerLimit,byteBudget)` допускает до32 владельцев при пределе98 304 000 байт полей одного пула. Default-пул по-прежнему имеет2 места. Reservation проверяется до factory; превышение фактического размера очищает новый канал. Проверка заимствованного канала выполняется раньше Dispose, чтобы не уничтожить прежнего владельца. Factory обязана создавать исключительно принадлежащий ей канал; межпуловое заимствование не поддерживается.

## Открытые границы и следующий результат

Это3 источника/расчёта, ещё не общий raymarch трёх объёмов. Renderer пока принимает2 источника; создание большого пула само по себе не делает его многодетальным. Компактный source содержит целую деталь: разрезание больших частей на пространственные участки, переход границ и второй actor ещё не реализованы.93,75 МиБ ограничивают только поля одного пула; source-текстуры, dense meshes и CPU-копии сюда не входят. Общий бюджет клиента и производительность тяжёлого дома ещё измерить.

Следом общий объём нескольких источников → визуал существующего Forest Hut из28 деталей → постоянный проект/колышек/табличка, материалы, безопасная отмена/возврат/reload/сервер. Стоимость, права и предметы в .205 не менялись. К обычной стройке compact visual ещё не подключён. Новый ручной тест дома пока не готов. Полная цель ACTIVE.
