# Серверная библиотека чертежей

[English](SERVER_LIBRARY_PANEL.md) · [Границы приёмки](CURRENT_STATUS_RU.md)

Общая панель молотка/редактора реализует ограниченный просмотр, проверку точных байтов/хеша/формата и принятие личной копии. Публиковать/обновлять/удалять может только администратор с проверкой сервера. Доступ: **игроки** и **администраторы**. Клиент не выдаёт себе права; локальный мир использует полномочия своего host.

Публикуется явно сохранённый документ. У серверной копии своя ревизия; обновление проверяет её. Отмена подготовки ничего не пишет. Отмена уже отправленного запроса прекращает ожидание, но не отменяет подтверждённую сервером запись. Смена мира/клиента сбрасывает review.

Личная копия сохраняет источник/происхождение и не заменяет несохранённый черновик. Вставка переносит неизменяемое происхождение через Undo/Redo/Save/Save As; конфликт/превышение количества источников отказывает до изменения. Снимок источника не даёт право публикации.

UI/протокол/тесты внутри процесса не доказывают host+remote. Живые отказы прав, sockets, reconnect и restart ещё не проверены; прямая передача игрок→игрок остаётся требованием. Файловое «Поделиться» есть, это отдельный путь.

Исторические доказательства: [основа](SERVER_LIBRARY_FOUNDATION_RU.md), [объём .184](MANUAL_QA_184_RU.md). Текущая очередь — [план](ROADMAP_RU.md), не старые абзацы «следом».
