# .230 — v11 в DLL и независимые состояния частей

19.10.2026 · [English](CHECKPOINT_230.md)

Это проверенный визуальный слой для незавершённых частей. Подключение к сохранённому строительному проекту и обычному размещению чертежа ещё не выполнено.

## Изменения

- Встроен ранее проверенный Linear bundle138133B, SHA `6F2A58531F61A3E12FCE61A549546092B699815B85E2457DA31C3F261F8F6F3B`. Solver/shader/include не менялись. Legacy fixtureDD9576… сохранён отдельно.
- `BlueprintFogBuilding` принимает замороженные мировые позиции/повороты и относительный масштаб: готовую позу не вычисляет повторно из корня чертежа и не применяет исходный масштаб prefab дважды.
- Часть можно скрыть и вернуть, сохранив источник и часы, либо окончательно удалить. Удаление во время подготовки закрывает iterator на границе шага; при GPU-операции исходные текстуры остаются у пула до подтверждённого retirement. Соседние части не пересоздаются.
- И поверхность, и объём получают один компактный список видимых частей. Пустой список очищает привязки и пропускает изображение; общий пул продолжает освобождать удалённые источники. Счётчик видимости отражает изменение сразу, до следующего кадра.
- QA-пробы читают `LoadEmbedded()` из установленной DLL вместо локального candidate-файла. Оплата, журнал, возврат, права и состояние проекта этим кодом не меняются.
