## Настоящий Valheim: что прошло

Одна временная8м стена из четырёх соседних native woodwall. Реальный QA-персонаж прошёл спереди, удерживался2с и вышел; восстановление наблюдалось8с, затем получены ещё два среза с интервалом1с. **30/30**, optional failures0,21,3с. Фоновый GABS, batchMode/background, прежние изолированные идентичности/cloud=false, без рабочей мыши/клавиатуры, выдачи ресурсов, строительства или сброса мира. Запись всех четырёх направлений остаётся в [.220](CHECKPOINT_220_RU.md); численная серия .221 пока проверяет одно направление.

Новый QA-probe на одной границе CommandBuffer читает published metadata/map bases/maps/payload/receipts/ledgerFlags и, по запросу, Bricks. Проверены owner/generation/sequence/tick/revision, активные flags3, допустимый банк и успешный receipt; неверная привязка отклоняется, а не становится «нулевой плотностью». Читаются только достижимые страницы. Все RGBA finite; alpha decoded из half. Для внутренней части Bricks сравниваются точные RGBA half-биты (+0/-0 равны). Gutters, интерполяция renderer и итоговые пиксели этим не проверены.

Срез требует76 034 912B managed-копий; оценка копий+staging152 069 824B, дополнительные расходы driver отдельно не измерены. Лимит128MiB относится только к managed-копиям. CPU-разбор1,38–3,74мс.
