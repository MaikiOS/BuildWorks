# .147 — десятичные запятые PlanBuild, проверка без игры

Код `ca8c5f7`. Собраны normal и QA0.19.147; установлена по-прежнему QA0.19.146.
Ostrix работает за компьютером: Valheim, Unity и управление вводом не запускались.

## Изменение и границы

Закреплённый PlanBuild PieceEntry.FromBlueprint принимает `3,25` как `3.25`.
BuildWorks отвергал такой файл; новый тест воспроизвёл отказ до исправления.
Нормализация теперь касается только колонок позиции2–4, quaternion5–8 и
масштаба10–12 в `.blueprint`. Пустые числа, нечисловые/бесконечные значения,
пределы положения/масштаба, quaternion и атомарный отказ сохраняются.
Строгие точки привязки и semicolon `.vbuild` не изменены.

Исходный текст, BOM/CRLF, ссылки на строки, ID, категория, надписи и неизвестные
Info/ZDO/chance сохраняются. Upstream заменяет запятые во всей строке; его порчу
пунктуации/идентификаторов BuildWorks не повторяет. Неизвестные данные остаются
инертными. Исходный root scale сохраняется; масштаб всей постройки не меняется.
В имеющемся публичном наборе десятичные запятые не найдены. Это подтверждённый
пробел совместимости, а не установленная причина прежних отказов или задержек.

Первичный источник: PlanBuild commit `e12ed86ff2498bbd4a9c0f5d81cb388e3aaeb549`,
PieceEntry.cs/SnapPointEntry.cs; локальные исходники, ссылки и SHA —
`artifacts/planbuild-reader-0.19.140/provenance.json`. Они не изменены и не включены
в мод. Исследовательский harness проверил обе культуры с явно указанными JSON/Unity
численными заменами; это не исполнение в Valheim.

## Отложенная ручная проверка — только после установки .147 или новее

Сейчас её выполнять не нужно. Нужен существующий QA-мир через TerrainRamp-1.0-Test
→ Modded; материалы и строительство для этой проверки не требуются.

1. Исходное состояние: каталог редактора открыт, версия не ниже .147.
   «Импорт файла» → папка
   `C:\Users\nfspr\AppData\Roaming\Thunderstore Mod Manager\DataFolder\Valheim\profiles\Default\BuildWorks\tests\fixtures\planbuild`.
2. Файл `26-planbuild-decimal-comma.blueprint` → «Импорт файла» →
   «Подтвердить импорт». Найди карточку **QA147 PlanBuild Comma**.
3. Меню карточки → «РЕДАКТИРОВАТЬ». Ожидается одна табличка `sign`:
   положение(3.25,-4.5,0.125), поворот90° поY, root scale(1.5,0.5,2.25),
   надпись **Привет, мир** с запятой. Проценты редактора могут быть100%:
   исходный root scale хранится отдельно от последующего пользовательского масштаба.
4. «Сохранить как…», имя `QA147 Comma Copy`; закрыть и снова открыть копию.
   Ожидаются та же форма/поворот/надпись. Исходный файл не изменяется.

Ошибка: отказ импорта, исчезнувшая/лишняя деталь, гигантская или единичная форма,
иной поворот, точка вместо запятой в надписи, потеря изменений после открытия.
Эта короткая серия проверяет редактор; подтверждения строительства/reload не заменяет.
