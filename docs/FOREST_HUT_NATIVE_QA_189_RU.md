# Forest Hut — игровая проверка .189, 2026-10-15

Установлена QA 0.19.189.0; Valheim 1.0.20/build25909357. Запуск выполнен через Thunderstore → TerrainRamp-1.0-Test → Modded с одноразовым разрешением существующего GABS bridge. Свежий лог подтвердил изоляцию; список сохранений содержал только QA-персонажа и QA-мир. Основные сохранения не использовались.

## Подтверждено в игре

- Продолжена существующая собственная копия QA187 Forest Hut: 28 деталей; повторного импорта или выдачи материалов не было.
- Четыре записи wood_wall_roof явно заменены через каталог на выбранную wood_wall_roof_a. Это проверка пользовательской замены, не доказательство автоматической эквивалентности старого ID.
- Отмена первого предпросмотра сохранила исходную запись и убрала временную копию. Применение, Undo/Redo и сохранение/повторное открытие прошли.
- После повторного открытия сохранились 28 деталей, четыре замены, их положения/повороты/масштабы и изменение двери.
- После наведения камеры призрак виден; native PlacementStatus=Valid. NoCostCheat=false; рядом существующий верстак.
- Один ограниченный клик обычного игрового ввода запустил серию. Первый дом завершён: 28 TryPlacePiece и 28 ConsumeResources, исключений 0. Древесина 64 → 6, расход 58 совпал с показанной стоимостью. Молоток износился; ожидание выносливости завершалось автоматически.
- Все 28 реальных объектов первого дома найдены по prefab и координатам. Положение совпало с чертежом при одном общем переносе, максимальная ошибка 0,000013 м; ошибка компонентов поворота 0; масштаба <0,000001. У объектов различные native ZDOID, без переноса старой сетевой идентичности.

- Штатный logout/reload выполнен: все 28 объектов найдены; положение и масштаб без изменений, разница quaternion ≤4,4×10⁻⁸. Полный инвентарь (включая прочность молотков и 6 Wood) совпал с непосредственным снимком перед выходом.
- Проверен native ZDO.Load: при загрузке ID назначается заново через ++m_loadID/SetID. У загруженных объектов 28 уникальных ID; равенство старому runtime ID намеренно не требуется.
- Временные god/ghost выключены; NoCostCheat=false, виртуальный ввод не активен. SHA внешнего исходника неизменён.

## Границы результата и оставшееся

- Ostrix подтвердил, что вторую стройку проверял вручную; это не повтор QA-команды. Замер 64 → 6 относится строго к первому завершению. Перед logout 6 Wood вновь находились в инвентаре; сверка reload использует свежие снимки до/после выхода.
- Сообщение об отсутствии видимого призрака при первоначальном горизонтальном наведении требует отдельного улучшения обратной связи. Позднее видимый призрак подтверждён кадром и native статусом; проверка только имени GameObject была бы недостаточной.
- Шрифт Valheim не содержит символ раскрытия группы U+25BE: Unity использовала заменяющий квадрат.
- Это один дом после явной пользовательской замены ID; автоматическая конвертация всей библиотеки, наполненные хранилища/крепления, административное восстановление, постоянный проект/v11 и сеть этим не проверены.
