# Исходная альфа BuildWorks 0.19.34

[English](release-notes-0.19.34.md) | **Русский**

## Изменения

- English-first runtime-локализация с полным русским каталогом;
- 596 стабильных ключей для текущего интерфейса BuildWorks;
- независимые от языка ID логики и сохранений;
- локализованные имена копий, Array и Contour;
- документация архитектуры, локализации и проверок для участников;
- проверка форматирования и embedded-ресурсов.

## Проверка

Release 0/0, localization 596/596, Geometry 104, Store, EditorBridge 3, WorldLayout 10, HostContract и Unity Workbench 81/81 — PASS.

## Известные ограничения

- 0.19.34 ещё не установлена и не запускалась в Valheim;
- ручная проверка English и Russian ещё не выполнена;
- игровые сценарии placement и Array 0.19.33 остаются открыты;
- save/reload, multiplayer, import/export, сохраняемые операции и процедурные кривые ещё не прошли финальные ворота.
