# Проверка окна импорта — 0.19.82

В этой проверке ничего строить, добывать или открывать персонажу не нужно.
Используй тестовый профиль **TerrainRamp-1.0-Test**, не основной мир.

## Что проверить сейчас

1. Возьми молоток, открой меню строительства → **«Чертежи»** → **«Импорт файла»**.
2. Нажми **«Папка BuildWorks»**, затем строку **«Папка: test-fixtures»**.
   Это подготовленная папка с шестью файлами с твоего снимка. Путь вводить не надо.
3. Вверху должна быть короткая надпись **«Папка: test-fixtures»**. Длинный путь
   специально не выводится в узкой строке. Справа — **«Изменить путь»**.
4. Пока файл не выбран, нажми **«Скопировать путь»**. Вставь текст в Блокнот:
   должен скопироваться полный путь, а не сокращённая надпись:

   `C:\Users\nfspr\AppData\Roaming\Thunderstore Mod Manager\DataFolder\Valheim\profiles\TerrainRamp-1.0-Test\BepInEx\config\BuildWorks\test-fixtures`

   После выбора файла эта же кнопка копирует полный путь выбранного файла.
5. Нажми **«Изменить путь»**. Вместо короткой надписи появится увеличенное поле
   с полным путём на нескольких строках. В `\nfspr` не должно быть искусственного
   переноса, в `\test-fixtures` — табуляции: обратные косые черты должны быть видны.
   Для необычно длинного пути поле допускает прокрутку при перемещении курсора.
6. Не меняя текст, нажми **«Открыть»**: снова должна появиться короткая надпись,
   а список файлов остаться прежним. Снова нажми **«Изменить путь»**, измени текст
   и нажми **«Отменить ввод»**: должна восстановиться та же папка. Пока ввод пути
   открыт, импорт/экспорт заблокирован — неподтверждённый путь не используется.
7. Нажми **«Закрыть»** вверху справа. Открой редактор чертежей → клавиша Tab →
   **«Чертежи»** → **«Импорт файла»**. Повтори шаги 2–6: окно у редактора и молотка общее.

Если снова виден обрезанный текст, пришли снимок и укажи разрешение экрана и
масштаб интерфейса. Это проверка конкретного окна; повторять все испытания
импорта и строительства ради неё не нужно.

## Что означают подготовленные файлы

Имена файлов оставлены прежними, чтобы ранее импортированные копии и пути
не потерялись. Ниже — русские пояснения; английский для проверки не нужен.

| Файл в списке | Что внутри | Название уже импортированной копии |
|---|---|---|
| `01-walls.blueprint` | Две деревянные стены | `TEST 01 Walls` |
| `02-sign.blueprint` | Стена и табличка «BuildWorks: Привет, Ostrix!» | `TEST 02 Sign` |
| `03-opaque.blueprint` | Две стены и пока неподдержанные дополнительные данные | `TEST 03 Opaque` |
| `04-snap.blueprint` | Две стены и точка привязки чужого формата | `TEST 04 Snap` |
| `05-missing.blueprint` | Намеренно отсутствующая деталь: проверка отказа | Не должен импортироваться успешно |
| `06-lamp.blueprint` | Стена и лампа для диагностики масштаба | `TEST 06 Lamp` |

Не импортируй все шесть одновременно: пятый файл специально ошибочный.
Третий и четвёртый предназначены для редактора, их строительство пока ограничено.
Шестой помогает расследовать масштаб лампы; эта сборка не объявляет проблему лампы решённой.
Наличие миниатюры не означает готовность чертежа к строительству.

Сборка 0.19.82 меняет отображение путей, не форматы чертежей и не правила мира.
Автоматические проверки Unity не заменяют эту короткую проверку в Valheim.
