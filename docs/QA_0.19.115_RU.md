# Проверка .115 — заменить отсутствующую деталь своими

Файл: `tests/fixtures/replacement/14-replace-missing.buildworks.json`.
Найти: профиль Default → BuildWorks → tests → fixtures → replacement.
Имя чертежа: **QA115 Replace Missing**. Это собственный синтетический стенд:
один намеренно отсутствующий prefab с тестовой рамкой и две обычные woodwall.
Рамка не является измерением настоящей отсутствующей модели.

Исходное состояние: QA .115 в изолированном TerrainRamp-1.0-Test и подготовленный
QA персонаж/мир. Материалы, чужие моды и стройка стенда не нужны: проверка редактора.
При разрешённом запуске использовать Thunderstore → **Modded**.

1. Каталог редактора → «Импорт файла», выбрать точный файл. Оставить
   «Отсутствующие детали: СОХРАНИТЬ ЗАПИСИ» → «Подтвердить импорт».
   Ожидаются три записи и предупреждение об одном отсутствующем ID.
2. «РЕДАКТИРОВАТЬ». В дереве выбрать **QA missing target**, затем с Ctrl добавить
   **QA own wall A** и **QA own wall B**. Свои стены можно заранее передвинуть
   существующей гизмой. «Инструменты» → «ЗАМЕНИТЬ ОТСУТСТВУЮЩУЮ».
   Ожидаются ID BuildWorks_QA_KnownEnvelope и две детали замены.
3. «ОТМЕНА»: все три записи остаются, положения прежние. Повторить действие,
   нажать «ПРИМЕНИТЬ»: рамка исчезает, две стены остаются в своих положениях
   внутри группы «Замена». Основная деталь переходит на стену A.
4. Ctrl+Z: возвращаются отсутствующая запись и прежнее дерево. Выбрать только
   отсутствующую запись: замена недоступна, ничего не удаляется. Ctrl+Y: снова
   две стены и группа замены. Не должно появиться дополнительных копий стен.
5. «СОХРАНИТЬ» → имя **QA115 Replacement Edited** → «СОХРАНИТЬ».
   Закрыть редактор и снова открыть сохранённую копию. Ожидаются две стены,
   их прежние положения/масштабы и группа. Исходный файл не изменяется.

Признаки ошибки: автоматическое смещение/изменение размера; исчезли свои стены;
дубликаты; Undo не возвращает запись целиком; сохранение/reopen теряет группу;
невозможно сохранить после переноса последней детали из основной группы.

В Workbench отдельно проверены устаревшее подтверждение, исчезновение prefab,
свободная опора и исходные данные. Этот сценарий не доказывает игровую стройку,
расход ресурсов, reload мира, multiplayer или туман v11.
