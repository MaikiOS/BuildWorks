# Проверка .190: причина недоступности детали

Только существующий QA-мир и персонаж: Thunderstore → TerrainRamp-1.0-Test → Modded. Проверка не требует ресурсов или строительства стенда. Установку .190 сверять по живому списку.

Файл: `35-present-not-in-hammer.blueprint`, папка `BuildWorks/artifacts/Blueprints-for-import/BuildWorks-tests`. Это отдельный авторский тест одной старой детали крыши, а не загруженная библиотека. Автоматически в каталог он не добавляется.

1. Молоток → «ЧЕРТЕЖИ» → «Импорт файла». Открыть указанную папку, выбрать файл и подтвердить импорт через «Подтвердить импорт».
2. Найти карточку **TEST 35 Legacy Roof Warning**. На текущем Valheim 1.0.20 старая модель `wood_wall_roof` загружена, но отсутствует в обычной таблице строительства молотка.
3. Открыть каталог редактора и выбрать эту карточку. Ожидается предупреждение с конкретной причиной недоступности строительства. Если модель доступна, она не должна обозначаться как отсутствующий мод только из-за запрета строительства.
4. Нажать «РЕДАКТИРОВАТЬ». Ожидается доступная модель; редактор открывается. Закрыть без изменений.
5. Выбрать «РАЗМЕСТИТЬ» в молотке. Ожидается отказ с причиной; расход ресурсов и создание деталей отсутствуют. Это проверка сохранённого запрета, а не просьба строить недоступную деталь.

Признаки ошибки: карточка редактора теряет причину, показывает только общий восклицательный знак; доступная модель выдаётся за missing; редактор запрещён; недоступная деталь бесплатно создаётся. Если состав модов/Valheim изменился и старый prefab уже входит в молоток, сценарий больше не воспроизводит нужное исходное состояние — сообщить версию и результат, не считать это отказом исправления.

Этот случай пока не проверен в Valheim .190. Автоматические тесты данных предметов не доказывают отображение предупреждения.
