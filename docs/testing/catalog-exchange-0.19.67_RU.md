# Проверка BuildWorks 0.19.67

Только профиль TerrainRamp-1.0-Test. Игру запускает Ostrix.
180 состояний и реальные клики прошли в изолированной Unity, не в Valheim.

1. Молоток → «Чертежи»: проверить ускоренную прокрутку категорий, затем
   «Импорт файла». Папки «Загрузки», «Документы», «Рабочий стол», переход
   «Выше» и выбор файла должны работать без знания полного пути.
   Во время смены папки старые строки исчезают. Импорт .blueprint/.vbuild/
   .buildworks.json/ZIP оставляет исходник и сообщает путь отдельной копии.
2. Пока открыт диалог, ввод в полях/клики/колесо не двигают камеру и не
   размещают детали. Esc закрывает только диалог, не молоток/каталог;
   закрывающий клик также не должен разместить деталь.
3. Экспорт: выбрать папку, имя без расширения и JSON либо ZIP BuildWorks.
   Результат остаётся открытым, «Скопировать путь» возвращает полный путь.
   Повтор имени даёт ошибку без перезаписи; исправить имя и повторить.
   В редакторе проверить тот же сценарий во вкладке «Чертежи».
4. Импортировать экспорт, сравнить XYZ-размер, надписи, группы, позу опор.
   Внешнюю постройку с неединичным масштабом исходных prefab сравнить с
   исходным модом: размер не должен удваиваться или самовольно уменьшаться.
   Нет нужного prefab/поддержки данных — явная причина, без частичной постройки.
5. Редактор → Space/F3 → «Инструменты»: создать свободную опору.
   В дереве только существующие объекты/опоры, не кнопки создания/удаления.
   Выбрать опору, G/R меняют её, не детали. Назначить опорой размещения,
   сохранить/открыть и сравнить; удаление и возврат центра через «Инструменты».
6. Проверить диалоги с открытыми подсказками на 1280×720 и своём широком
   разрешении, масштаб интерфейса 100/120/140%. Нижние кнопки доступны,
   подсказки их не перекрывают. Не нужно выключать подсказки для экспорта.

Новый формат с полным хранением чужих данных, тяжёлые интерактивные сцены
больше 512 деталей и поддержка обычных предметов/оснащения держателей ещё
не реализованы. Опоры после перезагрузки мира/на другом клиенте не подтверждены.
Это проверка конкретного шага, не окончательное принятие всей цели.
